## 1. 第一次打开：选库、配模型、看懂界面

### 1.1 启动与选学习库

在仓库根目录运行：

```bash
npm run tui
# 或指定已有学习库目录（与桌面版/插件版共享同一套学习库数据）
node packages/studyhub-tui/bin/studyhub-tui.mjs --root /path/to/.dsh-study
```

- 首次打开若学习库为空，会自动进入 **新手启动台（Launchpad）**：可以一键载入示例课程体验，或直接导入自己的讲义资料。
- 想更换学习库目录：按 `,` 进入 **设置** → 按 `2` 切到 **工作区（Workspace）** → 按 `e` 修改路径并按 `c` 确认。

### 1.2 配置 AI 模型（以及没配模型时能用什么）

按 `,` 进入 **设置** → 默认就在 **模型（`1`）** 页签：

1. **主模型（默认优先 `agy` CLI）**：本机装有 `agy` CLI 时会自动探测，选好模型后按 `a` 或 `Enter` 启用，按 `e` 调整思考强度（`low` / `medium` / `high` / `xhigh` / `max`），按 `t` 测试连通。
2. **副模型（OpenAI 兼容接口）**：内置 DeepSeek / OpenAI / 硅基流动 / 智谱 GLM / OpenRouter / Groq / Moonshot Kimi / 自定义 Base URL 预设。也可通过环境变量提供密钥（不落盘）：
   - Linux/macOS：`export DEEPSEEK_API_KEY="sk-..."`
   - Windows PowerShell：`$env:DEEPSEEK_API_KEY = "sk-..."`
3. **没配模型时哪些功能还能用？**
   - **完全可用（0-token 本地功能）**：导入与阅读资料、高亮/书签/目录浏览、刷已有题组与 FSRS-6 自评、错题本浏览与 0-token 错题分流、模拟考试（选择题卷）、学习统计热力图、待办看板与番茄钟、学习笔记编辑与 Markdown 导出、所有无头 CLI 命令（`--doctor` / `--stats` / `--due` / `--board` / `--search` / `--export`）。
   - **需要模型的功能**：AI 从资料出题、AI 帮我理解讲解与追问、互动带学、费曼复述评估、AI 评分标准批改、生词提取、翻译题目/页内翻译、AI 归类/分夹、生成复习全书与知识骨架、音频转写。

### 1.3 看懂界面三块区域

- **顶栏（TopBar）**：最上方一行。左到右显示 `StudyHub` 标志、当前页面、当前课程（`[c]` 切换，宽窗口完整展示不硬截）、右侧显示收件箱未读数（`[I]`，进入后按 `h` 可切至「近期提示」回看最近 50 条多行提示消息，不怕提示闪过）、运行中后台任务、今日到期题数、当前生效模型、`[?] 帮助` 与 `[/]`（或 `[Ctrl+K]`）命令面板。
- **左侧导航栏（SideNav）**：分「每日」「考试」「整理」三组共 15 页，加上顶部绿色 **「▶ 继续练习 `r`」**（有进行中练习时显示）。按 `\` 折叠/展开（窗口宽度 `< 100` 列自动折叠）。
  - **重要提示（诚实按键）**：三个**保留全局键**永远不会被任何页面覆盖：
    - `r`：随时回到正在做的题目 / 继续练习（即使你在资料列表、阅读器或阅读器抽屉里！）
    - `q`：随时安全退出（有进行中的刷题或模拟考时会弹出确认框）
    - `?`：随时打开当前页面帮助与教程
  - 其他页面跳转键（如 `a`、`t`、`n`、`1-4`）若在当前页面有局部含义，侧栏会**自动隐藏**该键提示，避免误导。任何页面里按 `Ctrl+K` 都能用命令面板跳到任意页面。
- **主内容区 + 底部提示行**：中间是当前页的核心工作区；最底部一行显示当前情境最常用的快捷键，窗口较窄截断时会明确提示 `按?看全部`。

## 2. 核心主线：从导入资料到刷题与错题复盘

如果你第一次用 TUI，照着下面 5 步就能跑完完整学习闭环：

1. **导入资料（`2` → `i`）**
   - 按 `2` 进入 **资料** 页 → 按 `i` 打开导入框。
   - 输入 PDF / PPTX / DOCX / Markdown / TXT / HTML / LaTeX 文件路径（支持 `Tab` 路径自动补全），选择所属课程后按 `Enter` 导入。
   - 导入完成后按 `Enter` 可直接分页阅读；阅读中随时按 `r` 可回到刷题。
2. **创建题组（`3` → 勾选资料 → `Ctrl+S`）**
   - 按 `3` 进入 **创建题组** 页。
   - `j`/`k` 移动光标，`Space` 勾选刚导入的资料（`a` 全选/清空，`/` 关键词筛选资料）。
   - 按 `k` 选题型、按 `n` 选题数、按 `p` 选页码范围、按 `f` 填写侧重点，然后按 `Ctrl+S` 启动后台出题任务（可按 `t` 在后台任务页看实时进度）。
3. **审核并发布草稿（`3` → `Tab` → `P`）**
   - 出题完成后会生成草稿。在 **创建题组** 页按 `Tab` 切到 **草稿编辑（DraftEditor）**。
   - `j`/`k` 逐题预览，`e` 修改题干/答案/解析，`x` 移除不想要的题（误删按 `u` 撤销），`V` 运行发布预检，确认无误后按 `P` 发布成正式题组。
4. **开始练习与看反馈（`1` → `Enter` 或全局 `r`）**
   - 按 `1` 回到 **学习库**，选中刚发布的题组按 `Enter` 开始练习（或在任意页按 `r` 继续最近练习）。
   - 单选/多选/判断用 `1-6` 或 `a-f` 作答，填空/简答按 `i` 输入后 `Enter` 翻看参考答案，再用 `0-5` 做 FSRS-6 记忆自评。
   - 有不懂的题按 `h` 打开右侧「AI 帮我理解」抽屉，按 `o` 直接跳到引用的讲义原文页，看完原文按 `r` 一键回到刚才那道题！
5. **复盘错题（`4`）**
   - 做错或自评低分的题会自动进入 **错题本**（按 `4` 进入）。
   - 按 `e` 标记错因，按 `t` 做 0-token 错题分流，或 `Space` 勾选多道错题后按 `B` 发起批量错题重练。

## 3. 刷题页详解：每个键的作用、AI 抽屉与自评 0–5

### 3.1 作答与导航基础键

- `1-6` / `a-f`：单选直接选并提交；多选勾选/取消（也可用 `Space`），选完按 `Enter` 提交。
- `1` 与 `2`：判断题选「对 / 错」（`t` 留给带学，不再用来作答）。
- `i` / `Enter`：填空题或简答题进入输入模式（多空题用 `Tab` 切下一空，自动保存草稿，离开再回来不丢）。
- `Space` / `Enter`：闪卡翻开参考答案；已提交反馈后按 `Enter` 或 `.` 进入下一题。
- `m`：在「Unicode 渲染数学公式」和「原始 LaTeX」之间切换。
- `X`：结束本轮练习进入「本轮小结」（带二次确认，不会误退；想退出整个 TUI 按全局 `q`）。

### 3.2 底部提示行每一个键都是干什么的？

| 按键 | 名称 | 作用与适用场景 |
| --- | --- | --- |
| `h` | **讲解（AI 帮我理解）** | 打开右侧流式 AI 抽屉，讲解考点、思路与误区，支持自由追问（优先复用已存与本轮讲解，`R` 重生成）。 |
| `t` | **带学（常驻助手带学/复述）** | 打开统一常驻 AI 助手与带学工作台（也可随时 `Ctrl+G` 唤出），包含「助手 / 带学」双 Tab；带学按 `提问 → 作答 → 判定 → 复述 → 小结` 推进（`[t]` 直达复述阶段，`[S]` 跳过复述并记录，`[c/C/y]` OSC 52 复制，`[F]` 全屏）。 |
| `L` | **苏格拉底带学（独立弹窗）** | 打开经典一步一步苏格拉底带学弹窗（适合专注当前题的逐步引导，支持跳过单步或直接展示剩余要点）。 |
| `F` | **费曼复述（独立弹窗）** | 打开经典费曼复述弹窗，用自己的话复述本题并查看「讲对了 / 漏掉了 / 讲错了」结构化反馈。 |
| `*` | **重点** | 把当前题标记/取消标记为重点题，方便后续集中强化。 |
| `G` | **评分（AI 评分标准批改）** | 仅对带 Rubric 评分标准的简答/案例/开放题显示，按得分点逐项打分并给出建议 FSRS 分档。 |
| `A` | **答题卡** | 查看或生成结构化「分析题答题卡」（提炼题型信号、题干事实、核对过的原文引文与评分点对照），支持 `d` 发起弱项强化练习。 |
| `W` | **翻译** | 翻译当前题干、选项与解析（支持双语对照，带本地缓存）。 |
| `S` | **同类** | 查找题库里和本题容易混淆的同类题（顶部高亮原题并支持 `[B]` 一键回原题），按 `Enter` 开对比练习轮（自动压栈，`Esc`/`r` 逐层返回原题）。 |
| `D` | **工具（卡片工具箱）** | 集中入口：编辑题目、暂停/斩题、管理前置依赖题、**提取专业生词/术语**、提交题目质量反馈、回退/重试 AI 改题。 |
| `Q` | **队列** | 打开**本轮练习队列编辑器**（模拟考模式下锁定）：查看本轮接下来还有哪些题、插队、重排或移除本轮某道题。 |
| `E` | **标记** | 给这道题打问题标记（如题目有歧义、答案有误），方便后续统一修订。 |
| `s` | **跳过** | 暂时跳过当前未作答的题，先做后面的题。 |
| `u` | **撤销** | 撤销上一题的作答/自评评分（选错了 `0-5` 分档时马上按 `u` 就能撤回重评！）。 |
| `,` / `.` | **换题** | `,`（或 `←`）看上一题，`.`（或 `→`）看下一题。 |
| `J` | **改分** | AI 评分后，手动调整 FSRS 最终分档（覆盖 AI 原评并保留记录）。 |
| `K` | **确认订正** | 错题有待确认订正提示时，按 `K` 确认订正并将该题加入本轮重练。 |
| `N` | **陪学点拨** | 答错或自评 `< 3` 分时出现，打开 AI 陪学点拨与轻量小检查。 |
| `o` | **跳转原文** | 当题目有资料页码引用时，直接打开阅读器定位到那一页；看完随时按 `r` 回到刚才这道题。 |

### 3.3 「AI 帮我理解」抽屉（`h`）：复用、追问与保存

- **优先复用，不白花额度**：
  - 如果这道题以前保存过讲解（`run.solution.followups`），翻开答案后刷题页会提示 `已存讲解 N 条，按 [h] 查看`，打开抽屉**直接展示已有讲解，0 次模型调用**。
  - 同一轮练习里关掉抽屉再按 `h` 打开，本轮对话历史自动保留，不会重新生成。
  - 没保存过讲解的新题，首次打开会自动生成一次讲解。
- **抽屉内常用键**：
  - `i` / `Enter`：聚焦底部输入框，自由输入追问。
  - `s`：生成 3 条推荐追问（自动折行完整展示），按 `1`/`2`/`3`（或鼠标点击）一键发问。
  - `N`：把最新一条问答保存到本题追问记录和学习笔记中，**下次打开直接复用**。
  - `R`：**显式重新生成**（界面标明会调用一次模型），新讲解不会覆盖已存记录，除非你再次按 `N` 保存。
  - `j`/`k`（或 `↑`/`↓`）：滚动阅读讲解；`Esc` / `h` 关闭抽屉。

### 3.4 AI 结果页之后的统一后续指令（`a`）

在**生词提取（`D` → 术语）、互动带学完成页（`L`）、费曼复述评估页（`F`）、答题卡（`A`）、同类题对比（`S`）**的底部，都有统一的 **「接下来想做什么？按 `[a]` 自由输入指令」** 输入框：

- 当前题干、你的作答与本次 AI 工具结果会**自动带入上下文**，无需手动复制粘贴。
- 按 `a`（或点击输入框）后，可直接打字提要求（例如生词提取后输入「给每个词写一段通俗讲解」），也可点/按快捷项 `[1]通俗讲解`、`[2]举个例子`、`[3]换个讲法`、`[4]出前置题` 快速填入一句话再修改发送。
- 收到回答后按 `N` 可直接存成这道题的追问与学习笔记，按 `Esc` 收起对话框。

### 3.5 FSRS-6 六级记忆自评（`0`–`5`）怎么选？

| 分档 | 含义 | 什么时候选 |
| --- | --- | --- |
| `0` | 完全不会（黑屏） | 看了题目完全没印象，需要重新学 |
| `1` | 没答出，看答案有印象 | 自己想不起来，翻开答案才想起来 |
| `2` | 勉强对 / 关键细节错 | 方向沾边但漏了核心条件或算错关键步骤 |
| `3` | 困难但答对（Hard） | 想了很久才答出来，下次间隔较短 |
| `4` | 正常记住（Good） | 思考顺畅、准确答出，**最常用的标准档** |
| `5` | 非常轻松（Easy） | 一眼秒杀、彻底掌握，拉长下次复习间隔 |

> **选错了怎么办？** 立刻按 `u` 撤销上一题评分，或者按 `,` 回到上一题重新核对。

## 4. 全 16 个页面使用指南（每页做什么、常用操作、易误按键）

### 4.1 `1` 学习库（Library）
- **干什么**：首页总览——查看今日学习进度、全部课程与题组列表、草稿与失败任务。
- **最常用操作**：
  1. `Enter` 开始练习选中题组；`R` 定制本轮题数/题型/范围；`p` 查看今日计划。
  2. `m` 进入**题组卡片管理**（见下方二级按键说明）；`o` 导入/合并/拆分题组；`x` 导出题组复习卷 Markdown。
  3. `g` 打开 AI 带学工作台；`C` 课程设置与术语表；`/` 按关键词筛选题组；`Tab` 在「题组」和「草稿/失败任务」间切换。
- **关于 `m:` 题组管理二级按键（怎么进、怎么退）**：
  - 在学习库选中一个题组后按 `m`，会弹出 **题组管理弹窗（DeckManageModal）**。
  - 在弹窗内：`Space` 多选卡片（支持批量），`F` 批量设重点、`S` 批量暂停、`T` 批量改主题、`L` 批量关联前置题、`X` 批量斩题、`+` 题组补题、`k` 转换题型、`C` 改所属课程、`n` 改题组名。
  - 按 `Esc` 退出题组管理弹窗，回到学习库。
- **易误按键**：`a` 在本页是**归档/取消归档题组**（带确认），不是跳到「音频转写」（侧栏会自动隐藏 `a` 提示）；`[` / `]` 在本页是上下调整题组顺序。

### 4.2 `r` 刷题复习（Review）
- **干什么**：FSRS-6 间隔复习主战场，支持单选/多选/判断/填空/简答/闪卡全题型与全套 AI 助学工具。
- **最常用操作**：见 [第 3 节 刷题页详解](#3-刷题页详解每个键的作用ai-抽屉与自评-05)。本轮小结页支持 `w` 重练错题、`d` 本轮 AI 复盘点评、`R` 再来一轮、`b` 返回学习库。
- **易误按键**：结束本轮练习是 **`X`**（带二次确认）；按 `q` 是退出整个 TUI（同样带二次确认）。

### 4.3 `2` 资料与阅读器（Sources / DocumentReader）
- **干什么**：管理讲义/教材/PDF/课件，内置分页文本阅读器，记住每份资料的上次阅读页码。
- **最常用操作（资料列表）**：
  1. `i` 导入本地资料（`Tab` 自动补全路径）；`Enter` 打开阅读器。
  2. `g` 用选中资料去出题；`G` AI 课程归类；`V` 查看引用覆盖率与关联题卡。
  3. `F` 文件夹筛选、`m` 移至文件夹、`e` 重命名资料、`c` 修改所属课程、`Space` 多选批量操作、`M` MinerU 扫描件/长 PDF 规划、`R` 重读清单、`x` 导出资料目录。
- **最常用操作（阅读器内）**：

## 6. 鼠标点击与滚轮支持

- **Alt 兼容原则**：**Alt+点击 = 鼠标操作；普通点击保留终端选择**（复制、拖选不中断，滚轮滚动照常生效）。
- **如何开启与切换**：
  - 启动时加 `--mouse` 或设置环境变量 `STUDYHUB_TUI_MOUSE=1` 开启 SGR 1000+1006 上报；用 `--no-mouse` 可完全禁用。
  - 默认仅 **Alt+左键点击** 触发 TUI 动作，普通左键点击一律忽略，不干扰终端原生文字选择/复制。
  - 如希望普通左键点击也直接生效，启动时加 `--mouse-alt=0` 或设置 `STUDYHUB_TUI_MOUSE_ALT=0`。
- **支持 Alt+点击的区域**（全部操作均有等价键盘方式，危险操作照旧走确认框）：
  1. **侧栏**：点击任意页面或「继续练习」立即跳转。
  2. **所有列表行**（题组、资料、错题、任务、草稿、命令面板等）：点一下选中，再点一下打开（等价回车）；滚轮上下滚动。
  3. **刷题页**：点击选项作答、点击「翻开答案」、点击 FSRS 0–5 自评档、点击底部 `[h]讲解` 等功能标签、点击 AI 抽屉里的推荐追问或输入框。
  4. **弹窗与确认框**：点击「确认」「取消」按钮或右上角 `esc ✕` 关闭；弹窗打开时点击外面不会点穿下面的页面。
  5. **顶栏与页签**：点击课程、收件箱、模型、帮助/命令，以及设置页的 4 个页签。

## 7. 命令行参数（无头快路径与备份导出）

以下命令**不启动交互式界面、零模型调用**，适合脚本化检查与日常快查（均支持 `--json` 机器输出和 `--ascii` 纯字符模式）：

| 命令参数 | 干什么 / 输出什么 |
| --- | --- |
| `--doctor` | 检查终端环境、色彩能力、Unicode/ASCII 策略、终端能力矩阵（tmux/screen、OSC 52/8/2/9、DEC 1004 焦点上报、6 套主题）、学习库绑定状态与各模型提供方就绪状态（绝不泄露 API Key） |
| `--stats` | 离线输出学习库总览统计（课程数、题组/题数、今日到期、掌握度分布） |
| `--due [--course 课程名]` | 按题组列出今日到期复习队列汇总 |
| `--board [--course 课程名]` | 直接读取 `tui-board.json` 输出三列待办看板与番茄钟摘要 |
| `--search <关键词> [--limit N]` | 离线关键词搜索题库题目与资料正文 |
| `--export [相对路径]` | 一键原子化导出整个学习库 JSON 备份。**导出位置**：严格保存在 `<学习库根目录>/backups/` 下（默认文件名 `studyhub-backup-YYYY-MM-DD-HHmmss.json`） |
| `--root <路径>` / `--library <路径>` | 指定学习库目录 |
| `--page <id>` / `--theme <id>` / `--lang <zh\|en>` | 启动时指定默认进入的页面、主题或语言 |
| `--mouse` / `--no-mouse` / `--mouse-alt=0` | 启用/禁用 SGR 鼠标；默认 Alt+点击生效、普通点击保留终端选择，`--mouse-alt=0` 放开普通点击 |
| `--ascii` / `--unicode` | 强制开启或关闭纯 ASCII 边框与图标模式 |

## 9. 与插件版 / 桌面版的差异

- **共享同一份本地学习库数据**：学习库目录结构、题组、FSRS-6 进度、资料、复习全书、知识骨架、错题本、笔记均与插件版/桌面版兼容互通。
- **纯终端适配差异**：
  1. **录音采集**：终端不调用系统麦克风现场录音，请在「音频转写（`a`）」导入已有录音文件或字幕文件。
  2. **数学公式与图表**：终端用内置 LaTeX → Unicode 渲染器（`m` 随时切原始 TeX）与 Unicode/ASCII 终端图表展示，无浏览器 Canvas 依赖。
  3. **PDF 渲染与原页预览**：TUI 阅读器提供高性能分页文本阅读、页内搜索、高亮/批注与双语翻译；原文件附件可在 `2` 资料 → `O` 管理。
  4. **无插件主会话**：插件版「发给主会话」的能力，在 TUI 中由各 AI 结果页底部的统一 **「接下来想做什么（`a`）」** 对话框承接，可直接基于当前结果继续下指令并一键存追问/笔记。

## 10. 常见疑问（FAQ）

**Q1：为什么按 `a` / `t` / `n` 有时候不是切换侧栏页面？**
A：当前页面有局部功能占用了该字母（例如学习库 `a` 是归档、错题本 `t` 是分流）。此时侧栏会自动隐藏该键提示避免误导。想切页面可按 `Ctrl+K` 输入 `:页面名`、用 `[`/`]` 切页或开启 `--mouse` 直接点击侧栏。保留键 `r`（回题目）、`q`（退出）、`?`（帮助）永远不会被覆盖。

**Q2：为什么「AI 帮我理解」里按 `R` 才会重新生成？**
A：为了省模型额度并加快速度，同一道题已保存过的讲解或本轮已生成的讲解会自动复用；只有你确实想换一版讲解时再按 `R` 重新生成。

**Q3：开了 `--mouse` 后终端里怎么复制文字？**
A：按住 `Shift` 键再用鼠标拖选即可复制；或直接不加 `--mouse`（或加 `--no-mouse`）启动。

**Q4：Windows PowerShell 5.1 里边框乱码怎么办？**
A：TUI 会自动检测旧版 conhost 并启用纯 ASCII 模式；也可手动加 `--ascii` 或设置 `$env:STUDYHUB_TUI_ASCII = "1"`。推荐使用 Windows Terminal 获得最佳真彩色与 Unicode 体验。

**Q5：为什么输入框里按 `Enter` 没提交（多行编辑器）？**
A：多行编辑框（如费曼复述、笔记编辑）里 `Enter` / `Ctrl+J` / `Shift+Enter` 是换行，提交请按 **`Ctrl+S`**。
