## Implementation

`runtime.pilot.audioSingle` defaults false and routes only new public single-file imports. Ordinary manifests remain v1; existing legacy/managed attempts retain their executors and policy when the switch changes. Audio registers one definition on a real Cordis scope. Current legitimate request services bind execution; cold reads cannot manufacture an Agent. The native DSH controller remains the physical executor (DSH-01/03/09); `work.jobs` remains the sole business Job table.

Optional generic admission, trusted presentation, set-control and private binding ports implement the published contract. The domain reuses the actual audio gate, existing per-recording text pool, pipeline, cache, upload registry, deterministic source writer and notifier. Pausing drains admitted windows, saves validated cache references and releases the physical Attempt; resume starts another native handle. Terminal observers include durable domain delivery bookkeeping while physical leases drain independently. Failed presentation/cleanup hooks now converge to one failed terminal event rather than stranding shutdown.

Pipeline checkpoints preserve original non-secret cache settings and adjustable control values. They validate input/context identity, actual cached file bytes/digests and containment, including Windows absolute paths. Usage-cache writes do not invalidate the completed-output checkpoint. Existing prepared-artifact checkpoints remain compatible. Publication uses the existing guarded writer and S1-5 reconciliation.

The existing gateway supplies Call labels, native child linkage and bounded output sinks (DSH-04/05/07). Actual host testing found that child stream subscriptions must be attached to the root event scope; parent-local subscriptions missed the child output. Cached units are skipped producer observations, never requests or charges. No public console component was changed.
