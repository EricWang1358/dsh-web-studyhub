# S6-7c：按音频任务种类展示详情

## 接手与范围

2026-10-07，Codex 接手 `codex/runtime-s67c-audio-detail-wip`，已合并基线 `fceafd60`（#361、#362、#359、#363）。前置交接见 [s6-handoff.md](s6-handoff.md) §3.2.1。原有 WIP 含请求摘要、时间线图例与测试，本轮补齐文件面板并验证整条详情链。范围为 `ui/tasks/` 对应详情组件、英文文案及控制台测试；不修改运行时契约、持久化和 23 个迁移开关。

## 实现前的界面设计

沿用现有两列详情布局、文件行宽度与底部固定高度的信息条，不新增面板。

| 任务 | 请求摘要与时间线 | 文件阶段条与底部计数 |
|---|---|---|
| 单文件导入、批次 | 转写、校对、翻译 | 三阶段 |
| 字幕导入、课堂保存 | 校对、翻译；不声称请求转写服务 | 两阶段，均分原有阶段区域 |
| 字幕复查 | 校对 | 一阶段，占原有阶段区域 |
| 课堂校正 | 课堂校正 | 不显示文件标签页，保留正在进行、实时输出与日志 |

普通音频与缺少具体 kind 的兼容记录保留原有三阶段。每条可访问名称和底部计数必须与可见阶段一致。未知用量不补造数字。

## DSH 边界

复用既有任务契约与控制台视图，不新增宿主服务或公共适配器。参照 [DSH 能力表](s1-0-dsh-capabilities.md) DSH-05（DSH 0.2.0-rc.2 的宿主导航边界）与 DSH-07（宿主观测与唯一计量来源）；本次只按已提供的任务种类选择展示内容，不扩大上述能力的已核验范围。
