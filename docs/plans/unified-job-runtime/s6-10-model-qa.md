## 隔离与证据限制

- DSH 0.2.0-rc.2；独立 `DSH_HOME`、临时目录、库和端口 3497。先清理所有继承秘密变量，再仅向私有 DSH 注入目标 provider 凭据。最终定点复验结束后 2413 个私有输出文件精确密钥扫描通过（依赖 `node_modules` 不在该输出扫描范围）。
- 未遇真实额度限制，没有切换 provider，没有调用付费备用线路。公开 `calls` 是宿主或网关观测，不代表含重试/竞速在内的 HTTP 请求总数；未观测的调用数/费用保留 unknown。
- 探针有两次修正：等待宿主可观察会话建立；将误匹配输入哈希中 `429` 数字的额度检测改成结构化错误字段检测。错误初始输出保留，成功样本没有为此重复调用。
- 该样本量不能证明无 Bug 或普遍质量提升；单段字幕不覆盖真实录音转写、课堂长时校正和音频其余家族。真实冷却参数与满额并发尚未做服务商压力验证。
