# 3.0.0 正式发布执行约定

## 目标与授权

2026-10-07，所有者要求当日交付正式 `3.0.0`，委托代理完成必要修复、合格 PR 合并和发布。这替代此前仅交付 alpha 的版本安排。零缺陷无法从有限测试证明；已知正确性缺陷、失败检查和数据兼容性问题必须解决，未完成的真实环境项目依 [发布政策](../../release-policy.md) 如实列入发布说明。

真实模型抽检使用所有者在 2026-10-07 明确指定的 DSH `commandcode`（CommandCode）provider 订阅额度，遇额度限制停止后续样本，不回退到其他线路或按量收费账户。沿用既有 provider 配置，通过隔离 DSH 的 `ctx.llm` 调用；只读必要配置与该 provider 的凭据引用，仅在子进程环境中使用目标凭据，不输出或另存密钥，不修改所有者学习库和宿主配置。首选已配置的 `deepseek/deepseek-v4.1-flash`，记录实际模型及档位。这里不使用 Claude Code 或 Codex CLI 的账户。

发布负责人为 Codex。集成分支 `codex/studyhub-3.0.0`，基线 `4d04f751112d30387f295d1e590771931fe557d1`，包含已合并的 [#364](https://github.com/EricWang1358/dsh-web-studyhub/pull/364) 与 [#365](https://github.com/EricWang1358/dsh-web-studyhub/pull/365)。本页记录执行约定，不声明已有版本发布。

## 验证契约

- 每个行为修复先记录红灯，再跑受影响公共路径回归。全量测试遵守机器锁，秘密环境变量清理，独立 TEMP/TMP/DSH_HOME。
- 四份现有 `runtime-s27/s37/s49/s57` 回退演练重新运行，旧版固定为真实2.7.1代码，不随版本号改写兼容基准。
- 真实模型质量记录输入、模型/档位、输出评价、耗时、可见请求/用量；未知保持未知。直接运行订阅CLI不能冒充DSH网关及子代理链路；如需桥接，只能复用已核验的宿主适配口作为测试薄适配。
- 候选默认值必须同时覆盖缺省配置与显式false。存量在途任务保留原执行者和策略。
- 本机最终main的 `npm run verify` 全绿；Windows与Ubuntu对最终main的CI全绿；构建与打包的SHA一致。
- 发布说明分别列出已验证与未验证的真实环境项目，包括无法在当日补足的一整天真实使用，不写零Bug保证。

## DSH与范围

复用 [能力表](s1-0-dsh-capabilities.md) 的生命周期、作用域、模型、子代理、会话与宿主UI能力。停止修复只改现有进程边界，测试适配只用于隔离验收；不自建公共任务表、队列、重试或用量账本。

无具体错误证据的按定义retry状态配置、批次重复哈希优化不为版本号抢做。有界调用历史涉及合计、未入账调用和回退形状，需单独契约；缺少长时间验证时不把课堂校正迁移默认开启。
