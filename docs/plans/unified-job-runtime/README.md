## 一句话目标

新增一种普通后台任务时，主要增加任务定义、业务执行器和必要的详情展示；公共查询、等待、控制、计量、恢复与任务控制台直接复用。

## 已定的决策（不要重新讨论）

- 出题类任务重启后要可恢复（P3 交付）。
- 按资源与实际配额域调度，保留必要的资料/草稿写入互斥；翻译不再无条件排在出题后面（单独开关、单独验收）。
- 状态读旧写新：旧 `done` → `complete`；部分结果用 `result.completeness`，不占生命周期状态。
- 暂停按能力开放：`unsupported` / `queued-only` / `checkpoint`（安全边界检查点暂停）。
- 每日总结与学习流目标是子代理优先，统一入口接入后单独开关启用。
- 架构迁移与行为改进分开：先接入并保持原行为，再分别打开恢复、并发与执行策略改进。
