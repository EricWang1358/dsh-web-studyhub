# 陪学 · 自动驾驶 · 定制题（2026-09-15 计划）

目标：做题时不打字也能被带着学；系统暗地里记住学习目标与掌握情况，征得同意后边做题边备好变式题，做完一轮直接给「雷霆建议」；👍/👎 快速反馈自动改题。全程最少 token、不增加负担、界面不卡。

## 省 token 原则

- 陪学调用走「轻量路由」：同一会话模型，思考程度取模型支持的 off/none/minimal，否则 low；限制输出 token。
- 能用代码判断的不用模型：认知层次（记忆 / 概念辨析 / 应用分析）先用规则分类；本轮小结的指标、洞察、下一步先由规则算出，模型只负责一句话和画像摘要。
- 输入只给必要字段并截断：陪学点只用题目自带的答案/解析（已经有原文依据），不传原文；改题和变式题只传引用附近的原文片段（逐字引用校验仍由代码做）。
- 一切结果落盘缓存：同一次答错只生成一个陪学点；本轮小结按已答题数缓存；变式题攒批生成（每批最多 4 个目标）。

## 数据（study-workspace.json，向后兼容）

- `learner`：`consent.prep`（是否允许后台备题）、`goal`（考试/面试/工作/兴趣）、`summary`（≤400 字画像，由小结调用增量更新）、`signals`（懂了/不懂/太简单/太难/👍/👎 计数）、`levels`（模型确认过的认知层次覆盖）。
- `coach[]`：陪学线程（卡片、答错的那次练习、要点、解释、小检查、回复、追问解释、改题通知）。
- `feedback[]`：👍/👎 与标签（题干太空、选项太烂、太简单、太难、答案有误、解析不清）。
- `prepared[]`：备好但未入库的定制题（来源卡、原因、目标层次）。接受后移入系统题组「为你定制」并开练。
- `run.debrief`：本轮小结缓存。

## 动作

`coach.nudge` `coach.reply` `coach.feedback` `coach.consent` `coach.goal` `coach.debrief` `coach.practice` `coach.status`。
答错后服务端预取陪学点（界面请求时直接复用进行中的结果）；同意备题后，答错、「太简单」「太难」和「只练概念」的小结会把目标加入备题批次。

## 界面

- 题目旁「陪学」栏：答错后打字指示 → 要点 + 解释 + 二选一小检查；「懂了 / 还是不懂」一键回复。窄屏落在题目下方。
- 工具栏 👍/👎，👎 展开标签；停手 1.2 秒自动提交；改题完成后在陪学栏通知并可撤销。
- 自动驾驶（可选，本地偏好）：答对自动下一题（可取消的倒计时条）；一轮结束按小结的 `next` 倒计时执行（白名单动作）。
- 小结卡：骨架动画 → 雷霆建议 + 原因 + 「刷 N 道为你定制的题」。
- 快捷键：Enter 下一题/提交/翻卡，H 提示/讲解，G 👍，B 👎（展开后 1–6 选标签），A 自动驾驶，S 从任意页开始/继续学习，? 快捷键帮助，Esc 关闭。
- 性能：陪学请求不占全局 busy；快照轮询带指纹，未变化时服务端只回 `unchanged`；最后一题答完即预取小结。
