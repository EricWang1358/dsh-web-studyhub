# StudyHub 3.0.0 独立端备忘（2026-10-01 调研结论）

本文记录 R1 子代理在隔离环境中**实测验证**过的机制，供 3.0.0 开发参考。2.x 只需遵守[重构计划](2026-10-01-studyhub-overhaul.md)第 8 节的解耦护栏。

- 证据（截图、脚本、外壳 bundle 原型）位于当时的会话临时目录 `scratchpad/audit/R1/`。
- 以下全部基于 **DSH 0.2.0-rc.2**。

## 版本

- npm 的 `latest` 和桌面版都是 **0.2.0-rc.2**。部分机器的 npx 缓存仍是 0.1.0-rc.6，所以启动器必须锁定版本。
- StudyHub 2.0.3 已经依赖 0.2：`dsh.client.inject` 引用的 `@deepseek-ai/dsh-client-store` 只存在于 0.2。
- 0.1 → 0.2 改变了以下机制：
  - 预设改为 bundle 补丁里的一行配置；
  - `bundle.patch` 可以是数组；
  - 新增顶级 `main` 面板；
  - profile 支持 `--from-default-profile`；
  - 桌面版独占 `desktop` profile。

## 组合语义

**叠加顺序**（后面的覆盖前面的）：
1. profile 根目录的 `cordis.yml`（始终为 `[]`）；
2. `dsh.profile.bundles` 中的各个 bundle，按声明顺序；
3. profile 的 `cordis.patch.yml`，即用户层，设置界面写在这里；
4. `$DSH_HOME/cordis.patch.yml`，对所有 profile 生效，启动器绝不能写它；
5. `--patch` 覆盖层。

**补丁操作只有两种：**
- `insert`：插入到根或某个分组；
- 按 id 覆盖字段：`config` 整体替换，不做深合并；也可以设 `disabled`。

没有删除和重排操作。外壳的默认值必须放在 bundle 里，因为放在覆盖层的值无法再从设置界面修改。

## 已验证的定制点

| 能力 | 做法 | 代码 |
|---|---|---|
| 学习模式预设 | 插件在 `dsh.bundle.patch` 里加入 `./presets/study.patch.yml`，插入一行 `@deepseek-ai/dsh-agent-preset`（id `study`）；外壳 bundle 设置 `agent-preset-registry: config: {default: study}` | 预设文件随插件发布（2.x 已做） |
| 个人学习库 | `daily-flashcard` 的配置项 `libraryRoot: !!js dshHomePath('study','library')` | 无需改代码 |
| 预置服务商卡片 | 给 `llm-pi-ai` 的 `config.providers` 打补丁（如硅基流动 `api: openai-completions`，baseURL `https://api.siliconflow.cn/v1`；智谱 `https://open.bigmodel.cn/api/paas/v4`；openrouter）。只写 Key 的引用名，新用户只需粘贴 Key | 无需改代码 |
| 默认模型 | `agent-default-model.{provider,model}` | 无需改代码 |
| 隐藏编程界面 | 对 `ui-sidebar-terminal`、`ui-permission`、`ui-cordis`、`preset-ptc`、`preset-minimal`、`preset-cordis` 设 `disabled: true` | 无需改代码 |
| 落地页 | 在根 `main` 键槽注册页面，加 `sidebar.panellist` 入口，启动时调用 `ctx.layout.selectPanel(key)` | 插件提供通用顶级页面，外壳决定是否把它设为落地页 |
| 品牌 | 禁用 `ui-brand-official`；填充 `sidebar.brand.mark` / `sidebar.brand.name`；用 `webServer.tapIndex` 改 favicon；用 MutationObserver 维持页面标题 | 只放在外壳包里 |
| 默认工作区目录 | `workspace-controller.documentsDirectory` | 无需改代码 |

**无法通过配置修改的：**
- 首页文案；
- 页面标题，需要在客户端持续改写；
- 身份行 “You are an AI agent powered by DeepSeek Harness.”；
- 预设名称的多语言版本。

## 分发路线

| 路线 | 体积 / 前提 | 结论 |
|---|---|---|
| 官方桌面版 + 在 `desktop` profile 里装插件 | 安装包 Windows 289 MB / macOS 374 MB，有 DeepSeek 签名 | 插件版即是这条路。桌面版不能启动其他 profile（profile 名、端口 19387 都写死，且有单实例锁） |
| **桌面版自带运行时 + 独立的 studyhub 网页 profile** | 无需安装 Node；`resources/runtime/cli/bin/dsh.cmd --profile studyhub --port <p>` | **推荐**，已在 Windows 实测。macOS 路径为推断，尚未验证 |
| npm 网页路线 | 约 520 MB `node_modules` + 93 MB profile；需要 Node ≥ 22.19 和 pnpm | 没有桌面版时的后备方案 |
| 从 DSH 源码构建品牌版 | 需要几周工作量，外加签名、公证和持续跟进上游 | 不建议。名称不能使用 “DeepSeek Harness” |

## 3.0.0 架构草案

| 层 | 内容 |
|---|---|
| 共享插件 | 全部学习功能、学习模式预设、通用顶级 StudyHub 页面、不依赖会话的学习库通道、读取外壳配置行、音频密钥通过 `ctx.credentials` 读取（一个硅基流动 Key 同时用于对话和转写） |
| 外壳 bundle `@studyhub/standalone` | YAML 配置：默认预设、`libraryRoot`、服务商卡片、默认模型、`documentsDirectory`、隐藏编程相关的行；外加一小段品牌代码（只在这个包里） |
| 启动器 | 优先使用桌面版运行时，否则用便携 Node + 锁定版本的 DSH。数据目录用独立的 `~/.studyhub`（用户已在 D2 决定）：会话、工作区注册表和凭据都是按目录隔离的，不是按 profile。首次运行时从 web profile 创建 studyhub profile，并添加插件和外壳 bundle |

新用户首次使用约 4 步：
1. 安装 DSH 桌面版（已装则省略）；
2. 运行 StudyHub 启动器，直接打开 StudyHub 落地页；
3. 粘贴一个 Key；
4. 开始。

## 已知风险与待验证

- **0.x 接口变化快。** 在 CI 中锁定版本，跑 `--dump-config` 快照和 Playwright 端到端测试。
- **`config` 是整体替换。** 外壳的标记要放在独立的配置行里，不要在外壳中复写 `daily-flashcard` 的配置。
- **主区域的 Study 视图会被 DSH 对话输入框遮挡底部。** 2.x 的 WP2 负责修复。
- **待验证：**
  - 在模型设置页编辑 bundle 声明的服务商时会写入什么；
  - 通过 `credentials.config.path` 共享 Key；
  - 硅基流动和智谱的模型 id；
  - 下载的脚本在 macOS Gatekeeper 和 Windows SmartScreen 下的表现。
- **测试隔离（重要）。** DSH 读取凭据时，继承的环境变量优先于 `$DSH_HOME/.credentials.yaml`。在 Windows 上用 `--host 127.0.0.1` 会弹出系统原生的文件夹选择框。测试时必须清除 `*_API_KEY` 类环境变量，并设置 `SSH_TTY`。
