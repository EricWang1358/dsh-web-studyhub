# 出题前后自查

范围说明（2026-10-03）：下面的生成、自查、独立验收适用于内置资料出题及显式审阅发布路径。当前草稿界面默认快速发布，不等待模型复审；不能把本篇的审阅保证套到每份外部 JSON 或默认发布操作上。

quiz、multi、flashcard、open、cloze 和混合题型的资料生成（含 PDF 转题目）每批最多 5 题；专用 case 试卷流程保持原有行为。每个资料组先共享一次提取，之后最多 3 批并行：

1. 提取知识点与原文：先找有价值的事实、规则、机制或边界，并逐字引用支持它的原文；这一步不写题目、情景或干扰项。程序先核验引用确实存在于所选资料，才允许继续。资料只支持较少知识点时保留有效部分，请求题数是上限，不是必须凑满的配额。
2. 确定答案与情景：逐个知识点先给出具体答案及可检查的推导，再补齐必要情景条件，以及对应题型的选项、评分标准或填空。虚构教学情景必须明确列出假设，不能补造学科事实；缺乏应用依据时改成有依据的回忆任务或跳过。程序在写题前检查答案结构。
3. 写题并自查：同一次作者调用完成题干、提示、题解和主动改稿。每题必须显式绑定已核验的知识点；程序沿用该知识点的目标、引用、答案与评分字段，缺失、未知或重复绑定不能通过。本地再检查结构、引文、泄题和可见背景。
4. 独立验收：新的调用同时看到资料、知识点、答案方案和改稿，逐题检查自足性、泄题风险、选项质量、学习价值、证据支持、题解教学质量，并检查原文是否实际支持答案和决定性情景条件。题解必须说明条件如何导向答案、关键推导与易错边界；只复述答案或贴对错标签不能通过。缺少逐题记录，或任何维度失败，都不能通过。
5. 只保留通过的题，并记录准备阶段的遗漏与被拒题目的原因。正常生成与补题不自动修题、重复独立验收或为了凑数量追加生成；无法安全定位到具体题的批次问题不能忽略。

正常为每资料组 1 次共享提取、每批 3 次模型调用（答案与情景、写题与自查、独立验收）。提取与答案准备各允许一次纠正，仍可保留有效部分；作者另有有界的格式恢复机制。原生子代理条件满足时，各阶段出现在生成任务记录中；其他环境明确显示直接模型调用。草稿保留知识点、答案方案、遗漏原因、主动改写和验收记录。

每张生成题会记录审阅时的内容指纹；编辑后草稿立即显示审阅已失效。内容不完整的题可以保存在草稿中，发布时逐题做结构校验。选择显式审阅发布且模型可用时，会独立复审修改、新增及旧版没有指纹的题；默认快速发布不等待这一步。批量审阅的问题无法定位到具体题，或整批请求失败时，会逐题复审，避免一题拖住整批。通过的题目先发布；确定有缺陷的题留在待处理草稿。单题模型请求失败属于未完成审阅，结构合格的题可带“未自动审阅”标记发布，修复模型连接后可通过编辑题组并再次选择审阅发布完成复审。用户可选择启动后台修题，逐题修复并独立复审，之后再发布到原题组；缺少引用的题会使用原生成资料，单资料草稿会使用该资料，找不到来源时明确要求先选择资料。后台修题会看到目标题组的已有考点；改稿有内容缺陷或与已通过、已发布题目重复时，带着具体问题再改一次，第二稿仍需独立复审，失败则继续留在草稿。用户手动修改待处理题后，保存会移除该题上次的失败结论；再次发布时才会按新内容检查，后台修题不能接收尚未保存的页面编辑。模型不可用时仍允许离线发布，但会明确显示并保留未自动审阅题数。

规则针对实际失败案例：不同维度的荒谬干扰项、题干或提示抄出答案、依赖未展示幻灯片、只问图上括号位置，以及用原文未支持的概念区分包装成“应用题”。基础闪卡仍允许简洁回忆，不要求每题都写情境。PDF 文字位置不证明图表语义。

作答前的卡片数据不再返回学习目标和评分标准，防止其中包含答案。原始元数据保留；评分标准在揭晓后可用。

本流程用于 generate；ingest 保留用户已有题目的措辞，不自动改写导入题库。不要在对话中生成一批题后用 ingest 绕过生成验收。既有题目需要单独修改，不会因更新插件而被改写。

验证包含阶段顺序、所选资料范围内的引文检查、稳定知识点绑定、答案准备、自查改稿被采用、漏检/泄题验收失败、不可见幻灯片依赖、取消及作答前字段隔离。模型输出采用测试适配器，尚未测量新流程的真实模型首次通过率；规则和独立审阅不能证明事实必然正确。

## 历史记录

2026-09-14 实际运行确认：三次中止均发生在约 180 秒，触发的是生成阶段自身的超时。生成专用时限现为 10 分钟（普通教学调用不变）；一次性子代理、可通信子代理及直接生成调用使用相同上限。超时不当作内容质量不合格。修复后子集验收最多额外一次模型调用，仍不保证达到请求数量。


2026-09-20：修复后不再采信修复者的自评；验收记录升级到版本 3，必须包含 explanationQuality。新增生成阶段的答案原样复述拦截。独立验收接收请求的岗位、难度和重点。旧题不会自动被改写；揭晓题解后可点“重新讲清楚”，直接生成并保存针对本题的补充讲解，无需先生成追问建议，复习进度保持原有行为。补充讲解须标明证据不足或原题错误，不能为了维护原答案编造理由。

## 课程覆盖与学习证据（规划，尚未实现）

题目内容合格、资料覆盖完整、学习者能力通过是三个独立结论。题目审阅通过不能证明课程没有遗漏，也不能证明学习者会迁移或实操。
拟新增的验收任务绑定稳定知识点及目标版本、必需 rubric 项和任务族；服务端记录提示/答案暴露，按实际提交生成分维度证据。关键词分类为“应用”、重复同题、自评、间接前置加分和生成笔记均不能直接验收核心点。
模型审阅缺项、不可用或依据不足时记录未评估；不以默认通过或默认不懂代替。真实模型样本应与人工标准对照，分别记录误通过和误拒绝。
人工盲评确认的实质误通过必须修复，并用原失败及独立样本复核；未解决时，受影响评分路径只能提供候选/支持性反馈，不得发放已验收证据。延迟回忆还要跨题检查该知识点最近一次讲解、提示或练习时间，防止刚重学后换题答对被当成记忆保持。
