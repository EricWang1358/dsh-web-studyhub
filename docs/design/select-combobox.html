下拉选择：Select 与 Combobox

已定（2026-10-06）：① Select / Combobox 基于 Base UI；② 图标整套换成 Phosphor Light；③ 内置 Inter，只覆盖数字和拉丁字母；④ 第 ⑥D 节的浮层细节（内高光、双层阴影、同心圆角）统一推广到所有浮层、卡片和对话框。

用 Base UI 的行为层（键盘、焦点、无障碍、定位、碰撞翻转）替换 16 处原生 <select>。外观全部来自现有 token：弹层就是 .sh-menu 那张 raised 面板，触发器就是 .sh-input。不新增颜色，不使用朱砂色（每屏唯一的主按钮保留给真正的主操作）。下面每块画板都是真实 token 渲染的。

⑥ 美观：哪些地方值得借助成熟方案 四组对比，全部真实 token 渲染

Base UI 只管行为，不带任何样式。界面好不好看，取决于下面几处：前三处可以直接用成熟的开源资源，第四处要靠设计功夫。

A. 图标 20px，深色桌面，同一颜色

现有 43 个手绘图标，风格统一，但数量少，新功能经常只能临时内联 SVG（页面里已有 11 处）。Lucide 与现有图标同为 24px 网格、圆角端点，描边设成 1.6 后几乎可以无缝替换，图标数量 1500+，ISC 许可，按需打包每个约 0.3 KB。Phosphor 有细、常规、双色等 6 种粗细，更有性格，但线条语言和现有图标不同，需要整套一起换。

⑦ 规格

组件与 API

  • ui/components/Select.jsx：选项少、无需搜索时用；可用 items 或分组。
  • ui/components/Combobox.jsx：可搜索，支持分组、章节层级、底部动作（设置、新建）。
  • 沿用 Field 的 label / hint / error 接线，调用方式和现在的 Select 一样。
  • Base UI 只在这两个文件里出现；其余页面只认 ui/components。

键盘与无障碍

  • ↑↓ 移动，Enter 选中，Esc 关闭并把焦点还给触发器，Home/End 跳首尾。
  • Select 支持直接打字跳转（type-ahead），和原生一致。
  • role=listbox / option / group，章节用 aria-level 表达层级，不再读出空格。
  • 底部动作是独立按钮，方向键翻选项时碰不到。

动效

  • 弹层：从触发器方向 scale(.97)→1 + 淡入，--dur-fast，只动 transform 和 opacity。
  • 箭头旋转 180°；关闭不做动画。
  • prefers-reduced-motion 下全部关闭。

宿主适配

  • 弹层挂在 .study-app（在对话框里时挂到打开的 <dialog>），沿用 Menu 的 placeInHost 处理界面缩放。
  • CSS 走现有 useComponentCss 注入，归入 study.components 层，过 token 守卫测试。
  • React 继续由宿主提供；Base UI 按需懒加载，三件合计约 65 KB gzip。

范围

  • Combobox：课程切换（CourseHeading、WorkflowScope 换课程）、题组选择（Ingest、JsonImport、Manage 合并）。
  • Select：其余 10 处短列表。
  • 原生 date / range 本次不动。
  • QA 脚本里对原生 select 的 selectOption 改成点选，测试同步更新。
