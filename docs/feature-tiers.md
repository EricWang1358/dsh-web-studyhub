# 功能分层：什么时候用

更新日期：2026-10-02。起因是用户的一句话：「现在学习步骤已经逐渐明朗了，哪些是一门课程的一开始的几乎一次性功能，哪些是天天要用、次次要用的」。本文把 StudyHub 的每个入口按**使用时机**分层，标出今天放错层的东西，并记录这次按层调整了什么、没调整什么。它不删除任何功能、路由、快捷键或已记录的用户决定。

## 依据

分层只用产品结构和已记录的反馈，没有编造使用数据：

- [用户建议收集表](user-feedback-intake.md)：F-005/F-006（打开先看当前课程和新题）、F-009 与 F-024（资料→出题是主流程，JSON 导入是第二入口）、F-010/F-011（做题页只留常用，低频放进「更多」）、F-023（不写死「当前课程」限制，别的课程用标签说明）、F-027/F-028（防蠢：先设置再用、每个操作有反馈）。
- [体验重构计划](plans/2026-10-01-studyhub-overhaul.md)：P08/P10/P11/P12（空库首页引向 JSON、上手指引、导航顺序、空库显示高级区块）。
- [学习工作流约定](requirements/studyhub-workflows.md)：学习流是可选的，不是强制模式；答错本身不自动调用模型。
- 新用户走查（2026-10-01 之后）：第一屏先推示例而不是「我的第一份资料」；没有「一本书的首页」；侧栏 12 项；两种互相重叠的学习方式（今日路径与学习流）；七个都叫「掌握」的数字；导入一本转换过的教材要 8–9 步。

## 三层

| 层 | 含义 | 例子 |
| --- | --- | --- |
| **S** 一次性 | 一门课或一个学期开头做一次 | 加资料、转换并分章、为大教材建检索索引、补原文件、出第一批题、设考试日期、画知识脉络、配置模型和密钥 |
| **D** 每天 | 每次学习都要用 | 今日到期与逾期、接着上次、推荐的下一步、薄弱点与错题、读/问/翻译当前章节、笔记、待办 |
| **P** 阶段性 | 隔一阵用一次 | 模拟考试、统计、备份与导出、更新、归档课程、整理题组 |

有些东西每次上课都会重复一次（导入新课件、课堂录音）。它们的**配置**是 S，**使用**是「每课一次」，介于 S 和 D 之间。这次按用户的指示把它们放在「课程准备与管理」组，同时在首页的「整理与添加」菜单里保留了「＋ 添加资料」，见文末「请你确认」。

## 课程准备

首页顶部，只对**当前课程**显示（F-023：不限制，也不替别的课算）。一个组件（`ui/SetupChecklist.jsx`），状态完全从库里算出来（`lib/course-setup.js`，纯函数，不存任何东西，不调用模型），按父课程包含子课程的规则统计（`lib/course-tree.js`）：

| 步骤 | 什么时候出现 | 怎么算完成 | 唯一的动作 |
| --- | --- | --- | --- |
| 加入资料 | 总是 | 课程范围里有资料 | 导入资料（带课程） |
| 转换长教材并分章 | 有超过 300 页还没分章的书，或已经转换过 | 已转换或已有章节 | 去资料页转换 |
| 为大教材建立检索索引 | 课程有大教材，且检索扩展已报告 | 已建好最新索引 | 打开检索设置 |
| 补全原文件 | 有旧版导入、没保留原文件的 PDF | 没有这样的资料 | 去资料页处理 |
| 出第一批题 | 总是 | 课程范围里有题组 | 用这门课的资料出题 / 检查并发布草稿 |
| 设定考试日期与目标（可选） | 已有题组，且课程有记录 | 有考试信息 | 设置考试信息 |
| 画出知识脉络（可选） | 已有题组 | 有覆盖该课题组的知识骨架 | 生成知识骨架 |

三种样子：**卡片**（课程正在准备，且首页不是首次空库）、**一行**「课程准备 4/5 · 查看」（核心步骤已完成、或课程已经在用、或首页的首次引导卡在带头）、**完成提示**（全部完成时说一次，之后消失）。每一步有「稍后」，记在本机，不计入 n/m；全部推后也不会显示「完成」。它从不挡住任何东西，也不加第二个主按钮（`ui/DESIGN.md`：每屏一个实心主按钮），下一步只用序号高亮标出。

有一个例外：另一个课题组还在被用的库里新建一门课，卡片上的「出第一批题」和首页今日卡的「接着做」同屏出现，这是 F-023 的结果（最近没做完的练习不分课程，永远在主卡）。

## 数字的说法

走查发现首页有七个都叫「掌握」的数字。它们不是七个分数，是同一批题的不同侧面。这次没有发明新分数，只统一说法，悬停说明在 `ui/mastery-terms.js`：

| 说法 | 数的是什么 |
| --- | --- |
| N 题到期 | 到了复习时间的题（含已逾期的）；复习不调用模型 |
| 学过 | 至少答过一次的题 |
| 已掌握（间隔复习累积） | 复习间隔累积到 3 周以上，或你自评「轻松」 |
| 薄弱 | 最近一次答错、或自评没记住 |
| 未学 | 还没答过 |
| 掌握度 | 按级别折算再平均（未学 0、薄弱 15%、学习中 45%、熟悉 75%、已掌握 100%），不是正确率 |

「掌握度」只指上面这一个数字（首页、资料、阅读器都用它）。统计页的数字各有自己的名字，同样写在 `ui/mastery-terms.js` 的 `MEASURES`，作答少于 3 次的比率显示「数据不足」，不显示百分比：

| 说法 | 数的是什么 |
| --- | --- |
| 达标率 | 近 30 天的作答里得 3 分及以上的比例，客观题和自评合在一起，按认知层次或题型分开看 |
| 客观题通过率 | 同一个比例，只算自动判分的作答（单选、多选、填空、考试） |
| 自评达标率 | 同一个比例，只算自评的作答（闪卡、开放问答） |
| 客观题答对 / 自评达标 | 某一轮练习里的题数（不是比率），同样分开说 |

## 没有做、不应该声称做了的

- 「一本书的首页」：只有课程级的准备清单，没有每本书一页。
- 「两种互相重叠的学习方式」（今日路径与学习流）：没有合并。学习流仍然是可选的，只是上移到「每天」。
- 「导入一本转换过的教材 8–9 步」：转换流程本身没改，步数没变；课程准备让它更容易被发现，但不缩短。
- 首屏点击数：从空库到第一道生成的题仍是 5 次点击，同课程加新资料出题仍是 2 次，接着做仍是 1 次（`scripts/qa/steps.mjs` 在 2.4.0 和这个分支上各量了一遍，结果相同）。变化在首屏要选的东西：欢迎页的主按钮从「载入示例」变成「导入我的第一份资料」；首页的「继续」从最多三处变成一处。

## 请你确认（改变了行为的地方）

1. 「资料」「创建题组」「音频转写」「课堂实录」按你给的分组放进了「课程准备与管理」，行变矮变淡。但导入每周新课件、课后录音、再出题其实每课一次。这四个入口是否应该回到「每天」？首页「整理与添加」菜单里的「＋ 添加资料」已经保留。
2. 首页的整块「为你定制」卡片没有了，变成「其他开始方式」里的链接；侧栏那一行没动。
3. 「课程下一批」「先讲后练」「到期复习与巩固」三条链接折进「其他开始方式」。首次空库首页的链接（添加资料、导入 JSON 题组）没有折。
4. 欢迎页的主按钮换成「导入我的第一份资料」，示例是一行链接（走查的建议）。已载入示例时的欢迎页没动。
5. 设置页分组、默认关着；老用户打开设置会看到两行标题而不是整页。
6. 侧栏每行的相对位置变了（见 A）。三个组名要占纵向空间，所以收窄了品牌区、栏顶内边距和底部状态行的留白；900px 高的窗口刚好放下。更矮的窗口（这在 2.4.0 里就已经放不下底部）可以把两个下组收起来，这是最直接的办法。
7. 英文 UI 里「掌握度」写作 Mastery，「全学习区」改称「所有课程」；第三个组名的英文是 Setup & manage（原样写进去侧栏放不下）。

## 2.5.3 的决定（所有者让我决定）

- **资料、创建题组放回「每天」。** 每周都会来新讲义，导入它、再从它出题是每天学习循环的一部分，不是每门课开头做一次的事；放在「课程准备与管理」里会让每周多点一次折叠。音频转写、课堂实录只有录课的人才用，知识骨架开头做一次，仍留在「课程准备与管理」。已经保存过侧栏顺序的人，组成员按默认值重新归位，组内顺序保持。
- **首页「为你定制」不恢复整块卡片。** 它需要先有一份学习者画像才有内容，对大多数人是空的大块；保留为「其他开始方式」里的一条链接，侧栏行不变。等「使用频率记录」里有真实数据，再按数据重新评估。
