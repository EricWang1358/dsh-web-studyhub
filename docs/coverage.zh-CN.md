# 每份所选资料都出题（覆盖 · 流程 A）

本文为 [coverage.md](coverage.md) 中“Every selected material gets questions”一节的节选译文；其余章节（覆盖强度、自动多轮、状态与发布后补题等）请见英文完整版。

2026-10-11 的真实情况：一份混合题组要 30 题，只规划了 18 题、留下 8 题，8 段录音里有 6 段（占 60% 的文字）一道题都没有；一次“完整”运行的第 1 轮 29 题只覆盖了 30 个小节中的 2 个。

学习者按 **资料** 来数（`lib/coverage-materials.js`）：一份文档（PDF 的所有页是一份，一段录音的几个分卷是一份）、合并转写里的每段录音（`## N. 文件名`）各算一份，同一文档的不同版本只算一份。

- **规划**：题数不够每个小节时，先保留每份资料最重要的一个小节，再按重要程度保留其余小节。自定义题数少于资料份数时，自动提高到资料份数，并用一行字说明（不弹确认框）。精简模式保证每份资料（不只是录音）至少一个小节。
- **轮次**：第 1 轮先让每份资料都有一个小节，再按重要程度排；放不下时，每份先少问几题，计划总题数随之减少，界面上的数字和实际运行一致。
- **只给题数的出题**（不超过 30 题、不选覆盖强度）：每组页面至少 1 题；一次调用里有多份资料时，提示词要求考点分散到所有资料；模型对整组回答“依据不足”时，改为逐份资料单独规划，仍然没有考点的资料记为“需要补题”并写明原因。题数少于资料份数会自动提高；出题前已被删除的资料会被统计并显示。
- **出题前**：在预估那一行显示「选了 N 份资料，M 份会出题，K 份不会：原因」。只显示，不拦截，没有费用确认。
- **出题后**：草稿页顶部显示「选了 N 份，M 份已出题，K 份没出题」，每份没出题的资料写明原因，并有自己的「补题」按钮：只补这份资料还没有题的小节，作为一个单独的补题轮次运行，不受“反复失败不再自动重试”的限制。引用仍然逐字来自原始资料，审阅标准不变。
- **重点覆盖**（`lib/focus-progress.js` `focusCoverageOf`）：当课程已保存重点知识点时，`coverage.get` 额外返回 `focus: { total, covered, uncovered }`，草稿覆盖摘要显示「重点覆盖 covered/total」并列出还没有题的重点；没有保存重点时不输出空块。
- **按知识点查缺**（`lib/evidence/point-link.js`、`point-rows.js`、`point-report.js`）：`coverage.get { draftId, points: true }`（只有草稿页这样问：它要读整门课）额外返回 `points`，即课程总纲里这份草稿的资料讲到的知识点：多少个、多少个还没有题、最多 30 个没题的知识点（别的知识点建立在它之上的排前面），以及「补这些知识点」一轮要补哪些；没有按清点结果整理的总纲时只返回原因（`no-outline`、`descriptors`、`no-inventory`、`stale`；总纲或清点记录坏了是 `unreadable`，其余照常返回），不会自己开始整理总纲。不提供「补这些知识点」时 `hold` 说明原因：`cannot-top-up`（案例题、修改或修补已发布题组的草稿）或 `planned-rounds`（草稿计划里还有轮次没跑：按知识点补的一轮会占掉计划小节，计划随后会跳过那一轮，所以先等计划跑完）。知识点是这份草稿资料讲到的；草稿自己的题不论它归在哪门课都算。一道题的引文和某个知识点所含条目的已核对位置重叠，就算这个知识点有题；对不上的按所在页算。整门课的题组和草稿都算（「未归位」的题只在未归位里算一次）；总纲按清点结果整理且没有过期时，总纲页的题数、「未出题」筛选和复习全书的「草稿里有题」用同一套对应关系；过期的总纲不做这种对应，各页都按页算。「补这些知识点」发 `generate { resumeDraftId, coverage: { pointIds } }`：每个知识点一项任务（它已核对的原文段落，重叠或相接的合并，前后不加字，这样引用其中任何一句都能记到它名下，最多 6,000 字，标题是知识点名，1 题，20 条及以上的大知识点 2 题），记到包含这段原文最多的小节上，走同一个补题轮次、轮次上限、预估和审阅。草稿处于 `hold`、有不认识的知识点、已经有题的、在草稿资料里找不到原文的，或者超过一轮题数时，整次拒绝。补之前的预估就是这一轮的预估。这一轮会记下 `pointIds`：宿主在这一轮中途停止后，「接着做」会把还没有题的知识点补完。
