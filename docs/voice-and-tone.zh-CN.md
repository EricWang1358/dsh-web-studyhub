# StudyHub 的说话方式

界面里的每一句话都在回答学习者的两个问题：刚才发生了什么，接下来我该做什么。这份手册写给要改界面文字的人：错误、空状态、提示、设置步骤、状态词、回执、横幅和 toast。它不改功能名和按钮名，只管句子。

整体的语气：平实、温和，不卖萌，不说教。像一个靠谱的同学在旁边说话：事情是什么样就说什么样，然后给一个下一步。

## 八条规则

### 1. 先说发生了什么，再给唯一的下一步

学习者读到一句话，应该立刻知道两件事：现在是什么情况，下一步点哪里。只给一个下一步；原因不明就直说不明。

- 之前：出了点问题，请重试。
- 之后：这次没有成功，也没有拿到具体原因。可以再试一次。
- 之前：已重新检查，目前还没有连上。
- 之后：已重新检查，还没有读到可用的模型。在 DSH 里配好后，再点一次「重新检查」。

### 2. 「稍后」「暂时」要有原因或出口

「稍后再试」没有告诉人什么时候、做什么。要么写出等多久，要么写出能点的东西，要么说明真正的原因。页面不会自己重试，就不要说会自动重试。

- 之前：另一个操作还在进行，请稍后重试。
- 之后：上一个操作还没结束，这次点击没有生效。等它结束后再点一次。
- 之前：稍后再试。（模型服务不可用）
- 之后：这是模型服务那边的问题。等一两分钟再试一次，或在设置里换一个模型。

### 3. 状态词在每个会显示它的场合都要是真的

一个状态词会出现在很多页面。写之前先查它在什么条件下显示，别让它在不对的时候说话。

- 之前：正在生成…（顶栏。PDF 转换、音频、翻译、建索引在后台跑时也会显示）
- 之后：后台任务进行中
- 之前：今天已经清空（其实是这个范围里一道题也没有）
- 之后：这里还没有可以学的题

### 4. 被挡住时，说清为什么、怎样解除

按钮点不了、操作做不了，就在旁边说明原因和解除的办法，不要只是灰着。

- 之前：还没有可用的 AI 模型，先完成第 1 步。
- 之后：还没有可用的 AI 模型。完成第 1 步后，这个按钮就能点了。
- 之前：请先归档这份资料，再永久删除。
- 之后：这份资料需要先归档，才能永久删除。

### 5. 用平实的口气，不用命令的口气

不用「请勿」「必须」，不用「您」，只用「你」。陈述事实，把选择留给学习者。

- 之前：必须填写，才能生成。
- 之后：填写主题后才能生成。
- 之前：请手动复制
- 之后：需要手动复制

### 6. 空状态说清楚什么是空的、怎样才会有内容

空状态不是道歉，也不是催促。说出这里是什么，什么时候会有东西。

- 之前：暂无消息
- 之后：信箱是空的
- 之前：还没出题（点「练 5 道」后的提示）
- 之后：这个知识点还没有题。先到「创建题组」从资料出题。

### 7. 不承诺页面做不到的事

写「会自动重试」「稍后可用」之前，确认代码真的会这样做。做不到的承诺比没有提示更糟。

- 之前：学习插件暂时没有连上，稍等一下会自动重试。
- 之后：StudyHub 暂时没有连上。点「重试」再试一次。
- 之前：读取详情失败，稍后再试
- 之后：没能读取这道题的详情。点页面上的「刷新」后再展开一次。

### 8. 用学习者的词，不用系统的词

界面句子里不出现「宿主」「插件」「渲染」「拉取」「缓存」这类开发和运维的词。主聊天窗口只叫「主会话」。

- 之前：学习工作台渲染出错
- 之后：学习工作台没能显示
- 之前：在对话输入框的模型选择器里选
- 之后：用主会话输入框里的模型选择器

## 词汇表

这些词在整个界面里只有一个意思。新文案沿用，不要换同义词。

| 词 | 意思 |
| --- | --- |
| 主会话 | DSH 里和你对话的主聊天窗口。界面里它只有这一个名字。「在新对话中打开」是真的新开一个对话，不是主会话。 |
| 学习库 | 你电脑上的一个文件夹，资料、题库和复习记录都保存在里面。 |
| 题组 | 一组题。 |
| 草稿 | 只指待发布的题组。你自己输入框里写的字、备好等你练的变式都不叫草稿。 |
| 归档 | 把资料或题组收起来，不再参与练习，可以恢复。永久删除之前必须先归档。 |
| 斩 | 把一道题收进「斩题组」：不再参与复习，作答历史和复习进度保留，随时可以恢复到原题组。 |
| 删除 | 永久删除，无法撤销。先归档，再删除。 |
| 为你定制 | 系统自动建的题组，放着根据你的错题和反馈改写的定制题。 |

不要改名的功能和按钮：创建题组、错题与待巩固、发给主会话、复习全书、斩、归档、为你定制。

## 写新文案前的检查清单

- [ ] 这句话说了发生了什么吗？说了唯一的下一步吗？
- [ ] 有没有「稍后」「暂时」「请」「必须」「您」？有，就换成原因、出口或直接的陈述。
- [ ] 它在所有会显示它的场合都是真的吗？去代码里查它的触发条件。
- [ ] 它承诺的事，页面真的会做吗（自动重试、保存、保留）？
- [ ] 被挡住的操作，说了原因和解除的办法吗？
- [ ] 主聊天窗口叫「主会话」了吗？「草稿」只用在待发布的题组上吗？
- [ ] 有没有开发词（宿主、插件、渲染、拉取、缓存）？
- [ ] 保留了所有 `{0}` `{1}` 占位符吗？
- [ ] 英文对照改了吗：每个 `ui/locales/en*.json` 里中文原文那一行都要同步，用旧文案的测试也要改到新文案。
- [ ] 句子读出来像人在说话吗，没有撒娇，也没有训话？
