STUDYHUB 2.5.13 · 安装引导

从安装开始，到自己的学习库

StudyHub 是 DeepSeek Harness（DSH）的学习插件。DSH 可以装成桌面应用，也可以在浏览器里以网页版运行。先装好 DSH，再在 DSH 的插件管理里添加 StudyHub，最后配一个模型用来出题。

已经在用 DSH 桌面版或网页版？保留现有的 DSH、模型和配置，直接在 DSH 中安装 StudyHub。网页版不用下载客户端。

在 DSH 中安装 StudyHub · 在浏览器里运行 DSH · 配置模型 · 更新 StudyHub

Windows

64 位 Windows · 官方 .exe 安装器

下载 Windows 安装器

打开下载的安装器，按提示安装并启动 DSH。桌面版自带运行时。

Linux

官方 npm 网页版 · 无需客户端

使用 Linux 网页版

安装 Node.js 22.19 或以上，启动 DSH 后在浏览器里添加 StudyHub。

macOS

Apple 芯片（M 系列）· 官方 .dmg 安装器

下载 macOS 安装器

打开磁盘映像，按提示把 DSH 放进「应用程序」，然后启动。不用另装 Node.js。

以上链接来自 DSH 官网，下载的是 DSH 本身，StudyHub 在下一步安装。Intel 芯片的 Mac 或 Windows ARM 电脑，请查看官网的支持情况，或改用网页版。StudyHub 2.5.13 适用于 DSH 0.2（0.2.0-rc.2 起，0.3 之前）；DSH 和 StudyHub 的版本号各自独立。

在 DSH 中安装 StudyHub

以下步骤桌面版和网页版通用，原有的模型、工作区和配置都不用动。

  1. 在 DSH 打开「插件」页，点「添加插件」。
  2. 粘贴下方地址。安装完成后，确认包名是 @ericwang1358/dsh-daily-flashcard，版本是 2.5.13。
  3. 点「启用」，启用 StudyHub 和你需要的组件。如果 DSH 提示重新加载，先等后台任务完成或取消它们。
  4. 第一次启用后，StudyHub 会自动打开；之后从 DSH 左栏的「StudyHub」进入，不用先发消息。学习库为空时，点「载入示例并开始导览」，会载入一门示例课程并开始约 3 分钟的导览，不需要模型。

查看 2.5.13 安装包与校验值 · 直接下载 StudyHub 安装包

DSH 无法从 GitHub 下载时，先下载 .tgz，再在「添加插件」里填这个文件的绝对路径。文件必须放在运行 DSH 的电脑或服务器上：访问远程网页版时，你自己电脑上的路径在服务器上并不存在。也可以直接用上方的 HTTPS 地址。

高级：自定义组件

完整安装包包含 7 个组件：StudyHub、StudyHub · 核心、StudyHub · 资料、StudyHub · 题库、StudyHub · 出题、StudyHub · 练习与复习、StudyHub · 音频转写。在 DSH 自带的插件管理里启用或停用。发布页也提供每个组件的独立安装包。

「创建题组」需要资料、题库和出题；练习、「错题与待巩固」「模拟考试」和「统计」需要题库和练习与复习。页面所需的组件停用后，StudyHub 会隐藏这个页面，或提示功能已停用。已保存的资料、题组和学习进度都会保留。停用前先结束相关的后台任务。

删除资料前，先启用题库和练习与复习，StudyHub 才能检查引用了这份资料的题目、草稿和学习记录。如果同一组件由多个已安装的包提供，要在所有包里都停用才算关闭。旧版完整包仍提供全部功能，先升级再自定义。

在终端安装时沿用原来的配置名（dsh web 的配置名是 web）：dsh plugin --profile web add <安装包地址或绝对路径>。桌面版请用插件管理安装；命令行安装必须先完全退出桌面版（包括托盘图标）。

在浏览器里运行 DSH

适用于 Linux，也适用于不想装客户端的 Windows、Mac 用户。安装 Node.js 22.19 或以上，然后在终端运行：

npx @deepseek-ai/dsh web

DSH 默认在 http://127.0.0.1:3080 打开。保持进程运行，然后安装 StudyHub。已经在用网页版的话，跳过这一步。

DSH 官方网页版启动说明

配置模型服务商

在 DSH「设置 › 模型」保存 API Key，然后在会话里选择模型。出题、讲解、「帮我弄懂」、校对和翻译需要模型；示例导览、浏览资料和练习已有题组不需要。

日常使用：DeepSeek 官方 API

在 DeepSeek 开放平台创建 API Key，确认账户可以调用模型，再在 DSH「设置 › 模型」的 DeepSeek 卡片填入并保存。内置的 DeepSeek 卡片不用填写接口地址。StudyHub 默认用会话里选的模型出题；想让出题和讲解单独用另一个模型，在 StudyHub「设置 › 学习库与模型」的「生成模型」里选择。

用量大时：先核对 Coding Plan

只选提供 API Key、并且允许在 DSH 里用于学习的套餐。购买前确认适用工具和用途、专用 Base URL、模型 ID、并发限制和额度重置规则。能创建 Key 不等于允许任意应用调用；有些套餐只支持指定的编程工具。

接入获准的套餐，在 DSH「设置 › 模型」选择「添加模型提供商」。其他接口选「自定义模型 API」，填写 Base URL、API 协议、Key 和模型 ID。套餐的专用接口和普通 API 接口可能扣不同的额度。参见 DSH 模型配置指南。

Claude、ChatGPT 订阅不是 API Key

DSH 目前不支持 Codex 这类 OAuth 订阅登录。Claude Pro／Max、ChatGPT／Codex 的订阅额度不能当作 API Key 填进来；Anthropic 和 OpenAI 单独付费的 API 可以作为第三方服务商添加，费用与订阅分开计算。

Claude 计费说明 · OpenAI 计费说明

录音：另配转写服务

把录音转成文字要另配转写服务，在 StudyHub「设置 › 音频转写」里填密钥。支持硅基流动 SenseVoice、Gemini 和 Groq；可用地区、额度和收费以各服务商的当前说明为准。「课堂实录」的实时转写只支持 Gemini。转写之后的校对和翻译默认使用你在 DSH 会话里选的模型。

本页不收集密钥。模型的 API Key 只保存在 DSH「设置 › 模型」，转写密钥只保存在 StudyHub「设置 › 音频转写」。不要把密钥贴到对话、资料或题组里。

更新 StudyHub

DSH 插件不会自动更新，只重启 DSH 也不会换成新版本。学习库和设置都会保留。

  1. 从 2.1.2 起，GitHub 有新版本时，StudyHub 侧栏会出现「有新版本 x.y.z」提示。点它，再点「一键升级到 x.y.z」和「确认升级」。
  2. 有后台任务在运行时，点「停止任务并升级」会先停止这些任务，已完成的部分会保留；也可以等任务结束后再升级。
  3. StudyHub 按 SHA256SUMS-x.y.z.txt 核对安装包的 SHA-256，再交给 DSH 插件管理安装。
  4. 重启 DSH：桌面版完全退出（包括托盘图标）后重新打开；网页版按原来的方式（同一个配置）重启服务，再刷新页面。只刷新浏览器不够。

2.1.2 之前的版本，或一键升级失败时：在 DSH 的「插件」页「卸载」StudyHub，再「添加插件」粘贴新版本的安装包地址，点「启用」后重启 DSH。开始前先等后台任务完成或取消它们。

StudyHub 最多每 12 小时向 GitHub 查询一次新版本，不发送任何学习数据。可在 StudyHub「设置 › 关于与更新」关闭。

选择中文或英文界面

第一次打开时，StudyHub 跟随浏览器的首选语言：中文浏览器显示中文，其他显示英文。在 StudyHub 侧栏底部的「语言」切换，这个浏览器会记住你的选择。切换界面语言不会翻译已保存的资料、题目、笔记或文件名。
