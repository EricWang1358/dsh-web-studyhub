已有 DSH：仅安装全套插件

以下步骤适用于正在使用的桌面版和网页版。在现有 DSH 的插件管理器安装，继续使用原来的模型与工作区。

  1. 打开 DSH「插件 → 添加插件」。
  2. 复制下方地址到安装输入框，安装完成后确认包名 @ericwang1358/dsh-daily-flashcard、版本 2.5.8，启用工作台和所需组件。
  3. 启用后 StudyHub 会自动打开；之后从 DSH 左栏的「StudyHub」进入，不需要先建会话或发消息。学习库为空时点「载入示例并开始导览」，约 3 分钟看完关键功能，不需要模型。

更新：DSH 插件不会自动更新，只重启不会换成新版本。从 2.1.2 起，GitHub 有新版本时 StudyHub 会在侧栏提示；点「一键升级」会核对安装包的 SHA-256 后交给 DSH 插件管理安装（可在「设置 › 关于与更新」关闭检查）。旧版本：在「插件」里卸载 StudyHub，再「添加插件」粘贴新版本的安装包地址。先结束后台任务，装好后重启 DSH：桌面版完全退出后重新打开，网页版用原配置重启服务。仅刷新浏览器不够。

高级自定义：按需安装、启用或停用组件

全套包含工作台、运行时、资料、题库、学习、生成和音频。在 DSH 自带插件管理器展开安装包，选择所需组件；以后仍在这里启停。发布页也提供独立子插件安装包。

生题需要资料、题库和生成；答题与考试需要题库和学习。停用所需组件后，对应入口隐藏或提示功能已停用。停用前先结束相关任务，已保存的资料、题组和进度会保留。

删除资料前须启用题库和学习，以检查已保存题目、草稿与学习记录的引用。

若同一能力由多个安装包提供，需停用所有来源才能完全关闭。旧完整工作台仍提供整套能力，升级后再自定义。

首次使用：只用 DSH 网页版

适用于 Linux，也适用于不希望安装客户端的 Windows、Mac 用户。安装 Node.js 22.19 或以上，然后在终端运行：

npx @deepseek-ai/dsh web

保持进程运行，默认打开 http://127.0.0.1:3080。随后在网页中安装学习插件。已有网页版可直接跳过这一步。

DSH 官方网页版启动说明 · Linux 当前使用官方 npm 路径。

首次使用：配置模型 Provider

在 DSH「设置 → 模型」保存 API Key，然后在会话中选择模型。生成、讲解、校对与翻译需要模型；安装插件、查看资料和复习已有题组可以先开始。

日常使用：DeepSeek 官方 API

在 DeepSeek 开放平台创建 API Key，确认账户可调用模型；在 DSH 模型设置的 DeepSeek 卡片输入并保存。内置配置无需手工填写 API 地址。

用量较大：考虑兼容的 Coding Plan

选择提供 API Key、且允许 DSH 与学习用途的套餐。购买前确认适用工具、用途、专用 API 地址、模型、并发限制和额度规则。有 Key 不等于允许任意应用使用；有些套餐仅限指定工具。

获准的第三方套餐可在「添加模型提供商」配置；自定义端点需填写地址、协议、Key 和模型 ID。参见 DSH 模型配置指南。

Claude／Codex 订阅不能直接当作 API Key

DSH 当前不支持 Codex 等 OAuth 订阅接入。Claude Pro／Max、ChatGPT／Codex 的订阅额度不能直接填入这里；Anthropic 和 OpenAI 的独立付费 API 可以作为第三方 Provider，费用与订阅分开。
