# Regression repair — 2026-09-14

## Debug Summary

**Problem:** New notebook, exam, action-registry and UI changes passed the original 40 tests but failed concurrency and cross-view scenarios.

**Root causes and fixes:**

- `lib/notebooks.js`: catalog reads happened before acquiring the write lock; lock errors were swallowed and timestamp temporary filenames collided. Concurrent publication lost entries or failed to rename. The entire read/modify/write now holds one lock and uses an exclusive UUID temporary file.
- `lib/store.js`: normalization treated present malformed collections as missing legacy fields. A later settings write could replace existing content with an empty list. Invalid existing shapes, revisions and versions now fail without altering bytes; missing legacy fields still receive defaults.
- `lib/service.js`: plain-object action lookup accepted inherited properties. Only own registered actions now dispatch. Exam card scopes now honor cardId, projections include the persistent start time, and examCount counts only objective choice cards. Substantive edits are refused while that card belongs to an unsubmitted exam, protecting the answer key.
- `ui/App.jsx`: equal revisions/jobs caused snapshots from different roots, different model readiness or different due times to be discarded. Full snapshot comparison now includes those changes, caches the previous serialization and clears root-specific UI state on a root change. Exam resumes route to the selected exam rather than the ordinary review screen.
- `ui/Exam.jsx` / `ui/async.js`: fire-and-forget answer writes could arrive after navigation or submission. A write queue preserves selection order; navigation/submission wait for it, and a failed latest save blocks those operations until a selection saves successfully. Action refs close the same-render double-click gap. The timer effect now follows its submission callback.
- `ui/App.jsx`, `ui/Review.jsx`, `ui/Cloze.jsx`: cloze cards in flashcard mode incorrectly used cloze submission instead of reveal/self-grade. The mode now controls presentation. Restored correct cloze feedback can display the already-revealed reference answer rather than “空 ✓”, without retaining raw learner text.

**Prevention:** Six regression tests added in the existing feature/notebook/store test files. They cover exact exam scope and time, protected answer keys, rejected inherited actions, queued writes and failed flushes, concurrent registry operations, and byte-preserving invalid-state rejection.

**Confidence:** High for the reproduced paths. Tests and browser probes used temporary or explicit demo libraries; real learner libraries were not modified.
