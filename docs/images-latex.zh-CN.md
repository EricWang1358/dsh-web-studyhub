# 学习卡片中的图片数学公式和化学方程式

题干、答案、选项、提示和解析可以显示 Markdown 图片及 LaTeX 公式。公式在本地渲染；显示成功不代表答案或化学反应已经验证正确。

## 输入数学公式

行内公式使用 `$x_i^2$` 或 `\(x_i^2\)`。独立公式使用 `$$...$$` 或 `\[...\]`，可以跨行，也支持 `aligned` 对齐环境。

```text
求满足 $2 x + 1 = 5$ 的 $x$。

\[
\frac{x_i^2}{\sqrt{2}}
\]
```

行内代码和代码块保留原文。`$5 and $10` 这样的价格不会变成公式。公式容易与价格混淆时，使用 `\(...\)`。无效或不支持的 LaTeX 会保留可见原文。

题卡、复习全书、错题与待巩固，以及阅读器里的文本、PDF 文字资料，也能识别从别处粘贴来的写法：`$ F = ma $`（两侧各有一个空格，且里面像公式）、数字后紧跟单位（`5$kg$`），以及不带美元符号的 `\begin{equation}…\end{equation}`、`\begin{align}…\end{align}` 等数学环境。美元符号后带空格的价格（`$ 5 + $ 3`）仍是价格，格式符的位置标记（`%1$s`）也一样。阅读器里导入的 Markdown、粘贴的资料沿用各自的美元符号规则，但走同一个渲染器，下面这些命令对它们生效；「学习笔记」页和讲解文章用自己的渲染器，两者都不认识。题卡渲染器用到的地方，`physics` 和 `siunitx` 宏包里常用的命令（`\dv{x}{t}`、`\pdv{f}{x}`、`\vb`、`\abs`、`\norm`、`\SI{…}{…}`、`\unit`、`\si`，只限普通数字和普通单位：`\SI{1.6e-19}{C}`、`\SI{9.8+-0.1}{m/s^2}` 和带点号的单位仍显示原文）以及 `\mbox`、`\upmu`、`\mathbbm`、`\label`、`\eqref` 会改写成渲染器认识的写法；拿不准的写法（`\dv[2]{x}{t}`、只带一个参数的 `\dv{x}`、`\pdv{f}{x}{y}`、带可选参数或星号的），以及宏包里含义不止字面的命令（`\ev`、`\va`、`\vu`、`\ang`、`\num`、`\qty`，siunitx 的其余命令）不支持，仍显示原文。浏览器不支持原生 MathML（Chromium 109 之前）时，公式显示为它的源码。

## 输入化学方程式

在数学定界符中使用 `\ce{...}`。本地 mhchem 支持系数、下标、电荷、物态及反应箭头；`\pu{...}` 用于物理单位。笔记预览也支持这些化学命令，沿用已有的 `$...$` 和 `$$...$$` 定界符。

```text
$\ce{2H2(g) + O2(g) -> 2H2O(l)}$
$\ce{Fe^{3+} + SCN- <=> FeSCN^{2+}}$
$\pu{1.5 mol L-1}$
```

渲染功能不会配平方程式、检查电荷守恒或验证化学计量。请对照资料核实这些内容。

## 插入图片

使用完整的 HTTP 或 HTTPS 图片地址，并写明图片内容：

```text
![反应能量图](https://example.org/reaction-energy.png)
```

图片会适应卡片宽度。闪卡中的图片可以点击或使用键盘放大；按 Escape 或关闭按钮返回，焦点会回到原图片按钮，卡片不会翻面。选项中的图片直接显示，不增加第二个操作按钮。加载失败时会显示图片说明和不可用提示。

浏览器会从图片地址请求内容，请选择自己有权访问并向学习者展示的图片。当前卡片没有可信的本地附件根路径，因此不支持文件系统路径、相对路径、`file:`、`data:` 或脚本地址。

数学和化学公式使用随应用提供的 MathML 渲染器，不需要 CDN 或字体下载。网络图片是否可用，取决于图片服务器及浏览器的网络规则。
