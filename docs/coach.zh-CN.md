# 陪学、定制题与自动驾驶

陪学围绕做题工作：题目有问题时你可以一键反馈，后台按反馈改题；每轮结束有一张小结，给出一个建议的下一步；你同意后，它还会按薄弱点备好定制题。自动驾驶让你不用点鼠标就能刷完一轮。

练习时只作答不会调用模型。陪学发给模型的请求都走当前会话模型的最低思考档位（见[模型调用与 token](#模型调用与-token)）。

## 一览

| 功能 | 入口 | 是否调用模型 |
| --- | --- | --- |
| 给题目打分 | 做题工具栏的点赞 / 点踩图标，或 G / B | 记录评价不调用；按反馈改题时，每次在后台调用 1 次 |
| 本轮小结 | 结果页的「陪学 · 本轮建议」卡片 | 指标和下一步不调用；答满 3 题后用 1 次轻量调用润色措辞 |
| 定制题 | 侧栏「为你定制」、结果页、「学习库」 | 你同意后按批调用 |
| 答错后的帮助 | 做题工具栏的「帮我弄懂」 | 只在你点了之后调用 |
| 自动驾驶 | A 键 | 不调用 |

## 设置陪学

打开「设置 › 学习画像与导览」，找到「陪学」一节：

- 「做题时在后台准备变式题和应用场景题」：即是否同意备[定制题](#获取定制题)。默认关闭，直到你在这里打开，或在结果页答应。
- 「学习目标」：应付考试、面试求职、工作中落地、兴趣拓展或未设定。陪学的语气和例子会贴近这个目标。
- 「画像」：陪学在一轮结束后写的简短摘要，以及你的反馈计数。画像只影响陪学提示、改题、定制题和每轮小结的措辞与侧重，不影响出题和复习排期。
- 「清空画像」：见[数据与隐私](#数据与隐私)。

## 反馈题目问题

1. 做题时点工具栏的点踩图标（「这题有问题」），或按 B。题目不错就点点赞图标（「这题不错」），或按 G。
2. 点踩后展开标签栏（「哪里不好」）。点一个或多个标签，也可以在标签栏展开时按 1–7。
3. 停手 1.2 秒，选好的标签就会提交。已提交的标签不能撤回。

一个标签都不选也有效：1.2 秒后，这次点踩会作为“检查并修改这道题”的通用请求提交。如果题干只问“资料怎么说”，「只问资料怎么说」会预先选好，提交前你可以取消。

| 标签 | 后台会做什么 |
| --- | --- |
| 「题干太空」「选项太烂」「解析不清」「只问资料怎么说」，或不选标签 | 后台改题，只改被批评的部分 |
| 「答案有误」 | 先对照资料核对。资料支持原答案时不改题，并在信箱里说明依据 |
| 「太简单」 | 开启备题时，准备一道更难的应用题 |
| 「太难」 | 开启备题时，准备一道更基础的前置概念闪卡。开练后，它会被链接为原题的前置题 |

改题和备题都需要会话里有可用模型。没有模型时，评价照样记录。

改题的规则：

- 改稿新增的引用必须逐字摘自资料。回复无法解析或校验不过时，会带着错误信息再改一次。模型调用本身失败时，空回复或临时的服务商错误最多自动重试 2 次；请求超时不重试。
- 每次改完都会在「信箱」里通知。只要这次修改仍是最新版本，就可以点「回退这次改题」恢复原题。
- 改题不会改动屏幕上已有的结果。题目正开着还没作答时，你答的仍是你看到的版本。新版从下一次作答起生效，例如本轮队尾重练或以后的复习。
- 最多同时改 3 道题。同一道题重复提交同一标签不会再改一次；10 分钟内对同一道题追加的标签并入同一条反馈记录。

## 看懂本轮小结

普通练习一轮结束后，成绩下方直接显示「陪学 · 本轮建议」卡片。模拟考试另有考试报告，不显示这张卡。数字和建议都由代码算出，没有模型也能用。

卡片上有：

- 「客观题答对」：单选、多选和填空题答对的数量。
- 「自评达标」：闪卡和开放问答中自评 3 分及以上的数量。
- 本轮题目在记忆、概念辨析、应用分析三个层次上的分布，以及每层达标的数量。
- 几条简短说明，例如这一轮几乎都是记忆和概念辨析题，或者通过率偏低。

两类结果分开计算：自评低分不算作答错，客观题高分也不会掩盖自评没掌握的题。

卡片只给一个下一步：

| 情况 | 按钮 |
| --- | --- |
| 已有备好的定制题 | 「刷 N 道为你定制的题」（N 为实际数量） |
| 本轮有答错或自评低于 3 分的题 | 「先补薄弱点」：只重练本轮低分题，不混入新题 |
| 没有低分题，且答了 15 题以上 | 建议休息，不显示按钮 |
| 没有低分题，不到 15 题 | 「继续学习」 |

建议是刷定制题或补薄弱点时，页面上其他主按钮会改成次要样式，保证一屏只有一个主操作。

有模型且至少答了 3 题时，会用 1 次轻量调用改写标题和理由，并更新你的画像摘要。模型给出的下一步与代码选定的不一致时，它的文案会被丢弃。小结随本轮保存，已答题数不变就直接复用；同时发起的请求共用一次调用。

## 获取定制题

定制题是按你的薄弱点新写的题，经过资料校验，备好后一直保留到你去练。需要会话里有可用模型，并且你已同意。

### 同意备题

下面任一方式都可以：

- 结果页的小结卡会问：「好，帮我备题」或「先不用」。你回答后就不再问。
- 在「设置 › 学习画像与导览」的「陪学」一节打开开关。
- 在「错题与待巩固」点「生成变式」时会先确认，点「同意并生成」即同意并开始。

选了「先不用」，之后仍可以在设置里打开。

### 哪些题会备

| 触发 | 备什么 |
| --- | --- |
| 在结果页选「好，帮我备题」，或在设置里打开备题开关 | 最近答错或自评低于 3 分的最多 4 道题的变式；在结果页同意时，如果这一轮小结需要应用题，也一并加入 |
| 开启备题后，每轮小结 | 为你已通过的最多 4 个主题备应用题。触发条件是：一轮 4 题以上、几乎都是记忆和概念辨析题且已达标；或 2 道以上客观应用题大多答错；或标了 2 道以上「太简单」 |
| 「太简单」「太难」标签 | 一道更难的应用题，或一道更基础的前置闪卡 |
| 开启备题后，在「追问？」里提出新问题 | 一道针对你疑问的巩固题，前提是资料能支持 |
| 「错题与待巩固」里的「生成变式」 | 你所选题目的变式，每次最多 8 道 |

做题时答错一道题，本身不会触发备题。想要错题的变式，请到「错题与待巩固」点「生成变式」。

### 怎么写出来

- 目标先攒一批：最多等 20 秒，或攒满 3 个就发出。每次模型调用最多写 4 道题。
- 变式题是单选题；原题是多选时写成多选。「太难」对应的目标写成闪卡。
- 每道题单独校验：引用必须逐字摘自所引资料，不能和已有题目重复，还要通过常规题目校验。不合格的直接丢弃，不修补。
- 同时最多备 12 道定制题。

### 去练定制题

只要备好 1 道，下面这些地方就会出现入口：

- 侧栏「为你定制」，带数量标记（侧栏收起时显示为图标上的圆点）；
- 结果页小结卡里的按钮；
- 「学习库」页面的「其他开始方式」；
- 「错题与待巩固」顶部的横幅。

开练后，这些题移入系统题组「为你定制」，之后按正常的间隔复习（SM-2）安排。

## 使用自动驾驶

- 按 A 开关自动驾驶。这个设置只保存在本机浏览器里。
- 答对，或自评 3 分及以上后，1.5 秒自动进入下一题。点任意处或按任意键就会停下。答错和自评低分不会自动跳走。
- 普通练习一轮结束后，小结给出的下一步会在 5 秒倒计时后自动执行。点任意处或点「取消」可以停下。建议休息时不会自动操作。
- 从「学习流」或绕路练习（做完会出现返回之前那道题的按钮）进入的结果页，以及带「回到原题」按钮的结果页，都不倒计时，避免把你带离原来的任务。

## 追问讲解

揭晓讲解后，「追问？」里有推荐问题，也可以自己写问题。详见[讲解追问](followup.zh-CN.md)。

- 问答保存在这道题上。
- 开启备题时，每个新追问都可能生成一道巩固题，校验方式与其他定制题相同。关闭备题不影响追问。
- 重新提交已保存的问题会直接复用原回答；同时发起的相同请求共用一次模型调用。

## 快捷键

面板获得焦点、且你没有在输入框里打字时，快捷键才生效。

| 按键 | 作用 |
| --- | --- |
| 1–6 | 选择选项 |
| 1–7 | 点踩标签栏展开时，选择标签 |
| 0–5 | 给闪卡或开放问答自评 |
| Enter | 下一题；提交多选或填空答案；翻卡 |
| Space | 翻卡 |
| ← / → | 上一题 / 下一题（→ 在作答后可用） |
| H | 作答前看提示，作答后看讲解 |
| T | 请后台助教用通俗的话讲这道题 |
| G / B | 点赞 / 点踩 |
| A | 开关自动驾驶 |
| S | 在任意页面继续上一轮或开始今日学习 |
| P | 阅读资料时：做这几页的题 |
| ? | 打开或关闭快捷键速查 |
| Esc | 关闭弹层 |

## 数据与隐私

陪学数据保存在学习库里，不在浏览器里：

| 记录 | 位置 | 内容 | 上限 |
| --- | --- | --- | --- |
| `learner` | `study-workspace.json`（学习库清单） | 是否同意备题、学习目标、画像摘要、反馈计数 | 画像摘要最多 400 字 |
| `coach` | `shards/misc/` | 陪学记录，例如改题通知 | 保留最近 400 条 |
| `feedback` | `shards/misc/` | 你的评价和标签 | 保留最近 400 条 |
| `prepared` | `shards/misc/` | 定制题 | 待练最多 12 道；已用的保留最近 100 道 |

自动驾驶的开关是例外，保存在本机浏览器里。

设置里的「清空画像」会删除学习目标、画像摘要、反馈计数和未使用的定制题，同时重置备题同意，下一次结果页会重新询问。练习记录、复习进度和反馈记录都保留。题目上的追问问答、推荐问题缓存和 EN 翻译不属于画像，也不受影响。

## 模型调用与 token

- 陪学使用当前会话模型的最低思考档位：模型提供 off、none 或 minimal 时选它，否则选 low，再没有就选列表里最低的一档。出题用的「推理程度」设置不影响陪学。
- 只有思考完全关闭时才限制输出长度，避免截断推理：提示 450、陪学回复 320、改题 1,600、一批定制题 3,600、本轮小结 650 token。
- 提示只发送题目本身的答案和解析，不发原文。改题只发送引用附近的原文片段，最多 5,000 字符；一批定制题最多 6,000 字符。逐字引用都由代码校验。
- 认知层次、指标、说明和下一步都由代码计算。
- 面板轮询快照时带上指纹，学习库没有变化时，服务端只回 `unchanged`，不再重发整个学习库（包括资料全文）。平时每 2.5 秒轮询一次；连续多次没有变化且没有任务在运行时会放慢，面板隐藏时停止。
- 陪学的调用量在「学习统计 › 模型用量」的「陪学」一项里，详见 [token 用量](token-usage.md)。

## 开发者参考

- 服务端操作：`coach.nudge` `coach.reply` `coach.feedback` `coach.consent` `coach.goal` `coach.debrief` `coach.practice` `coach.revert` `coach.status` `coach.profile` `coach.forget` `coach.prepare` `coach.variants` `coach.rewrite.retry`。
- 从 1.0.0 起，做题页不再有陪学栏。`coach.nudge`（客观题答错或自评低于 3 分后的陪学点，模拟考试不提供）和 `coach.reply`（懂了、还是不懂、回答小检查；每个陪学点最多再换 2 个角度讲）仍保留在服务端，但面板不会调用。同时发起的相同请求共用一次调用。
- 在结果页调用 `coach.consent { prep: true, runId }` 时，也会把这一轮需要的应用题加入备题。
- `coach.forget` 只清空 `learner` 和待练的 `prepared`。
- 设计依据：答错后的帮助只在学习者主动请求时启动（[反馈约束](user-feedback-intake.md) F-010）。
- 代码：`lib/coach.js`、`lib/contexts/coach/`、`ui/CoachDebrief.jsx`、`ui/ThumbFeedback.jsx`。

## 规划：系统学习中的陪学（尚未实现）

以下只是设计方案，当前版本都没有实现；上文现有的自动行为也不代表这条新路线的默认策略。

- 新路线复用例子、追问和教学阶梯，按“最小前置诊断 → 完整示范 → 半完成练习 → 独立检查”推进。
- 你主动选择补救后才进入，默认最多 3 个局部台阶，计入本轮预算；完成或退出都能回到原任务。不会因为答错自动切走，也不会在轮末自动追加下一轮。
- 看过提示或答案会影响这次作答能否算作证据。“懂了”、讲解完成和自评达标都不等于独立验收。
- 没有模型时可以继续已保存的内容；开放题判分会显示待评估，并保留提交以便重试。
- 原有的备题同意不扩展为全资料审计或外部实操的授权。

具体状态、延迟检查和新旧模式的边界见[计划 R5–R9、U4–U6](plans/2026-09-27-1945-feat-evidence-based-learning-plan.md) 与[学习工作流](study-workflows.zh-CN.md#proposed-system-learning)。
