# 用自己的题目作为参考样题

在 **创建题组 → 用资料出题** 中，先选择用于支持答案的教材正文，再展开 **参考样题（可选）** 上传优质题目，或选择资料库中已导入的文件。生成新的案例分析题时也有同样的入口。

TXT / Markdown 可以直接上传。PDF / Word 沿用现有资料导入与解析；图片请先转成文本。建议提供题干、正确答案和解析。导入的样题会保存在资料库，之后可再次选择。同一次生成中，一份资料不能同时作为教材事实依据和参考样题。

一次最多选择 5 页或文本片段，总计 12,000 字符。整本题集请只选少量相关页，或先整理成短文件。超限会提示你缩小范围，不会悄悄截断样题。

样题只帮助模型参考所选题型、难度、表达方式和解析结构。答案和原文引用仍必须来自教材正文。生成要求明确：写出新的题目，不复制样题，不把样题答案当成已核实的事实，并保持清楚易读。单选、多选、闪卡、填空、开放问答、混合题组和新生成的案例题分别遵循对应题型要求。导入已有案例时不使用样题改写你的题目。

默认不选择样题。所选样题随生成题组保存，后续补题可继续使用；如果删除了样题资料，需要重新选择。开始生成后，所选样题会随教材发送给已配置的模型。样题加入已有生成与审阅步骤，会增加上下文和 token 用量，但不会新增模型调用步骤；用量估算会计入样题。样题能帮助表达你想要的风格，但不能保证每道题都通过审阅，也不能保证每个模型的表述始终自然。

本次不内置第三方题库。已整理[开源题目参考来源与许可说明（英文）](reference-question-sources.md)，目前可以先上传自己的教材题目使用。
