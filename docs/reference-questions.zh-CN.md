# 用自己的题目作为参考样题

在 **创建题组 → 用资料出题** 中，先选择用于支持答案的教材正文，再展开 **参考样题（可选）** 上传优质题目，或选择资料库中已导入的文件。生成新的案例分析题时也有同样的入口。

TXT / Markdown 可以直接上传。PDF / Word 沿用现有资料导入与解析；图片请先转成文本。建议提供题干、正确答案和解析。导入的样题会保存在资料库，之后可再次选择。同一次生成中，一份资料不能同时作为教材事实依据和参考样题。

你可以自定义样题片段数量和总字符上限，默认分别为 5 个片段、12,000 字符。这里计数的是资料页或文本片段，不是其中的单道题目。为控制请求大小，可设置范围分别为 1–50 个片段、1–100,000 字符；实际还要受你所用模型的上下文容量限制。超限会提示你减少选择或调整设置，不会悄悄截断样题。所选上限随题组保存，补题时继续使用。

取舍：少量相关、风格一致的样题通常更容易表达要求，也更省费用和时间。更多样题可以覆盖不同题型与难度，但文本越多，已有生成与审阅步骤的输入 Token 越多，费用和等待时间可能上升；题型无关、重复或风格冲突的样题还可能干扰生成。提高上限本身不增加费用，实际选入的文本量才影响用量；字符数也不等于 Token 数。建议先用少量样题，观察效果后再增加。增加样题不会提高目标出题数量，也不保证更高通过率。

样题帮助模型遵循适合当前题型的设问结构、选项组织、难度和解析格式。格式保持一致，不意味着每道题套用同一情景或句式：提示词要求围绕不同的已核实知识点调整设问、措辞、情景和干扰项，避免只换名词的重复模板；生成自查和独立审阅同时检查格式适配与内容多样性。多样性不能以编造事实、强塞情景或损害可读性为代价，闪卡仍优先聚焦单个知识点。

拖动 **样题格式贴合度** 可以选择三档，默认“均衡贴合”，设置随题组保存并用于补题。这是表达风格的提示要求，不是遵循率或通过率保证：

| 档位 | 效果与取舍 |
| --- | --- |
| 灵活参考 | 借鉴有用的组织方式，允许更多结构变化；与样题外观可能有较大差异。 |
| 均衡贴合 | 保留主要题型结构，同时按知识点调整表达和情景。 |
| 紧密遵循 | 更紧密遵循适用的题干、选项和解析结构；格式更一致，但风格变化空间较小，仍要避免机械重复。 |

所有档位都保留答案依据、引用准确性、可读性和避免同质化的要求。样题格式与当前题型冲突时，优先当前题型；未选择样题时，滑块不会添加样题要求。

答案和原文引用仍必须来自教材正文。生成要求明确：写出新的题目，不复制样题，不把样题答案当成已核实的事实，并保持清楚易读。单选、多选、闪卡、填空、开放问答、混合题组和新生成的案例题分别遵循对应题型要求。导入已有案例时不使用样题改写你的题目。

默认不选择样题。所选样题随生成题组保存，后续补题可继续使用；如果删除了样题资料，需要重新选择。开始生成后，所选样题会随教材发送给已配置的模型。样题加入已有生成与审阅步骤，会增加上下文和 token 用量，但不会新增模型调用步骤；用量估算会计入样题。样题能帮助表达你想要的风格，但不能保证每道题都通过审阅，也不能保证每个模型的表述始终自然。

本次不内置第三方题库。已整理[开源题目参考来源与许可说明（英文）](reference-question-sources.md)，目前可以先上传自己的教材题目使用。
