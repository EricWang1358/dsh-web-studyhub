# 复习全书

[English](review-book.md)

**复习全书**是每门课一本的书页，由[课程总纲](course-outline.zh-CN.md)和「生成复习全书」给每个知识点写的讲解组成。它用来读和复习；书里的题目是链接，点开就去练。这里写的是[设计](plans/review-book.md)的 M1（阅读）、M2（编辑）、M3（把问答加进书）、M4（读的时候弄懂）、M5（分析题答案卡）、M6（查找页和导出）和 M7（期末一周）。按 2026-10-11 的代码核对。

## 打开

侧栏「阶段性」里点「复习全书」：当前课程的书已经写好就直接打开书页；还没有就打开**总纲**页，页上一句话说明复习全书是什么，并提供「生成总纲」和「生成复习全书」。书页标题下，没有填考试日期的课程会有「设置考试日期，开启期末一周」（点开就是课程设置），考试日期比期末一周的窗口还远的，会写「期末一周在考前 N 天开始」。

在**总纲**页，复习全书写好后，学习顺序那一行旁边有「打开书页」；展开一个知识点，它下面也有「打开书页」，打开后直接到这个知识点。「返回总纲」回去。

## 书页上有什么

| 部分 | 是什么 |
| --- | --- |
| 目录 | 书里所有标题：总纲的章、节、知识点。「你在这里」标出正在读的知识点，点一个标题就跳过去。宽屏时在正文旁边；窄屏时折叠在标题下（「目录」按钮），跳转后自动收起。 |
| 章 | 总纲的每一章一块（「整章滚动」时）。只画打开的章，书再大也不卡；上次读到的那一章会自动打开。 |
| 知识点 | 按阅读顺序排的讲解（见下面「一节怎么读」），顶部一行是「练 5 道」「本节问答」。没有题的知识点在那一行显示淡色的「暂无题」和「出题」。没有样卷时不显示任何考试相关内容。 |
| 未归位 | 只在总纲重新整理后、你自己写的内容找不到对应知识点时出现；每段用原来的标题，标「已无对应知识点」。 |

## 讲解是怎么写出来的

「生成复习全书」是一个有质量把关的流程，不是一次提问（细节和调用次数：[课程总纲](course-outline.zh-CN.md#复习全书讲解层)）：

1. **清点**：并行读每份资料的每一段页面；模型列出每个术语、定义、概念、公式、步骤、规则、例子、论断和易错提醒，带页码和引文，逐字核对。
2. **总纲**：条目按学习顺序归成知识点；每个条目恰好在一个知识点里（否则在「其他 / 未归位」）。
3. **清单**：每个知识点得到必须讲到的条目（按「讲解详尽程度」；资料强调的、样卷考到的一律必讲）。
4. **写**：每个知识点单独一次调用（大的按整页分几遍），全部并行，自由地写，清单里的术语第一次出现就讲清楚，有过渡，资料以外的内容标「（资料以外）」。
5. **角标**：每个角标都要在这个知识点自己的页里逐字找到，否则去掉。
6. **审阅**：一次独立的调用对照清单和原文检查正文。
7. **判定**：写的一方声明讲到、正文里出现了名字、审阅没有指出问题，这个条目才算讲到。
8. **修复**：只改指出的地方，最多两轮，每次改完再审。
9. **未达标**的知识点保留并标「未达标：缺 N 个概念」，绝不显示为完成；任务以部分完成结束，「补漏」或下一次更新只补这些。
10. **生词与概念**：程序按讲到的条目生成，按字母排序，放在「查找」里，每条链到讲它的那一节。

**覆盖**对照这份清点来量，分三层，显示在书页顶部和总纲页：读到的**资料和页**、达标的**知识点**（必讲条目都讲到，没有不受支持的说法）、讲到的**概念**。从不按字数或模板。

## 两种读法

在「预览」里，「怎么读」在两种读法之间切换（按课程记在这个浏览器里）：

- **逐节读**（默认）：一次只显示一个知识点，上面是它所在的章、节，和「第 N / M 节」「上一节 / 下一节」（紧凑），底部也有「上一节 / 下一节」（带相邻那一节的标题）。键盘 ← / → 一样能翻（在输入框里打字、用菜单或选中了文字时不翻）。翻到新的一节从顶部开始读；目录标出它。点目录里的标题、「查找」里的编号、「今天读哪几节」的「去读」或「翻看」里的入口，都会显示那一节（点章或节：显示它的第一个知识点）。
- **整章滚动**：和以前一样把各章连着滚动，但除了正在读的那一节，每个知识点只显示标题和一句话（它的要点），点标题展开或收起。跳转会展开跳到的那一节。

切换读法时停在同一个知识点。练完题「回到复习全书」时，两种读法都回到原来的那一节和位置。

## 一节怎么读

一个知识点先显示程序写的内容，再显示你自己的一层；文件里的内容一样不少，只是换了显示顺序：

1. **顶部一行操作**：左边「在这里加一段」；右边「练 5 道」「本节问答 (N)」（N 是问答条数，显示这一节时读取）、「整理」（有 AI 块时才有）和「发给主会话」。「本节问答」在这一行下面展开。
2. **一句话**：这一节的要点，字更大。讲解里自带一句话时用它；否则用「讲解」的第一句，这一句不再在「讲解」里重复。第一句是列表、表格、公式、代码或太长时，不显示一句话。
3. 正文：「讲解」和「例子」（以及你写在生成文件末尾的内容）。
4. **要点清单**（知识梳理）和**补充（资料以外）**，各自收在标题下。
5. **我的笔记与 AI 解释 (N)**：你的笔记，然后是你自己文件里的 AI 块（按写入顺序），然后是加入复习全书的问答。有三项或以上、或有一块超过 1,500 字时，默认收起（每块只显示标题行和一行摘要）；你展开或收起过的块保持你的选择。点这一层的标题一次收起或展开全部块。为整个知识点写的块（「在这里加一段」写的）如果比讲解还长、而且大部分内容和讲解一样（按词对粗略比较，60% 以上的句子和引文在讲解里能找到），会显示「与上面的讲解重复度高」和「收起」。「新」只在展开的块上显示。
6. **本节的题 (N)**，默认收起：它现在的题目，前 5 道是链接，其余用「还有 N 道」展开。
7. **出处 N**：一个淡色的小按钮，点开才显示清单。正文里的角标照样打开阅读器里的原文。

**发给主会话**（在这一行「整理」之后、选中文字的面板里，以及书页顶部的「整本书 · 发给主会话」）把一条消息填进对话的输入框，请主会话按 `study-book` 技能改这一个知识点、你选中的话或整本书（见[复习全书与主会话](review-book-agent.zh-CN.md)）；消息里没有书的正文。

**整理**不会删除任何东西：「收起所有 AI 块 / 展开所有 AI 块」，以及「只留我写的（隐藏 N 段）」：在这一节隐藏不是你写的块（新的、没保留过的、为整个知识点写的块），这一层随后显示「已隐藏 N 段 AI 写的」和「全部显示」。隐藏和收起都按课程记在这个浏览器里，不写进书的文字，所以导出和「原文」不受影响。

正文 17 px，宽屏时一行约 70 个字符；表格在手机上在自己的框里横向滚动，整页不横向滚动。公式只画一次（MathML）；把页面复制成纯文本时它可能出现两遍（TeX 源码作为隐藏的注释跟着一起复制），这是复制的副作用，不是页面上显示的样子。

## 链接

- **一道题**（`studyhub://card/<题组>/<题>`）打开这道题的练习页，答题、判分、排期和别处一样。「回到复习全书」回到书里离开时的标题和滚动位置。
- **练 5 道**（`studyhub://practice?heading=<id>&n=5`）按练习的顺序（到期、薄弱、新题，然后是其余）练这个知识点的前 5 道；正好是这几道题的未完成练习会接着做。刚答对的题不再是到期、薄弱或新题，会排到别的题后面。
- **本节问答**（`studyhub://qa?heading=<id>`）在知识点下面列出关于它的问答：题目上留下的追问、阅读器里落在它位置之内的批注、问答卡。每一条折叠着，展开看答案，再去练这道题或看原文。
- 角标和出处列表打开阅读器，定位到引用的那句话。
- 指向已删除题目的链接显示「这道题已被删除」。链接只负责跳转，不会执行任何操作；别的链接照常打开。

## 编辑

书页上方的「预览」「原文」切换显示方式，每门课记住各自的选择。「原文」在 Markdown 编辑器里显示一份文件的原始 Markdown；文件选择列出按阅读顺序排的所有文件：每个知识点的「讲解（生成）」和「我的笔记」，以及「未归位」。任何一份都可以改。

- 「保存」保存这份文件。你自己写的标题（`## …`）在保存时得到一个稳定 id（写在标题行末，预览里看不到）；id 不会重复，也不会占用总纲标题的 id。「放弃改动」回到已保存的内容。有没保存的改动时文件选择会锁住，换文件不会丢改动。
- **改了生成的文件，它就归你**（「已改动」）。重新生成讲解时，你改过的文件不会被覆盖：新内容在预览里放在它下面，标「有新的生成内容」，可以「采用」或「忽略」（忽略过的不再提示，更新的会再提示）。一份文件最多同时留三条建议，最新的在前，各有自己的按钮，不会互相挤掉。你没改过的文件会自动跟着新讲解更新。你的笔记程序从不改动。
- **书已更新。** 保存时会核对你开始编辑时的文件版本。如果这份文件在此期间被改过（程序或另一个标签页），你的内容照样保存，另一边的内容作为建议留着（「书已更新」，可以「采用」或「忽略」）；别的文件不受影响。
- 「回退到上一版」一次退回这份文件的上一版；程序的任何一次写入都可以这样撤回。每门课保留最近 20 个版本（内容大时更少），存在学习库的资料之外；导出的备份带着它们，恢复时一起放回。两份程序同时写同一本书时，版本历史可能少记一版，书本身不会出错。
- 改过的文件在预览里照样显示题目链接、脚注和本节问答，不会渲染 HTML：标签原样显示成文字。你自己写的标题会出现在目录里，可以从目录跳过去；练完题回来也会回到它。

## 把问答加进书

练习时得到的问答（「追问」或「帮我弄懂」的回答）照旧留在题目上。想让它也进书，在它下面点「加入复习全书」（练习页上，或知识点的「本节问答」里）；之后显示「已加入 · 撤回」，点它就从书里拿出来（题目上的问答一直都在）。

- 它放进这个知识点自己的「问答」文件，显示在你的笔记后面：先是这道题的链接（知识点下还没有这道题的链接时），问答引用在它下面。不属于任何知识点的题放进「未归位」。同一条问答不会加两次。
- 进了书就是你的文字：可以像别的文件一样改（「原文」里选「· 问答」）；以后改了题目，它也不变。问答文件正在编辑器里打开时，期间加进来的问答会和你的保存合在一起，两边都不丢。
- 「自动加入复习全书」（练习页按钮旁的小开关，设置 › 练习里也有；默认关）：打开后，练习页开着时新得到的每条追问或「帮我弄懂」回答会自动加进书。已经在书里的不受影响；切换只影响之后的问答。自动加入失败时会有一行小提示，按钮照旧可以点。只有练习页上得到的问答会自动加入。

## 读的时候弄懂、加一段

在「预览」里选中一个知识点的几句话（讲解或你的笔记都行），下面会出现一个小面板：「弄懂」，以及一个输入框「让 AI 写一段…」（讲细点、加个例子、对比做个表）。每个知识点标题下的「在这里加一段」打开同样的输入框。两种都会开始一个任务，在「任务」页能看进度、停止、重试（不估算、不确认）；没有模型时面板显示统一的模型设置提示，读书页、改书页照常能用。

- 回答只依据这个知识点自己的资料（和阅读器里问一段原文同样的规则）。引文会在资料里逐字核对，找不到的去掉；资料以外的内容单独列在「补充（资料以外）」下。没有资料的知识点会直接说明，不开始。
- **你写的要求会被照着做。** 只点「弄懂」（没写要求）时，还是固定的讲解格式。写了要求（「让 AI 写一段…」或「在这里加一段」，比如「用厨师例子通俗解释 Day1-5」「讲细点」「对比 X 和 Y 做个表」）时，回答的形式、语气、长度和例子都按你的要求来；事实仍然只依据选中的那段和这一节的资料。要求里的类比、例子或背景如果来自资料以外，会直接写在正文里，并在那一处用「（资料以外）」标出来，不再藏在末尾的清单里；AI 被要求不能把资料以外的事实说成是资料写的，资料没讲清的地方只说一次。在某一段下面的追问是你的又一个要求，回答方式相同（比如「再用厨师例子讲一遍」）。如果模型仍单独列出资料以外的内容，它们会作为普通的圆点放在正文末尾，每条以「（资料以外）」开头，不再放在脚注标题下。检查过的原文引用仍可能放在末尾的「资料原文」里。
- 它作为新的一段写进这个知识点自己的笔记，从不覆盖已有内容，显示在这一节的「我的笔记与 AI 解释」里，在这一节的正文之后（不会放到正文上面）；写好时会自动展开并带你看到它。你选中的那几个字在原段落里保留虚线（找得到才有；那句话没了，块上标「原位置已变」）。「在这里加一段」为整个知识点写一块。第一行写着它是关于什么的：「关于：「…」」。
- 写进去以后就是你的文字：可以在「原文」里像别的内容一样改；书的更新不会改动它。「保留」表示留下，「重新生成」按原来的要求再写一遍，「删除」去掉它，下面的输入框可以接着问，回答放在它下面。
- 每一块可以收起：点标题行（AI、「关于：「…」」，收起时再加一行答案开头作为淡色摘要），或在上面按 Enter / 空格，就能收起或展开；「我的笔记与 AI 解释」的标题（或「整理」）一次处理这个知识点的全部块。新生成的块是展开的；收起与否是你自己的选择，按学习库和课程记在这个浏览器里，不写进书的文字，所以导出和「原文」不受影响。你选中的那几个字在它所在的段落里带一条虚线（找得到才有，找不到就没有）：点它会打开并带你看到这一块，点块里的「关于：「…」」会回到那几个字。
- 和书里别的内容一样，它只是参考，不会被当作出题的资料。
- 笔记正在「原文」里编辑时，期间写进来的段落会合进你的保存，两边都不丢。
- 已知限制：书页每 1.5 秒查看一次它开始的任务，只在任务进行中查看。预览和开发用的服务器没有后台任务执行器，所以这些任务（以及生成复习全书）只能在真正的宿主里运行。

## 分析题答案卡

案例题、分析题（有分值和评分标准的开放题，大题）的答案不是一段话，而是一张经过核对的**答题卡**。在练习页批改完这道题后，参考答案照旧显示，下面有「生成答题卡」（一个可以在**任务**页查看、停止、重试的任务；不预估、不确认；没有模型时显示统一的模型设置提示）。答题卡只有一个完整版本，没有简短版：

| 部分 | 内容 |
| --- | --- |
| 题型和识别信号 | 题型（风险场景、可用性、性能、容量与 RAID、领域划分、云迁移与选型，或一般分析题；课程可以加自己的题型）和题干里点明题型的词，附题干原句。 |
| 题干事实 | 答案用到的每条事实，附题目或案例里的原文。 |
| 概念 | 概念名、它在哪份资料里定义，以及资料原文里的定义。 |
| 假设 | 题干没说的地方明确写出假设（答案需要的数字写在这里，从不凭空出现）。 |
| 推理链、结论 | 按题型的解题步骤，把数代进公式，再给出结论。 |
| 为什么满足目标、代价与失败处理、如何验证 | 阅卷人要看的论证。 |
| 易错检查、评分点对照 | 常见错误；评分标准里每个评分点由答题卡的哪一句拿分。 |

程序会核对：每处引文和定义都在题干、案例或资料里逐字查找（空格和大小写不算），找不到的标「未核实」；省略号拼起来的引文、短到证明不了什么的引文也标「未核实」。转换来的、含 HTML 的资料（PDF 里的表格）按看得到的文字核对：去掉标签，单元格之间算一个空格，实体解码；所以表格单元格里的定义也能找到，并按这些文字显示。评分点覆盖由程序计算，不由模型自报；在题干、假设和概念里都找不到、也不是算出来的数字会被列出来。随后一次独立复核检查没有依据的说法、与题干矛盾、缺代价、编造的数字；核对或复核发现问题时再改写一次（总共两到三次模型调用）。答题卡显示它的状态：**已核对**（各项检查都通过）、**部分未核对**，或**被改过**（答题卡生成后，题干、分值、评分标准或参考答案被改过）。**已核对 ≠ 答案正确。**

- 答题卡存在题目旁边（`answerCard`）；题目原来的答案、复习安排和历史都不改。它和参考答案一样在揭晓后才出现，模拟考试中不出现；还没交卷的模拟考试里的题，交卷后才能生成。
- 题组的资料超过预算（24000 字）时，先给模型和题目（题干、主题、概念、评分标准）共用词最多的段落，再按阅读顺序补足；引文仍然对照完整的资料核对。
- 已知限制：核对或复核后改写过的答题卡，程序会再核对一遍，但不会再复核；数字检查是经验规则（题干没提的「RAID 5」这类级别可能被列出，算式之后写的输入数字可能漏掉）；题型由模型参照关键词猜测选择，课程自己的题型通过 `course.save {caseTypes}` 设置（还没有页面）。
- 答题卡下的「加入复习全书」把它放进这门课的复习全书，放在知识点的问答文件里、题目链接下面（不属于任何知识点的案例题放进「未归位」），只放一次；「已加入 · 撤回」把它拿出来。放进书里之后，它就是你的文字。

## 查找和导出（打印成自己的 CP）

一本从头读到尾的书，开卷考试时不好查。所以书有**查找页**，每次都从书现在的样子生成（从不单独保存，也不手改），导出时放在最前面：从一道题找到是哪一节、哪个定义、哪些步骤。

- **编号。** 每个标题有一个稳定的编号，就是它的 id 的大写（`H12`），书页上写在标题旁边，导出里写在页边（`### 1.2 标题 〔H12〕`）。编号永不重排：插入、移动、删掉一节，变的是序号（1.2 → 1.3），不是编号。一个知识点的题按它的编号排：`H12-Q1`、`H12-Q2`……；「未归位」是 `U`。
- **查找**（书上方的第三种看法，和「预览」「原文」并列）：**目录**，带编号；**按题型**，就是速查表：书里有答题卡的每种题型（以及课程自己的题型），列出题干信号、检查顺序和公式、最常见的错误和必须交代的代价（内置题型用书的语言，中文或英文；课程自己的题型照原样）、在哪里（编号和题号），上面是每道题都适用的答题顺序（题干事实 → 明示假设 → 设计/计算 → 为什么满足目标 → 失败与代价 → 如何验证）；**按概念**：答题卡里的概念、笔记和讲解里开头加粗的定义词（`**术语**：……`、`**术语**是……`、`**term** is ……`，或以「定义」开头那一行里的所有加粗词），以及你用 `[[术语]]` 标出的词，各自带编号；**易错点（按知识点）**：你加进书里的追问（当时不懂、去问的地方）和答题卡的易错检查。点编号就到那个标题。没有答题卡时不显示题型的内容。
- **导出**（标题栏里）：一个 Markdown 文件，可选**不含**或**含答案册**。最前面是书名和查找页，然后按阅读顺序是整本书（每个知识点：讲解、选了时它的题、你的笔记、它的问答；「未归位」在最后；含答案册时答案册在最后）。程序的标记注释都去掉（标题的 id 变成 Pandoc 的锚点 `{#h12}` 和页边编号；问答块、答题卡块、AI 块的内容保留）；**印哪些题**：**只印书里链接的题**（默认：问答文件里的和你自己写了链接的题）、**再加每个知识点自己的题**（每个知识点的题都印出来，带选项，最占页数）或**不印题目**（题目链接都去掉）。印出来的题目链接变成编号的题目，选择题在这个知识点第一次出现时带选项（A.、B.……）；已删除的题目、「练 5 道」「本节问答」的链接不导出；出处留下文字；脚注按文件命名，不会撞名。答案册只列印出来的题，用同样的题号，页数估计也跟着选择变：答案（正确选项、填空的答案）、解析、完整的答题卡。同一本书每次导出的字节都一样。**分文件导出…** 列出文件夹形式：每部分一个文件（`000-front.md`、`001-h3.gen.md`……）和记着顺序的 `book.yaml`；应用里没有打 zip 的工具，所以逐个下载，用 `pandoc $(sed -n 's/^  - //p' book.yaml)` 读出来就是同一本书。
- **不打印。** 在「原文」里写在 `<!-- sh:noprint -->` 和 `<!-- /sh:noprint -->` 之间的文字不导出，也不算进页数估计；书页上照常显示。没有闭合的标记不起作用（文字照常打印）。
- **页数。** 导出窗口按固定规则估计每种选择的 A4 页数（每行约 40 个汉字或 80 个其他字符，每页 45 行，空行算半行）：是估计，不是实测。**页数上限**（默认不填）存为 `settings.book.pageLimit`；填了之后，标题栏里有一行不显眼的「导出约 N 页 / 上限 M 页」（不含答案册的书），超出时说超出多少。
- 已知限制（接受）：概念规则只认行首的加粗词、以「定义」开头那一行里的加粗词和 `[[术语]]`；`course.book.open` 每次都带上这门课的题型目录（`caseTypes`，几 kB）；设了页数上限后，书每改一次，标题栏那一行都要把整本书再导出一遍（只算页数），书很大时更费时。标题栏的估计按默认选择（只印链接的题、不含答案册）。

## 期末一周

课程设了考试日期（「课程设置」）、也有复习全书时，程序按书里的知识点排出考前每一天：不调用模型，同一本书、同样的作答和标记，排出来总是一样；每一天都用一句话说明为什么这样排。

- **先学，再翻看。** 从今天到考试前一天：最后两个学习日（一到三天；剩下的天数更少时就全部）是**翻看日**：不再做新题，每一节看一次，易错点多的先看，再按薄弱程度；考前最后一整天另有一套**模拟卷**。前面的日子是**学习日**：读一节，再「练 5 道」（它接下来的 5 道题）。今天考试：只有一个翻看日，没有模拟卷。没有考试日期就没有计划，书照常能用。
- **哪几节先学。** 一节的分量是 1 + 样卷里考过它的份数（总纲的「样卷考过」）；没有样卷时每节一样重。薄弱程度看它的题（薄弱的算得最重，其次是没学过的、学习中的、熟悉的；到期的再加一点）。分量 × 薄弱程度最大的先学；每天的时间大致一样（读它的文字，每分钟约 300 字，加 5 道题），同一天里按阅读顺序。一节只学一次：某一天答了它至少 5 道题（题少于 5 道就全部），或者没有题的一节点了「读完了」。节数多于时间时，那几天会超过每天的时间（「设置 › 练习 › 期末一周每天学多久」：60、90、120、默认 180 或 240 分钟），并且写明（「节数多于时间：……」）：什么都不丢。第二天再排时，做完的节留在做完的那一天，剩下的从今天起重新分；刚好做完今天的节，后面几天和原来一样。
- **在首页。** 「今天先做什么」下面，每门考试在 21 天以内、没有停用的课（「设置 › 练习 › 期末一周提前几天出现」，7–60 天）有一张「期末一周 · 课程」卡片：今天是什么日子、为什么这样排、今天的几节（「去读」打开书页到这一节，「练 5 道」，翻看日是「翻看」）、「翻看全书」和「用这几节出一套模拟卷」。不是当前课程的，会先切换到那门课再打开书页（书页显示当前课程的书）。
- **在书页。** 标题栏里的「今天读哪几节」在下面打开同一天。第四种看法「翻看」按计划的翻看顺序列出每一节：先是你的**易错点**（你问过、加进书里的追问，答题卡的易错检查，用「弄懂」讲过的地方），**讲解**收起（展开时才画出来），「已看」（每门课记着，刷新后进度还在）和「选进模拟卷」。
- **模拟卷。** 「用这几节出一套模拟卷」（翻看里选中的几节，没有选就是今天的几节，再没有就是全书）先说这几节一共多少道题、多少道单选或多选可以进卷、按题型哪些不进（模拟考试只考单选和多选），题数（1–50，默认最多 20）和限时（课程的作答时间，没有就 30 分钟）；「开始模拟卷」用这些题开始普通的模拟考试，到期和薄弱的题在前。考试页、计时、交卷和成绩都和平常一样；回去的路是复习全书。
- 已知限制（接受）：休息日只是操作的参数（`daysOff`，没有页面）；阅读速度是固定规则；一节学没学完看一天里的作答，所以在模拟考试里答了它 5 道题也算；从首页打开另一门课的计划会把那门课设为当前课程；在「翻看」里同时打开「今天读哪几节」时有两个模拟卷按钮，范围不同（今天的几节，和翻看里选中的或整个范围）；翻看的顺序当天固定（看过的一节留在原处，变灰）；一天的计划在学习库或书变化之前保留不变，所以当天晚些时候才到期的题，要等下一次变化才影响排序。

## 在主会话里改

可以让 DSH 主会话来写或重写书的任何部分：它按 `study-book` 技能一次处理一个知识点，先读资料页，逐字核对每条引文，写过的每份文件都保留上一版。见[复习全书与主会话](review-book-agent.zh-CN.md)。书页也可以用「发给主会话」把一个知识点、选中的话或整本书交给主会话。

## 存在哪里

全书是学习库里的一条隐藏记录（`provenance: 'course-book-doc'`），里面是几份 Markdown 文件：每个知识点一份生成的文件（程序的）和一份你自己的文件（M1 里为空），一份清单（总纲的树，每个标题一个稳定 id），以及一份放「未归位」内容的文件；期末一周的「读完了」「已看」是同一条记录里每节一个日期（`bookDoc.marks`），不是文件。它只是参考，不是资料：不在资料列表、选择器和搜索里，不进检索索引，不计入助手看到的学习库情况，把它当资料用会被拒绝。题目仍然引用原资料。

打开书页时，第一次会生成这些文件（不调用模型），之后把生成的文件更新到当前的讲解。知识点的题目列表不存在文件里，每次现读，所以加题、删题不改任何文件；什么都没变时打开书页不会写学习库。你自己的文件不会被改动。总纲重新整理后，新的知识点如果包含同样的资料（否则看同名），就沿用原来的文件和标题 id；对不上的放进「未归位」；什么都不删。

## 回退

只能升级。旧版（3.3.0 及更早）不认识这条记录：会原样保留，但可能把它当一份名为「复习全书 · 课程」的 Markdown 资料列出，正文只有一行「复习全书（由 StudyHub 3.4 以上管理，请勿删除）」。在旧版里删掉这一条，书页的文件也就没了。版本历史（学习库文件夹里的 `book-history`）旧版不会理会。题目的答题卡（`answerCard`）旧版原样保留，只显示原来的参考答案。导出不写任何东西；旧版下次保存设置时会丢掉页数上限（`settings.book.pageLimit`），保存课程时会丢掉课程自己题型的 `mistakes`。期末一周只写它的标记（`bookDoc.marks`，旧版原样保留）和可选的 `settings.book.crunchWindowDays`（旧版保存设置时会丢掉）；模拟卷是普通的考试记录。

**有质量把关的流程（这个版本）同样只能升级：先备份学习库**。3.4 还能读它的记录，但有这些限制：3.4 不认识资料清点的记录（`course-outline-inventory`），可能把它当资料列出（不要拿它出题）；它解析不了按清点整理的总纲里的页段（`doc@s3-7`），这些知识点在 3.4 里不显示题；讲解里带一份 3.4 能读的正文和出处（`explain`、`cites`），显示时没有概念覆盖、生词与概念和未达标标记。升级以后不要再在 3.4 里点「更新全书」：它读不懂页段，会写出空的讲解。

- `course.book.export {course?, form?: 'single' | 'folder', answerKey?: boolean, estimateOnly?: boolean}`（lib/course-book-export-op.js，只读：按 `course.book.open` 会给出的书导出，什么都不写）返回 `{ status, course, form, title, language, filename, text | files + manifest, questions, estimate: { pages, book, withAnswers, columns, rows } }`；Markdown 由 lib/course-book-export.js 的 `exportBook` 生成（纯函数，浏览器可用，输出确定），查找页是 lib/course-book-lookup.js 的 `bookLookup(book, { caseTypes, answerCards })` 和 `renderLookup`（编号：`codeOf`）。`course.book.open` 另外返回 `answerCards`（书里题目的答题卡摘要）和 `caseTypes`（这门课的题型目录，课程自己的题型带 `own: true`），来自 lib/course-book-cards.js。题型可以带 `mistakes`（lib/case-types.js）。`settings.book.set {patch: {pageLimit: 1–2000 | null}}`。
- `book.crunch {course?, date?, minutesPerDay?, daysOff?, reviewDays?}`（lib/course-book-crunch.js，只读）返回 `{ status: 'ok' | 'far' | 'past' | 'no-exam' | 'no-book' | 'no-course', course, examDate, daysLeft, window, revision, plan, points }`；计划由 lib/crunch-plan.js 的 `crunchPlan` 排出（纯函数，浏览器可用，输出确定：`days: [{ date, offset, mode: 'learn' | 'flip' | 'off', mock, points, done, minutes, reason: { code, … } }]`、`today`、`order: { learn, flip }`、`merged`、`unlearned`）；`points` 是 `{ id, key, code, title, tested, weakness, questions, weak, due, fresh, size, pitfalls, done, seen }`，易错点来自 lib/book-flip.js 的 `pointMistakes(book)`。`book.crunch {all: true, date?}` 返回考试在窗口以内、没有停用的课程（`settings.book.set {patch: {crunchWindowDays: 1–60 | null}}`，默认 21 天），带今天这一天和它的几节。每天的分钟数是 `settings.book.crunchMinutes`（15–960，默认 180；操作的 `minutesPerDay` 优先）。结果按学习库文件夹、课程、学习库版本、书的版本、日期和参数保留（lib/course-book-crunch.js，`crunchComputations()` 记真正算了几次），所以首页卡片不会每次快照都把书重建一遍。`book.crunch.mark {course?, hid, kind: 'read' | 'seen', on?, date?}` 在书的写入队列里记下标记。`book.mock.plan {course?, pointIds?, count?}`（只读）返回 `{ points, unknown, questions, eligible, leftOut: { 题型: 道数 }, count, capped, perPoint, limitMinutes? }`；`book.mock`（同样的参数和 `limitMinutes?`）在一个事务里调用 `review.start {mode: 'exam', scope, count, examKinds: 'all'}`，返回考试记录并附上 `mock`。拒绝码：book-crunch-date、book-crunch-no-book、book-crunch-kind、book-crunch-point、book-mock-no-book、book-mock-points、book-mock-count、book-mock-empty。
- 页面在 ui/book/（ui/pages.js 的 `book` 一行）；链接通过 ui/Markdown.jsx 的 `resolveLink` 绘制。查找是 ui/book/BookLookup.jsx，导出是 ui/book/BookExport.jsx，翻看是 ui/book/BookFlip.jsx，计划的一天是 ui/book/CrunchDay.jsx（首页卡片是 ui/book/CrunchCard.jsx），模拟卷是 ui/book/MockPaper.jsx。阅读：两种读法和每一步是 ui/book/reading.js（`study-book-reading:<学习库>:<课程>`），逐节读的一节是 ui/book/BookStep.jsx，一节的正文是 ui/book/PointBody.jsx，顶部一行是 ui/book/PointToolbar.jsx，你的一层是 ui/book/PointLayer.jsx；生成文件的各部分、一句话、重复检查和这一层的默认收起是 ui/book/point-parts.js（纯函数：按 lib/course-book-files.js `genText` 写的标签读文件，所以你去掉标签改写过的文件整体显示为一部分）。收起、展开过的块和「只留我写的」在 ui/book/ai-fold.js（`study-book-ai-folded:` / `study-book-ai-opened:` / `study-book-ai-mine-only:`）。
