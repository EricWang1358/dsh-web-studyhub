# 复习全书

[English](review-book.md)

**复习全书**是每门课一本的书页，由[课程总纲](course-outline.zh-CN.md)和「生成复习全书」给每个知识点写的讲解组成。它用来读和复习；书里的题目是链接，点开就去练。这是[设计](plans/review-book.md)的第一步（M1）：书页只读。编辑、把问答加进书、导出和打印在后面的步骤。按 2026-10-11 的代码核对。

## 打开

在**总纲**页，复习全书写好后，学习顺序那一行旁边有「打开书页」；展开一个知识点，它下面也有「打开书页」，打开后直接到这个知识点。「返回总纲」回去。

## 书页上有什么

| 部分 | 是什么 |
| --- | --- |
| 目录 | 书里所有标题：总纲的章、节、知识点。「你在这里」标出屏幕上正在读的标题，点一个标题就跳过去。宽屏时在正文旁边；窄屏时折叠在标题下（「目录」按钮），跳转后自动收起。 |
| 章 | 总纲的每一章一块。只画打开的章，书再大也不卡；上次读到的那一章会自动打开。 |
| 知识点 | 讲解（考情、知识梳理、讲解、例子、补充（资料以外）、出处作为脚注），然后是它的题目链接，最后是「练 5 道」和「本节问答」。没有题的知识点写「这一节还没有题。」并给出「出题」。没有样卷时不显示任何考试相关内容。 |
| 未归位 | 只在总纲重新整理后、你自己写的内容找不到对应知识点时出现；每段用原来的标题，标「已无对应知识点」。 |

## 链接

- **一道题**（`studyhub://card/<题组>/<题>`）打开这道题的练习页，答题、判分、排期和别处一样。「回到复习全书」回到书里离开时的标题和滚动位置。
- **练 5 道**（`studyhub://practice?heading=<id>&n=5`）按练习的顺序（到期、薄弱、新题）练这个知识点接下来的 5 道；正好是这几道题的未完成练习会接着做。
- **本节问答**（`studyhub://qa?heading=<id>`）在知识点下面列出关于它的问答：题目上留下的追问、阅读器里落在它位置之内的批注、问答卡。每一条折叠着，展开看答案，再去练这道题或看原文。
- 角标和出处列表打开阅读器，定位到引用的那句话。
- 指向已删除题目的链接显示「这道题已被删除」。链接只负责跳转，不会执行任何操作；别的链接照常打开。

## 存在哪里

全书是学习库里的一条隐藏记录（`provenance: 'course-book-doc'`），里面是几份 Markdown 文件：每个知识点一份生成的文件（程序的）和一份你自己的文件（M1 里为空），一份清单（总纲的树，每个标题一个稳定 id），以及一份放「未归位」内容的文件。它只是参考，不是资料：不在资料列表、选择器和搜索里，不进检索索引，不计入助手看到的学习库情况，把它当资料用会被拒绝。题目仍然引用原资料。

打开书页时，第一次会生成这些文件（不调用模型），之后把生成的文件更新到当前的讲解和题目。你自己的文件不会被改动。总纲重新整理后，新的知识点如果包含同样的资料（否则看同名），就沿用原来的文件和标题 id；对不上的放进「未归位」；什么都不删。

## 回退

只能升级。旧版（3.3.0 及更早）不认识这条记录：会原样保留，但可能把它当一份名为「复习全书 · 课程」的空 Markdown 资料列出。在旧版里删掉这一条，书页的文件也就没了。

## 开发者

- `course.book.open {course?}`（lib/course-book-files.js）返回 `{ status, course, revision, title, language, notes, papers, nodes, unplaced, missing }`；`nodes` 是 `{ hid, key, title, number, depth, leaf, gen, mine, questions, children }`，`missing` 是已不存在的链接题目。它是学习库的一个写操作（文件有变化时写入记录），不随快照发送。
- lib/course-book-links.js（浏览器可用）：三种题目链接（`parseBookLink`）、写在标题行末的标题 id（`## 标题 <!-- sh:id h3 -->`，`assignHeadingIds`：只给一次，永不复用）、`bookIndex`（标题树和每个标题下的题目链接）、`stitchBook`（按顺序拼接文件，脚注按文件命名）、`plainBook`。
- 页面在 ui/book/（ui/pages.js 的 `book` 一行）；链接通过 ui/Markdown.jsx 的 `resolveLink` 绘制。
