## U9：主会话资料查询与现有题组关系

- `library.context` 返回当前学习库、日历时区及紧凑数量摘要；详细操作契约按 `area` 读取。资料列表、搜索、覆盖检查共用同一日期、课程和资料范围。明确空范围保持空结果，绝不回退全库。
- 日期可选某日、today/yesterday 或闭区间，回显实际日期和时区。真实导入时间与旧记录的 `createdAt` 兼容依据、推断和未知分开；推断日期不冒充精确导入日期。PDF 文档和有序音频分卷可按逻辑文档聚合，原成员 ID 和分页仍可查询。
- `source.coverage` 列出资料被现有活动/归档题组及草稿直接引用的证据和分母，并把 JSON 自引用载体单列。语义覆盖留给主会话阅读证据判断，不伪造百分比。精确题组目标经原生成、续生成和发布合并路径，原题目 ID、复习进度、历史及前置关系保留。
- 首轮 4 项新增行为测试观察到日期、上下文、分组和目标题组失效后才接线。最终 8 文件定向检查 100 通过、0 失败；1 项旧有可选 SDK renderer 检查因当前进程未装 SDK 跳过，实际生产常量注册、授权与长度检查独立通过。改动文件定向 lint 通过。常驻工具说明由 21715 缩至 2859 字符，另有 609 字符的使用提示，最大片段按需读取为 2441 字符。浏览器/宿主全链仍由 U7 检验。
