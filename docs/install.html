STUDYHUB 2.7.1 · SETUP GUIDE

Set up your own study library

StudyHub is a study plugin for DeepSeek Harness (DSH), which runs as a desktop app or as a web page in your browser. Install DSH, add StudyHub through DSH’s plugin manager, then connect a model for question generation.

Already using DSH, desktop or web? Keep your current installation, models and profile, and go straight to Install StudyHub in DSH. No desktop client is needed for the web version.

Install StudyHub in DSH

These steps work in desktop and web DSH. Your models, workspace and profile stay as they are.

  1. In DSH, open Plugins › Add plugin.
  2. Paste the address below. After it installs, check that the package is @ericwang1358/dsh-daily-flashcard, version 2.7.1.
  3. Click Enable for StudyHub and the components you want. If DSH asks to reload, finish or cancel background tasks first.
  4. StudyHub opens by itself the first time. Later, open StudyHub in DSH’s left sidebar; no chat message is needed. On an empty library, Load the sample and start the tour loads a sample course and a tour of about 3 minutes. Neither needs a model.

Advanced: customise components

The complete package installs seven components: StudyHub, StudyHub · Core, StudyHub · Materials, StudyHub · Question bank, StudyHub · Question generation, StudyHub · Practice & review and StudyHub · Audio. Turn them on or off in DSH’s own plugin manager. Each component is also on the release page as a standalone package.

Create deck needs Materials, Question bank and Question generation. Practice, Mistakes & weak points, Mock exam and Statistics need Question bank and Practice & review. When a page’s components are off, StudyHub hides the page or says the feature is off. Saved sources, decks and progress stay. Finish related background tasks before you turn a component off.

Turn on Question bank and Practice & review before you delete a source, so StudyHub can check the questions, drafts and study records that cite it. If more than one installed package provides a component, turn it off in all of them. Update an old complete package before you customise.

To install from a terminal, keep your profile name (web for dsh web): dsh plugin --profile web add <package-URL-or-absolute-path>. For desktop DSH, use the plugin manager; a command-line install works only after desktop DSH is fully quit, including the tray icon.

Run DSH in your browser

For Linux, or browser-only use on Windows or Mac, install Node.js 22.19 or later and run:

npx @deepseek-ai/dsh web

DSH opens at http://127.0.0.1:3080 by default. Keep the process running, then install StudyHub. If you already run DSH web, skip this step.

Set up a model provider

Save an API key in DSH Settings › Models, then choose a model in your session. Generation, explanations, Help me understand, proofreading and translation need a model. The sample tour, browsing sources and practising existing decks do not.

Everyday use: the official DeepSeek API

Create an API key on the DeepSeek platform and save it on the DeepSeek card in DSH Settings › Models. The built-in DeepSeek card needs no endpoint. StudyHub generates with the session’s model by default; to use another configured model for questions and explanations only, choose a Generation model in StudyHub Settings › Library & model.

Heavier use: check a Coding Plan first

Choose a plan only if it gives you an API key and allows DSH and your study use. Before buying, check the permitted tools and uses, the dedicated base URL, model IDs, concurrency limits and quota resets. A key alone does not make a plan usable from any application; some plans allow only named coding tools (in Chinese).

To add a permitted plan, choose Add model provider in DSH Settings › Models. For any other endpoint, choose Custom model API and enter its base URL, API protocol, key and model ID. A plan’s dedicated endpoint and its ordinary API may draw on different quotas. See DSH’s model configuration guide.

Claude and ChatGPT subscriptions are not API keys

DSH’s model settings do not accept OAuth subscriptions such as Codex. A Claude Pro/Max or ChatGPT/Codex subscription cannot be pasted here as an API key. You can add the separately paid Anthropic or OpenAI API as a third-party provider; it is billed separately from the subscription.

Recordings: a transcription provider

Turning recordings into text needs its own provider, set in StudyHub Settings › Audio transcription. SiliconFlow SenseVoice, Gemini and Groq are supported. Check each provider’s current availability, allowances and pricing. Real-time transcription in Live class works only with Gemini. Proofreading and translation then use your DSH session model by default.

This guide collects no keys. Save model keys only in DSH Settings › Models and transcription keys only in StudyHub Settings › Audio transcription. Never paste a key into a chat, a source or a deck.

Update StudyHub

DSH plugins do not update themselves, and restarting DSH alone keeps the installed version. Your library and settings are kept.

  1. From 2.1.2, a Version x.y.z available chip appears in StudyHub’s sidebar when GitHub has a newer release. Click it, then Upgrade to x.y.z and Upgrade now.
  2. If background tasks are running, Stop tasks and upgrade stops them and keeps their finished parts; or wait until they are done.
  3. StudyHub checks the package’s SHA-256 against SHA256SUMS-x.y.z.txt and installs it through DSH’s plugin manager.
  4. Restart DSH: quit desktop DSH fully, including the tray icon, and reopen it; or restart the web service the way you usually do (same profile) and reload the page. Reloading the browser alone is not enough.

Before 2.1.2, or if the one-click upgrade fails: in DSH’s Plugins page, Uninstall StudyHub, then Add plugin with the new package address, click Enable and restart DSH. Finish or cancel background tasks first.

StudyHub asks GitHub for a new release at most once every 6 hours and sends no study data. Turn this off in StudyHub Settings › About & updates.

Choose English or Chinese

On first use, StudyHub follows your browser’s preferred language: Chinese for a Chinese browser, English otherwise. Switch with Language at the bottom of StudyHub’s sidebar; this browser remembers your choice. Switching does not translate saved sources, questions, notes or file names.
