Packages and checksums · Download the complete plugin

Updating: DSH plugins do not update themselves, and a restart alone keeps the installed version. From 2.1.2, StudyHub shows a chip when GitHub has a newer release; Upgrade verifies the package’s SHA-256 and installs it through DSH’s plugin manager (switch the check off in Settings › About & updates). On older versions: in Plugins, uninstall StudyHub, then Add plugin with the new package address. Finish background tasks first, then restart DSH: quit desktop DSH fully and reopen it, or restart the web service with its original profile. Refreshing the browser alone is insufficient.

If URL installation fails, download the .tgz and use its absolute path on the computer or server running DSH. A laptop download path is not a remote server path; prefer the HTTPS address above.

Advanced: customize and enable/disable components

The complete package contains the workbench, runtime, materials, bank, learning, generation and audio. Expand the package in DSH’s plugin manager to toggle components. Standalone component archives are also available on the release page.

Generation needs materials, bank and generation; practice and exams need bank and learning. Missing capabilities hide their entries or show a disabled notice. End related tasks before disabling. Saved materials, decks and progress remain.

Enable bank and learning before deleting sources, so references can be checked. If multiple installations supply a capability, disable every provider to turn it off. Update an old complete workbench before customizing.

New user: DSH in your browser

For Linux, or browser-only use on Windows or Mac, install Node.js 22.19 or later and run:

npx @deepseek-ai/dsh web

Keep the process running. DSH opens at http://127.0.0.1:3080 by default; then add StudyHub. Existing web users skip this startup step. Linux uses the official npm route.

Configure a model provider

Save an API key in DSH Settings → Models, then choose a model in your session. Generation, explanations, proofreading and translation need a provider; material browsing and existing-deck review work without one.

Everyday use: official DeepSeek API

Create an API key at the DeepSeek platform and save it on DSH’s DeepSeek model card. Built-in configuration needs no manually entered API endpoint.

Higher usage: check Coding Plan compatibility

Choose a plan only if it provides an API key and permits DSH and your actual study use. Check supported tools, uses, dedicated endpoint, model IDs, concurrency and quota rules before buying. Some plans are restricted to coding tools; having a key does not permit arbitrary applications.

For an eligible third-party plan, use Add model provider. A custom endpoint needs its actual protocol, address, key and model ID. Dedicated and standard API endpoints may bill different quotas.

Claude/Codex subscriptions are not general API keys

DSH’s current model settings do not accept Codex-style OAuth subscriptions. Claude Pro/Max and ChatGPT/Codex allowances cannot be pasted here. Separately paid Anthropic and OpenAI APIs can be configured; billing is separate from subscriptions.

Claude billing explanation · OpenAI billing explanation

This guide collects no credentials. Save keys only in DSH settings. Original audio transcription separately needs a transcription provider (SiliconFlow SenseVoice is free and reachable from mainland China; Gemini and Groq also work) under Study Settings → Audio transcription; your model provider handles later proofreading, translation and learning help.

Choose English or Chinese

New users get the browser’s preferred interface language; non-Chinese browsers start in English. The workbench language switch remembers your choice. Saved sources, questions and notes remain in their original language.
