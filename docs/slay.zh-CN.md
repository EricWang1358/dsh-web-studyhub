# 斩题

不想再学的题可以「斩」掉。它会立刻退出练习和复习，但不会删除：题目内容、复习进度和作答历史都保留，随时可以恢复到原题组。

## 斩掉一道题

- **练习时**：点工具条上的「更多」，选「斩掉此题」。练习自动进入下一题。
- **在题组管理页**：用「管理题组」打开题组，点题目下方的「斩」。

第一次斩题时，StudyHub 会创建斩题组。每个学习库只有一个斩题组。

## 立即撤销

练习时斩题后，提示条上有「撤销」。点它会立即把题放回原题组，复习进度不变。恢复的题不会回到当前这一轮练习。

## 找到已斩的题

在「学习库」页，用下面任一方式：

- 打开题组列表上方的「整理与添加」，选「斩题组（N）」。
- 打开「已归档」筛选，斩题组和已归档的题组列在一起。

斩题组里每道题都标有原题组名称和斩题日期。

## 恢复一道题

打开斩题组，点题目下方的「恢复原题组」。

- 复习进度保持不变。
- 斩题前已暂停的题，恢复后仍是暂停状态；否则恢复正常学习。
- 原题组已整组并入别的题组时，题会恢复到并入后的题组。
- 原题组已归档时，恢复后原题组仍是归档状态。
- 原题组或它正在编辑的草稿已有 100 题时，不能恢复。先整理这个题组，再恢复。

## 斩题会改变什么

- **题目迁移**：题移入斩题组，并在那里暂停。
- **从练习中移除**：所有未结束的练习里，这道题和它的重练副本都会移出，不新增评分记录。已结束的练习和历史作答不会改写。
- **斩题组不参与学习**：斩题组不参与日常复习、学习路径和模拟考试，不能整组取消归档或恢复学习，只能逐题恢复。
- **斩题组不能修改**：斩题组不能编辑，里面的题也不能暂停，需要先恢复。
- **编辑草稿同步更新**：原题组正在编辑时，草稿会同步去掉这道题，旧窗口发布草稿也不会把它带回来。恢复时，题会重新加回草稿。
- **前置关联跟着走**：斩题期间，这道题不会出现在待学的前置题里；恢复后，原有关联继续可用。
- **不限题数**：斩题组可以容纳任意多道题。

## 给 agent 和开发者

英文界面把「斩」称为 Retire，把斩题组称为 retired deck；接口和代码里叫 slay / slain。

- `card.slay {cardId, deckId?, runId?}`：斩题。只在学习者要求时调用。
  - 传入 `runId` 时，先确认这道题仍是该练习的当前题，再返回更新后的练习视图。
  - 不传 `runId` 时，返回斩题组 ID 和卡片 ID。
- `card.restore {cardId, deckId?}`：把已斩的题恢复到原题组，返回题组 ID、卡片 ID 和题组名称。
