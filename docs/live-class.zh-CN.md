# 课堂实录

边上课边转写：每句先出原文，下面紧跟简体中文译文。上课途中可以选中重点句子直接出题；下课后可以把整堂课连同课堂笔记保存为资料。1.4.0 起提供。

## 开始前准备

需要：

- **一个转写引擎**，二选一：
  - **本地转写（声音不上传）**：在这台电脑上运行，不需要密钥，一键安装，见[本地转写](#本地转写声音不上传)。
  - **Gemini 密钥**：用 Google Gemini 的实时接口。请确认 Gemini 当前的账户、地区和额度要求。在「设置 › 音频转写」的 Google Gemini 卡片里粘贴密钥，点「保存并验证」。

  两者都还不能用时，页面显示「先装一个转写引擎」，里面是本地引擎的卡片和「改用 Gemini 密钥」按钮（这台电脑没有本地引擎时，显示「课堂实录需要 Gemini 密钥」）。
- **翻译与校正用的模型**。默认有 StudyHub 的生成模型就用它，否则用 Gemini，见[设置项](#设置项)。
- **StudyHub 的生成模型**（默认跟随主会话）：上课途中要出题时需要。
- **能采集声音的浏览器**：较新的 Chrome 或 Edge，页面要通过 HTTPS 或 localhost 打开。浏览器询问时，允许使用麦克风，或共享标签页。

硅基流动 SenseVoice 和 Groq只能处理录音文件。两种引擎都用不了时，可以先用别的方式录下来，课后在「音频转写」页导入，见[音频导入](audio-import.zh-CN.md)。

上传录音前，请阅读 Gemini 卡片的隐私和地区提示，并核对 Google 当前的服务条款。

## 本地转写（声音不上传）

本地转写提供速度档 SenseVoice Small int8 和质量档 Whisper large-v3-turbo int8，通过 sherpa-onnx 和 silero 语音检测在 StudyHub 的后台线程里运行。SenseVoice 支持普通话、英语、粤语、日语和韩语，Whisper 支持多语种，中文直接写成中文。声音不会离开这台电脑。安装时要联网下载一次引擎和模型，设置了文字模型时，翻译和润色仍用它（见下）。思路和最初的移植来自社区用户 BAXUIE 的 StudyHub for ZCode。

在本地转写卡片里选择档位，装好后点「新实录使用此模型」。两档使用独立的安装目录和下载进度，可分别暂停、继续、修复和删除。原有安装继续使用 SenseVoice，新实录采用你的选择，「接着录」保留课堂原来的模型。

质量档模型约 989 MB，Windows 首次安装下载约 999 MB、占用约 1013 MB，默认目录是 `StudyHub\LiveLocalWhisperTurbo`。它使用修复中文 BPE 字节处理的 sherpa-onnx 2.0.1，速度档保留 1.13.8。质量档在自然停顿或连续语音约 15 秒时提交定稿，关闭反复解码的临时预览。Ryzen 9 7945HX 上的中文合成语音测试内存峰值约 1.6 GiB，真实网课和普通笔记本的效果仍需对比，模型更大也会有同音词和术语错误。Whisper 文件从固定 ModelScope 版本下载，下载无进展或失败时尝试固定 Hugging Face 备用源，使用相同 SHA256 校验。原始 Whisper 权重使用上游 MIT 许可。[Whisper 模型说明](https://huggingface.co/openai/whisper-large-v3-turbo)、[引擎中文处理修复](https://github.com/csukuangfj/sherpa-onnx/blob/af2d8d81/sherpa-onnx/csrc/offline-recognizer-whisper-impl.h#L175)

以下大小与默认位置说明对应速度档。

- **安装**：在「课堂实录」页，或「设置 › 音频转写 › 课堂实录的转写」里点「安装本地转写引擎」。分三步：「安装识别引擎」「下载识别模型」「检查能不能用」。进度显示在卡片上和「任务」里；「暂停」会保留已下载的部分，「继续安装」从停下的地方接着装。
- **装在哪里**：默认装在剩余空间最大的非系统盘的 `StudyHub\LiveLocal`（「选择位置」可以换）：`engine\node_modules` 是识别引擎，`models\sense-voice` 是模型。不往 StudyHub 自己的安装包或系统里加任何东西。
- **大小**：Windows 上首次安装下载约 239 MB：识别模型约 228 MB、语音检测模型约 2 MB、识别引擎约 9 MB。装好后占用约 253 MB。
- **下载什么、怎么核对**：识别引擎是 npm 包 `sherpa-onnx-node` 和这台电脑对应的预编译包，固定 1.13.8 版，从 npmmirror（或 registry.npmjs.org）下载，逐个和 npm 官方为这一版公布的 sha512 校验值核对。模型文件来自魔搭 ModelScope 的固定版本，逐个和魔搭文件信息里的 sha256 核对。不对的文件会删掉重下；中断的下载从 `.part` 文件接着下。社区版已经下载到 `~/.dsh/live-models/sense-voice` 的模型，核对一致时直接复用。
- **哪些电脑能用**：Windows（x64）已测试。macOS（Apple 芯片和 Intel）和 64 位 Linux 用的是同一版预编译引擎，但还没有测试；其他电脑（例如 ARM 版 Windows）会提前说明没有本地引擎。
- **准确度和速度**：识别结果会受口音、背景声和专业术语影响，请对照原声核对。自然停顿后会提交已识别的句子；连续讲话约 15 秒也会提交一段，尾部短句在结束时保留。加载和识别速度取决于电脑性能。
- **翻译和校正**：仍用你设置的文字模型（文字会发给模型服务商）。没有文字模型时只显示原文。已经是中文的句子不再送去翻译。
- **修复**：装好后如果引擎文件被删除或改动（例如被杀毒软件隔离），卡片显示「需要修复」而不是可以用了，「修复」只补装出问题的部分。安装时会记下每个引擎文件的大小和校验值，每次读取状态都会再核对原生库。
- **磁盘空间**：「继续安装」「重试」「修复」只需要还没完成部分的空间，不会按整个安装重新要求。
- **删除**：设置里的「删除本地转写引擎」只删除 StudyHub 装的内容；任何一个学习库里有课堂正在用它时都不能删除。
- **每堂课用哪个引擎**：「自动」（默认）在填了 Gemini 密钥时用 Gemini，没有密钥时用本地转写。「本地转写（声音不上传）」和「Gemini（云端）」按你的选择来，课堂不会自己换成另一个引擎。两者都能用时，开始表单里还有「转写」可以为这一堂课单独选择。「接着录」用这堂课录的时候的引擎；那个引擎现在用不了时，页面会说明，并把另一个引擎作为单独的按钮。引擎只由你选：主会话里的助手不能改。

## 录一堂课

1. 打开侧栏「课程准备与管理」组里的「课堂实录」。
2. 填「课堂名称」。不填时自动命名为“课堂实录”加日期和时间。
3. 选「声音来源」：
   - **「麦克风（现场课堂）」**：采集默认麦克风输入。
   - **「电脑系统声音（客户端 / 网课）」**（Windows 10/11 桌面客户端默认提供；Windows 浏览器中显示为「电脑系统声音（本机组件直采）」）：按需热安装轻量本机组件，直接只读采集耳机或扬声器正在播放的声音，不弹共享窗口。
   - **「标签页 / 系统声音（网课）」**：通过浏览器的标签页共享窗口采集网课声音。
4. 可选：选「课程归属」；展开「课程背景与术语（可选）」，填「这堂课讲什么」和「术语（逗号或换行分隔）」。
5. 可选（仅 Gemini）：勾选「只用付费密钥」，不使用 Gemini 免费密钥。
6. 点「开始实录」。若选的是「标签页 / 系统声音」，要在浏览器的共享窗口里选正在播放课程的标签页，并勾选「共享标签页音频」（只发送声音，不发送画面）；若选的是「电脑系统声音」且尚未装过组件，先在页面卡片上点一次「安装电脑声音组件」（1–3 秒完成）即可开始。

术语能帮助识别、翻译和校正。你填的术语排在前面，之后补上所选课程的题组标题和题目主题，合计最多 100 个。

老师开讲后，逐字稿会陆续出现：

- 每句先显示原文，下面是简体中文译文；译文到达前显示「正在翻译…」。
- 还在识别的文字显示在最下方，末尾带“…”，这时还不能选。
- 译文固定是简体中文，界面切到 English 也一样。
- 「正在跟随最新」会让最新一句始终可见；往上翻看时变成「回到最新」。

### 浏览器拒绝共享标签页时

选了「标签页 / 系统声音」而浏览器拒绝时，红色提示会说明是下面哪种情况，提示下面的按钮直接带你走下一步：

- **共享窗口弹出来了，你关掉了它。** 再点一次「开始实录」，选标签页并勾选「共享标签页音频」。
- **根本没有弹出窗口（几分之一秒内就被拒绝）。**
  - **在某个应用内置的窗口里**（例如桌面客户端或嵌了一个浏览器视图的应用）：这个窗口不允许标签页共享，再试也没有用。Windows 10/11 上可以直接在提示卡片里一键安装或切换「电脑系统声音」直采；其他系统可点「改用麦克风并开始」，或在 Chrome / Edge 的独立窗口里打开 StudyHub。
  - **嵌在别的页面里**，而那个页面的权限策略不允许屏幕共享：做法相同。
  - **在 Windows 或 Linux 的普通浏览器窗口里：** 共享标签页通常不需要系统授权。常见原因是工作或学校的管理策略：在地址栏输入 `chrome://policy` 或 `edge://policy`，找和屏幕捕获有关的条目。Windows 上可直接改用「电脑系统声音」本机组件；改好策略后也可点「再试一次共享」，或者改用麦克风。
  - **在 macOS 上：** 打开「系统设置 › 隐私与安全性 › 屏幕与系统音频录制」，打开浏览器的开关，完全退出浏览器再重新打开，然后点「再试一次共享」。

提示下面的「排查信息」列出 StudyHub 观察到的情况：浏览器、系统、这是独立页面、嵌入页面还是应用内置的窗口、权限策略是否允许共享，以及从你点击到被拒绝过了多少毫秒。向别人求助时可以带上。

麦克风来源不需要共享权限：把课程声音外放，让麦克风收音（戴耳机不行）。

### 不共享也能录电脑的声音（Windows）

在 Windows 10/11 的桌面客户端或不支持标签页共享的窗口里，推荐使用内置的**电脑声音直采组件（热插拔）**：

- **按需热安装，无需联网下载**：平时安装包里不预置任何原生程序或驱动。只在你点「安装电脑声音组件」时，调用 Windows 自带的 `.NET Framework` 编译器在独立目录（默认 `StudyHub\LiveLoopback`）本地生成约 20 KB 的只读采音程序并记录 SHA-256 校验值，通常只需 1–3 秒。
- **不装虚拟声卡、不改系统设置、支持蓝牙耳机**：通过 Windows 原生共享环回接口（WASAPI Loopback）只读监听当前默认播放设备（扬声器、有线耳机或蓝牙耳机），不安装任何内核虚拟声卡驱动，不改动默认录音设备，也不会触发蓝牙耳机的通话降质模式；课堂途中插拔耳机或切换播放设备会自动跟随。
- **平时与暂停时零后台进程**：空闲时不运行任何进程；点击「暂停」或「结束实录」（或关闭窗口）都会立即退出进程并释放全部声卡句柄，避免平时不用时干扰电脑声卡驱动。
- **随时修复或一键卸载**：每次启动前都会核对组件文件的大小与 SHA-256；不用时可在「设置 › 音频转写 › 课堂实录的转写」里点「卸载电脑声音组件」一键清除。

如果电脑禁用了系统编译器，也可以手动把 Windows 的「立体声混音」或虚拟声卡设为默认录音设备：

1. 右键任务栏的喇叭图标，打开「声音设置」，再点「更多声音设置」，切到「录制」标签。
2. 找「立体声混音」。看不到的话，在空白处右键，勾选「显示禁用的设备」，再右键「立体声混音」，选「启用」，再选「设为默认设备」。
3. 在「课堂实录」里选「麦克风（现场课堂）」，点「开始实录」；上完课后记得把真正的麦克风设回默认录音设备。
4. 「立体声混音」只混合声卡自己播放的声音；蓝牙耳机在手动方案下需改用虚拟声卡（如 VB-Audio Virtual Cable）。

### 录音时的按钮

| 按钮 | 作用 |
| --- | --- |
| 「暂停」/「继续」 | 暂停期间不上传声音，上下文校正也一起暂停；使用电脑系统声音组件时还会立即退出采音进程、释放声卡，点「继续」再重新拉起。 |
| 「结束实录」 | 停止采音，释放麦克风、共享标签页或电脑声音组件。剩下的句子在后台继续翻译和校正。 |
| 「接着录」 | 已结束的课堂才有。继续录进同一堂课，保留原来的名称、课程、背景和术语。 |

### 什么会继续、什么会结束实录

- 切到「待办」「资料」等其他 StudyHub 页面，实录继续。
- 同一个学习库同时只能有一场实录。
- 在浏览器里停止共享，实录结束。
- 切换学习库，实录结束。
- 录音时关闭或刷新页面，浏览器会先弹出离开提示。仍然关闭时，采音立即停止；StudyHub 在 90 秒没有联系后自动结束这堂课（暂停中的课堂为 30 分钟）。已收到的文字都会保留。

## 检查声音输入

连接期间显示「输入音量」面板；录音时，课堂名称下方有一条细栏，显示设备名称、音量条和状态。

| 状态 | 怎么办 |
| --- | --- |
| 「收到声音」 | 不用处理，声音正常进来。 |
| 「声音很低或静音」「设备已静音」 | 麦克风：对着它说话，看音量条；一直不动就检查系统输入设备、静音开关和距离。网课：确认课程正在播放、勾选了共享音频、播放器没有静音。 |
| 「声音过大」 | 调低系统输入音量，或离麦克风远一点。 |
| 「浏览器采音已中断」「未收到音频」 | 浏览器没有持续送来声音。检查设备或共享状态，必要时结束后重新开始。 |
| 「等待麦克风或共享权限」 | 在浏览器弹出的麦克风或共享提示里作出选择。 |

「声音详情」里写着一个事实：「电脑已收到声音 2 分 32 秒 · 已识别 12 句」。收到声音不等于已经转成文字，所以后面跟着已识别的句数。

上传积压约 30 秒时，StudyHub 会停止实录，已收到的内容保留。检查网络后点「接着录」。

音量条反映实际送去转写的声音的相对大小，不是校准过的分贝，也不判断是不是人声。

## 边录边出题

1. 选句子，三种方式任选：
   - 勾选句子前的方框；
   - 用鼠标划选原文或译文，划到的每一句都会选中；
   - 点「最近一段」：选中最近约 1200 个原文字符（一句特别长时，就是这一句）。
2. 原文至少约 120 个字符，最多 400 句。选择栏会提示还差多少字符；点「清空」取消选择。按钮灰着时，悬停或聚焦它会说为什么。
3. 「题数」设为 1–15，默认 5。
4. 点「选中内容出题」，实录不中断。
5. 进度可在「任务」查看；草稿生成后出现在「学习库 › 待发布草稿」，照常检查并发布。

背后发生的事：

- StudyHub 先把选中内容保存为一份资料，以课堂名称和时间段命名。资料里每句都带时间和中文译文，题目可以引用它。之后的校正不会改动这份快照。
- 出题走常规流程：生成、审核、草稿。题型为「测验 + 闪卡」，难度「混合」，题目语言跟随界面语言。
- 用过的句子标上「已用于出题」。

## 看懂校正标记

录音期间，StudyHub 每 30 秒结合上下文复查新句子，修正明显的识别错误。每句右侧的标记表示结果：

| 标记 | 含义 |
| --- | --- |
| 实心绿点（「已润色」） | 这句被改过。鼠标悬停可看原因；展开「查看识别原稿」可对照第一次识别的原文。 |
| 空心绿圈（「已检查未改」） | 检查过，无需修改。 |
| 没有标记 | 还没轮到检查。 |

逐字稿上方的「上下文润色」一行统计已检查、已润色和待处理的句数，并附图例。「说明与用量」里有模型调用次数、本地结果复用次数，以及服务商返回的缓存输入 tokens。

标记只反映模型高置信度的改动。空心圈或没有标记，都不代表这句一定正确；“已检查”只表示已提交校正，不保证准确。

检查失败时，错误显示在「上下文润色」一行，待处理的句子保留。课堂结束后或出错后，点「重试待校正内容」。

### 检查怎么进行

- 按顺序分批：每批最多 8 句（约 1,200 字）新内容，再带上前面最后 2 句（约 300 字内）作重叠上下文。特别长的一句会单独成批；更早的长句只带它的结尾，作为只读上下文。
- 每次请求允许的时间和回复长度，随它要读多少、预计要写多少而定，最多 60 秒、8,192 个 token。模型只返回要替换的几个词（小改动），不再把整句重写一遍；原文不是中文时才附中文翻译。
- 请求超时或回复被截断时，先用一半的文字重试一次，再逐句重试；仍然失败的句子会被**跳过**（原文保留），检查继续往后走。点「重试待校正内容」可以重新校正被跳过的句子。网络或额度问题最多在之后的检查里重试 3 次，然后等你点击。
- 累计摘要每隔几批才重写一次，不是每次调用都写；模型写错的笔记或摘要会被丢弃，不会连累这一批的校正。
- 每次检查会把开始时已有的积压全部处理完；检查途中新到的句子留给下一次。「结束实录」时会把剩下的补齐。
- 没有新句子时不调用模型。暂停期间不检查。
- 每批读取本批窗口、课程背景、术语、最多 1,600 字的累计摘要和最近 3 条笔记，写出本批笔记并更新摘要，不会把越来越长的整份历史反复重发。
- 只接受对已有句子、且模型标为高置信度的修改。原文和简体中文一起替换，第一次识别的原文折叠保留在句子下方。
- 校正之前发出的翻译请求，不能覆盖已校正的句子。此前选句出题时保存的资料是独立快照，不会被改写。

## 查看课堂笔记

逐字稿下方的「查看课堂笔记」汇总校正过程中整理出的内容：

- 「累计摘要」：到目前为止的课堂摘要，每批校正后更新。
- 「分批笔记」：每批的学习要点；标有「历史校正补记」的条目来自历史歧义校正。
- 「历史歧义校正」：复查旧句子的请求及其状态。

点句子编号（如「句 12」）可跳回逐字稿里的那一句。

### 历史歧义校正

有时后面的话会说明，当前窗口之外的某句旧话识别错了。这时逐批校正会另外提出一条请求，写明 1–20 个具体的旧句子编号和疑点。

- 请求在后台逐条处理，同一时间只跑一条，并把提出请求的那一批作为证据。实录和逐批校正不必等它。
- 每条请求显示「排队中」「处理中」「已完成」或「待重试」。点「重试历史歧义校正」可以重跑失败的请求。
- 合并结果前，StudyHub 会核对相关句子在请求之后有没有变过。过期、超时（60 秒）或失败的结果都不合并，保留为可重试请求，也不会显示为已完成。

由哪个模型处理，取决于「校对与翻译用哪个模型」（见[设置项](#设置项)）：

- **Gemini**：直接调用 Gemini，不经过 DSH 子代理。
- **StudyHub 的生成模型**：交给一个 DSH 子代理处理；它没有任何工具，也不能继续委派。DSH 不能运行子代理时，直接调用同一个模型。子代理一旦开始，失败后不会换路线重跑，请求保留待重试。

## 保存课堂

点「结束实录」后，页面底部有这些按钮：

| 按钮 | 作用 | 费用 |
| --- | --- | --- |
| 「保存为资料」 | 下课后随时可以点，不会因为润色或译文没做完而点不了。润色和译文都完整时，立刻保存中英对照逐字稿（课堂特别长时是几份）和课堂笔记。还有没做完的，会开一个「任务」：先补完润色（最多约 4 分钟，润色不了的句子保留原文）和失败的译文（最多约 90 秒），再保存；做不完的在任务的提示里写明，文字稿照样保存。没有文字模型时只存文字稿，并明说没有保存笔记。 | 补做的部分按文字模型计费；没有要补的就不调用模型（课堂笔记除外，见下） |
| 「校对后保存」 | 启动一个后台任务：校对识别错误的词，重新翻译，再保存。它使用音频设置里「校对与翻译」的档位，和录音导入共用一条队列，一次只处理一条录音。设置不变时再次保存同一堂课，会复用已保存的资料。 | 免费额度，或按服务商计费 |
| 「打开资料」 | 打开「资料」页。 | |

两种保存都会另存一份课堂笔记资料，包含累计摘要、分批笔记和带时间的句子引用；失败的历史歧义校正请求会列在其中的“待核对”一节。润色没有整理出笔记（每一批都超时或被跳过，或当时没有模型）时，保存会用文字稿另外整理：按约 8000 字分段，最多 8 次请求，每段给出摘要和引用句子的要点。没有文字模型就不存笔记，并在提示里说明。

润色因出错暂停时，「上下文润色」一行里会写明原因，旁边是「重试待校正内容」和到「设置 › 音频转写」换文字模型的入口。

某句译文暂时没有时，那一行下面只有一行小字「译文暂时没有」；点逐字稿上方唯一的「重试失败的翻译」再试。本来就是中文的句子不会翻译，也不会显示译文行。

## 管理历史课堂

页面底部的「历史课堂」按时间从新到旧列出未归档的课堂，显示时长和句数。

- 「打开」查看一堂课。正在录音时不可用。
- 「归档」把课堂移到「归档课堂」。正在录音的课堂要先结束。
- 在「归档课堂」里可以「打开」「恢复」或「删除」。删除不再弹确认：课堂立刻从列表里消失，底部提示约 8 秒内可以「撤销」；提示离开后才真正删除实录、译文和课堂笔记（另存的学习资料保留）。
- 已归档的课堂要先恢复，才能接着录。
- 永久删除会移除这堂课的逐字稿、译文和课堂笔记，无法撤销。已经另存的资料会保留在学习库里。

在主对话里，StudyHub 也可以列出你的课堂、读取某堂课的逐字稿和译文，或把已结束的课堂保存为资料。开始录音只能在「课堂实录」页。

## 设置项

课堂实录使用「设置 › 音频转写」里的引擎选择、Gemini 密钥和模型；模型选项在「高级 › 专家选项」里。

| 设置项 | 选项与作用 |
| --- | --- |
| 「课堂实录用哪个引擎」 | 「自动（推荐）」：填了 Gemini 密钥就用 Gemini，否则用本地转写。「本地转写（声音不上传）」或「Gemini（云端）」：一直用这个引擎；用不了时说明原因，不会换成另一个。选项下面是本地引擎的卡片（安装、进度、删除）。 |
| 「校对与翻译用哪个模型」 | 默认「自动（有生成模型就用它，否则用 Gemini）」，另有「Gemini（同样先免费后付费）」和「StudyHub 的生成模型（默认跟随主会话）」。实时翻译、上下文校正和历史歧义校正都按这里的选择。 |
| 「课堂实时转写模型」 | Gemini 实时模型，默认 `gemini-3.5-transcribe-live`。 |
| 「课堂实时翻译模型」 | 实时翻译和上下文校正用的 Gemini 模型，默认 `gemini-3.5-flash-lite`。选了「StudyHub 的生成模型（默认跟随主会话）」时不显示。 |
| 「课堂实录的上下文校正推理强度」 | 当前模型自己的档位或「模型默认」，默认「低」。模型没有的强度会对应到最接近的档位，下拉框里会写明。对上下文校正和历史歧义校正都生效。 |
| 「Gemini 付费密钥（可选）」 | 直接在「高级」里。免费额度用完时使用；勾选「只用付费密钥」时一直使用。 |

推理强度的实际效果：

- 用 StudyHub 的生成模型时，校正不会继承主对话的高推理档位；模型没有低档时用它的默认设置。
- 用 Gemini 时，Gemini 3 系列使用低思考档位，Gemini 2.5 系列使用较小的思考预算，其他模型用默认设置。

## 费用、密钥与隐私

- 课堂实录先用 Gemini 免费密钥；免费额度用完或被限流时改用付费密钥，某把密钥被拒绝时换另一把。这些切换记录在「连接与额度提示」里。
- 勾选「只用付费密钥」后，转写、翻译和校正都不使用免费密钥。
- 页面底部的「付费转写估算」只算付费转写，不含翻译和校正。
- 用 StudyHub 的生成模型校正时，按服务商计费，由 DSH 统计，不计入 Gemini 的用量数字。
- 校正请求使用固定的提示前缀，方便服务商复用缓存；StudyHub 记录服务商返回的缓存输入 tokens。另有本地缓存，最多复用 8 个相同请求的结果。缓存命中和折扣都不保证，StudyHub 也不会创建另行计费的显式缓存。
- 用本地转写时声音不上传，也不为它计费：课堂不计免费或付费分钟。设置了文字模型时，翻译和润色会把文字发给模型服务商。
- 密钥只保存在这台电脑的音频设置文件里，不随浏览器的音频消息传输，也不写进课堂文件。不要把密钥贴到主对话里。

## 保存与恢复

- 每堂课保存在当前学习库的 `live/<id>.json`，不保存原始录音。
- 内容变化后约 3 秒自动保存，多次保存按顺序进行。保存失败时页面会提示，文字暂留在内存里。
- 进程崩溃或突然断电，仍可能丢失最后几秒还没写入的内容；原始录音没有保存，这部分无法找回。
- 关闭页面后，没做完的翻译和校正会在 StudyHub 后端继续处理。
- DSH 重启后，没翻译完的句子显示为翻译失败，被打断的历史歧义校正显示「待重试」，在页面上重试即可。笔记、校正进度、历史歧义校正请求和归档状态都会保留。
- 「接着录」和删除都会先等后台处理和保存完成，避免旧实例覆盖接着录的课堂，或把已删除的记录重新写回。
- 课堂文件独立于学习库的主数据，不算资料，也不在学习库备份里。要把一堂课变成普通资料，点「保存为资料」。

## 实现细节

- **采音**：浏览器的 AudioWorklet 把输入混成单声道，转换为 16 kHz、16-bit 小端 PCM，约 100 ms 一帧。麦克风开启回声消除和降噪。采音工作线程的源码写成字面量，避免生产构建压缩时被改名破坏。
- **连接**：由 StudyHub 后端持有到 Gemini Live 的 WebSocket，收到 Google 的 setup 完成确认后才发送音频。单个连接最长 10 分钟，StudyHub 在第 8 分 45 秒（或 Google 提前通知断开时）开新连接；旧连接最后的文字收齐后，才显示新连接的文字。
- **重连**：切换连接不是服务端会话恢复，故障时仍可能丢失尚未最终确认的词。断线后 StudyHub 以逐渐拉长的间隔重连，期间最多缓存最近 30 秒的声音。重连失败时状态变为「连接中断」，已有文字已保存，可以点「接着录」。
- **本地引擎**：识别在一个工作线程里运行。一个本地回环连接讲和 Gemini Live 一样的消息，所以实录会话、页面和保存的课堂都照旧。语音检测在设定的停顿后结束一句，连续讲话达到约 15 秒时会主动提交一段。正在说的那句约每 0.6 秒解码一次，显示为灰色的临时文字。结束实录会等待已收到的声音识别完；识别长时间没有进展时，会明确提示未确认处理完成的时长。没有 10 分钟限制，也不需要换连接。
- **时间标记**：句子旁的时间是已录音频的累计时长，不含暂停。用来定位课堂位置，不是逐字时间戳。
- **翻译**：按顺序翻译，每次最多 6 句或 900 个字符，并附上前 3 句已有译文作上下文；每句最多尝试 3 次。翻译提示要求关键术语第一次出现时写成“中文（English term）”。
