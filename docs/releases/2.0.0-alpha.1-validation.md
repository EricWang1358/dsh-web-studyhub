## Alpha limits

- The advanced historical workflows retain a private compatibility kernel. New plugins use public owned APIs; this release does not finish rewriting every historical helper.
- Passage corners appear in the workbench reading view and native Study HTML. Native Markdown/PDF/TXT use the host viewer and a learning toolbar with associated questions.
- Complex rendered math or HTML may not map uniquely to projected text. The UI reports ambiguous or missing positions and supports choosing extracted text again.
- Originals are limited to 8 MB, text projections to 600,000 characters, and PDF imports to 200 pages. Text imports require UTF-8.
- Old PDF libraries that never retained original bytes keep their extracted text; an actual original must be explicitly attached to enable its original preview.
- Seven installer archives contain the shared compatibility code. Their enabled capabilities and lifecycle ownership are independent; archive size separation is future work.
