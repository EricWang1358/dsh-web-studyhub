# Guided calculation

After answering a practice question, choose **计算题引导练习 / Guided calculation** in the existing review panel. **逐步理解 / Guided understanding** retains the original prerequisite ladder. Neither option runs automatically or starts before the original answer.

Calculation practice has five stages: known conditions and unknown quantity; formula and why it applies; substitution and units; intermediate computation; result checks and rounding. Each stage presents one check. An incorrect response keeps that stage and the learner's input; a passing judgment advances once. Only the current stage is returned to clients. Private scoring references and future stages remain withheld; the transfer rule appears after all five stages.

Each calculation stage includes assumptions, units, rounding policy and exact quotations from the original question's cited sources. Unsupported quotations, missing metadata or stages in the wrong order reject the plan. The tutor is instructed to label constructed examples and identify missing conditions instead of inventing them. These checks establish quotation provenance and plan structure, not mathematical correctness or factual entailment. Generated prose and model judgments can still be wrong; verify the arithmetic independently.

Sessions persist separately by review, original question and mode. Reopening a cached mode makes it the selected session for reload. Existing sessions without a mode remain guided understanding. A changed original question invalidates new sessions' saved snapshot; navigation to another question does not redirect an in-flight result. Grading accepts an optional `stepIndex` to reject stale submissions, and checks the step again before committing. The current input draft uses optional browser session storage, isolated by library, session and step and capped at 10,000 characters. It restores after reload or switching modes, clears after completion, and never enters the learning library. Edits made while a response is pending stay in the input.

Runtime: `teach.start {runId,cardId?,index?,queueVersion?,mode?:understanding|calculation,language?:zh|en}`, `teach.get {id}`, `teach.answer {id,answer,stepIndex?}`. Starting requires an already answered question; new calculation plans also require cited source material. Cached sessions can reopen without a configured model. New plans and answers use the existing completion route and JSON parse retry budget; there are no extra review/model calls. This feature does not perform deterministic numeric checking or change Markdown rendering.
