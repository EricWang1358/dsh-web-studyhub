# Content Quality Protocol

## Node

A node must state a recallable core conclusion, relevant prerequisites, a
subject-appropriate example or derivation, common mistakes, and related next
material. Do not create a shallow node only to satisfy a quiz link.

When a node makes claims that depend on provided evidence, especially for
history, law, literature, or social science, `sources` must identify the
relevant source or passage and the body must distinguish evidence from
interpretation.

## Quiz

A quiz must have a clear answer, useful hint, direct explanation, common
misconception, and linked source material. A numerical or reasoning answer
must include enough intermediate steps to verify it. An open-ended quiz must
state a scoring rubric.

A teaching-derived supplemental quiz is allowed only when it tests a distinct,
independently gradable transfer target not already covered by a linked quiz. It
must link to the consolidated node and retain teaching provenance.

An evidence-based quiz must identify the supporting source or passage in its
prompt or explanation and explain how that evidence supports the answer.

## Recruitment Extension

When recruitment mode is active, read `references/recruitment-prep.md` and
apply it in addition to the generic quality rules. A node must be an
interviewable leaf that covers HOW, WHY, and WHERE and ends in an observable
output. A quiz must test one uncovered depth target and include a scoring
rubric, follow-up ladder, interview signal, and precise debrief action.

For multiple-choice or multi-select questions, use plausible alternatives at
the same abstraction level and similar length. Avoid joke answers, grammar
cues, repeated answer-position patterns, and a fixed number of correct
options. Every distractor should expose a real misconception.

## Daily Bite

A Bite has one source and one recall target. It must be short enough for quick
review and must not duplicate an entire quiz.
