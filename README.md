# DSH Daily Flashcard

原生 DeepSeek Harness 学习插件。把 `study-lib-spar` 的内容质量规则与 SM-2 调度，变成可操作、可验证、可持久保存的闪卡和测验工作区。

## 使用入口

安装后，会话视图增加 **学习** 标签；支持右侧工作区的 DSH 版本还可以在右栏打开 **学习**，与 Pair runtime 使用同一类原生扩展点。

打开即可使用：学习库默认放在当前会话工作区的 `.dsh-study/`（工作区根目录已有 `study-workspace.json` 时直接使用工作区本身），出题模型跟随对话输入框当前选择的模型。只有想改时才在 **设置** 里「更换目录…」（调用 DSH 自带的目录选择器）或从 DSH 模型目录中指定生成模型。改动保存在工作区的 `.dsh-study-binding.json`，不包含 API key；清空即恢复默认。

**首页是学习目录**（类似 NotebookLM 的资料/学习视图）：

- **今日学习**：一键「开始学习」，按路径排题：先复习到期 → 再补薄弱 → 按目录顺序学新题（每轮最多 10 道新题、共 20 题）；同一范围未完成的一轮会直接继续，不会重复开新轮。首屏同时给出「推荐下一步」主题。
- **目录树**：目录（题组的所在目录，可在「管理题组」中设置，如 `设计模式 / 第 4 章`）› 题组 › 主题。每一层都有掌握度进度条，颜色表示 已掌握 / 熟悉 / 学习中 / 薄弱 / 未学；勾选任意节点后「学习所选内容」，或点节点上的 ▶ 单独学习。
- **掌握度**由 SM-2 间隔与最近一次作答推算，不额外存储：答错为薄弱，间隔 ≥21 天为已掌握，≥6 天为熟悉。
- **和对话打通**：主题上的「问」、题组菜单「在对话中分析」、复习结束后的「在对话中讲解薄弱点」会把提示词填入对话输入框（不自动发送）。agent 也可以用 `map` 查看同一份掌握度与推荐路径。
- **`/study-spar <不会的问题>`**：在对话中直接输入。插件用会话模型判断它属于哪个题组、哪个主题，是否已有原题；已有则告诉你位置，没有就加入对应题组（没有合适题组时新建），默认存为闪卡，写「写成 MQ」存为单选题，「写成多选题」存为多选题。答案优先引用学习库原文；资料里没有依据时，会把模型写的说明另存为资料「补充笔记 · 主题」并明确提示你核对。`RabbitMQ` 这类词不会被误判为格式指令。

**现场对话录题**（创建题组 → 现场对话录题）：选好放进哪个题组（可新建并设目录）、题型（自动识别 / 闪卡 / 单选 MQ / 多选 / 开放问答）和错题记法，点「开始录题」后对话输入框会填好说明。之后这段对话里贴的刷题软件题目、Canvas 错题记录或截图，agent 都会用 `ingest` 直接录入，不需要先整理成文档、也不经过草稿：

- 保留原题干、选项和标准答案；每个选项写具体解析；贴的原文存为这批题的资料，引用即原文。
- 材料里没有答案时由模型推断，并给该题打上「答案由模型推断，待核对」标记；标明自己选错（或选了「全部当错题」）的题记为薄弱，学习路径优先出。
- 题库里已有的题会跳过并报告；格式校验不过的题会尝试修复一次，仍失败就列出原因。每次最多 60,000 字符，更长的分批。
- 录题期间面板顶部显示「录题中 · 题组 · 已录入 N 题」，可以点「停止录题」，或在对话里说「停止录题」。

**回到题目**（左侧导航第一项）：回到最近离开的那一轮练习、当时的那道题；没有进行中的练习就开始今日学习；还没有任何题目时显示为灰色，点击进入创建题组。

**做题卡住或题目质量不行时，回到对话解决**（题目页工具栏）：

- **不会？问 AI**：把这道题（题组、主题、题目、选项和题库定位 deckId/cardId）填进对话输入框，不附答案。你在对话里按自己的疑问追问；agent 每弄清一个前置点，就用 `capture`（`requiredBy` 指向这道题）把它加为前置题，题库已有的用 `card.link` 关联。也可以直接输入 `/study-spar 前置 <问题>`，会挂到面板里正在做的那道题上。
- **前置题**是可以随时增删的关联，不写死在题组里，也不影响复习进度；循环依赖会被拒绝。题目上方显示「前置题 N · 已掌握 M」，点「先学前置」学完后可「回到原题」。学习路径会把没学过或答错的前置题排在后面的题之前。
- **不额外加负担**：答对一道题时，它到期、薄弱或没学过的前置题（两层内）会一并记一次通过；尚未到期的不动。前置题和依赖它的题同时到期时，路径只出后面那道。
- **提升质量**：把这道题填进对话，你说哪里不好（例如「每个选项的解析太笼统」），agent 用 `card.update` 原地修改并说明改动。只改措辞和解析时保留复习进度，改了题干、答案或正确选项才重新开始；每次修改前的版本会保留，`card.revert` 可撤销上一次。正在做的这道题几秒内就会显示新版本。
- 在 DSH 主区域使用时，题目页可以「在右栏打开」，题目放到右侧栏，主区域继续对话。

1. **资料**：粘贴文字或导入 `.md` / `.txt`，可随时查看原文。
2. **生成**：选择资料、题型、数量、难度、语言和重点；可提供目标岗位，启用招聘准备规则。
3. **草稿**：生成与审题分开调用模型；编辑题目、选项、解释，校验后发布。高级 JSON 编辑器允许修改完整结构。
4. **学习**：单选、多选、开放问答、翻卡；提示、逐项解释、原文引用、题目标记和暂停后继续。
5. **复习**：到期队列、0–5 自评分、SM-2 下次复习时间、错题主题统计。
6. **逐步讲解**：答题后按前置关系逐步补齐理解，通过当前检查才进入下一步；小检查不额外更新 SM-2。

## 界面打磨与稳健性（0.4.1）

- **模拟考试上手引导**：考试页重构为规则徽章 + 题组选择面板；没有题组可选时给出带「创建题组 / 去学习库」入口的完整空态，而不是一行灰字。
- **页头与页宽统一**：考试 / 统计 / 错题本 / 创建题组 / 草稿 / 设置的页头结构对齐主壳，页宽统一 1200px。
- **渲染错误不再白屏**：学习面板外层加了 React 错误边界，渲染异常显示可一键重载的错误卡。
- **滚动与重渲染**：`scrollbar-gutter: stable` 防布局抖动；快照轮询在数据未变化时跳过整树重渲染；键盘快捷键监听只绑定一次。
- **LLM 输出容错**：生成 / 教学 / 批改的 JSON 解析支持剥离围栏外的说明文字，格式错误自动重试一次；`payload_json` 参数错误给出可读提示。
- **CSS 分层收敛**：基础层改用 `:where(.study-app)` 零特异性写法，视图样式不再需要高特异性补丁（视觉无变化，9 个视图截图对比一致）。

## 可视化、考试与挖空卡（0.4.0）

- **知识图谱 / 学习路径图**（横向分叉）：在学习库点「查看图谱」，或在目录树勾选范围后「查看图谱」。**知识结构**视图是根在左、子分支向右展开的树（题组 › 主题 › 题目），前置关系用虚线箭头叠加；**学习路径**视图按学习顺序横向排布并蛇形换行。节点颜色即掌握度（已掌握 / 熟悉 / 学习中 / 薄弱 / 未学），点题目节点可直接开练。
- **学习统计仪表盘**：左侧导航「统计」。GitHub 风格 182 天连续学习热力图、每日平均分趋势线、薄弱主题榜（一键按主题开练）、连续天数 / 活跃天数 / 正确率汇总。全部由作答日志推算，不额外存储。
- **模拟考试**：跨题组抽单选 / 多选组成限时卷（默认 10 题，最多 50 题，30 分钟自动交卷）。作答期间不显示对错、可反复修改、不更新 SM-2；交卷后出成绩单、按主题 / 题组的正误分布和错题清单，错题一键排进学习路径。
- **跨题库错题本**：聚合所有题组最近答错的题，按题组分组，可单题练或整本重练；重练走常规学习路径，进度照常记 SM-2。
- **源文高亮回链**：答题后点引用来源，弹窗在「排版 / 原文」两种视图里都会定位并高亮被引用的原文段落。
- **填空卡（cloze）**：第五种题型。生成时从资料里挖出 1–4 个关键概念（`{{id}}` 标记）；作答时逐空填写，代码按规范化比较判分（支持同义变体 `accept`），全部答对记通过。答案在作答前不下发到前端。
- **全局到期与跨库搜索**：「全局笔记本」区新增全局到期队列（各工作区今天到期的题组，点击跳转）和跨笔记本搜索（匹配题组、主题、题干，只读）。

## 跨工作区笔记本目录（0.3.0）

每个工作区的学习库默认完全独立。想让某个工作区的笔记本被其他工作区看到时，在学习库首页「全局笔记本」点 **发布到全局目录**（可选，随时可取消）：

- 发布只在 `~/.dsh/study/notebooks.json`（遵循 `DSH_HOME`）登记一条链接：工作区路径、学习库位置和标题。学习数据始终留在原工作区，不复制、不同步；取消发布即删除这条登记。
- 学习库首页的目录会列出所有已发布的笔记本（本工作区置顶），显示题组数、今日到期数和主题预览，点击「刷新」重新读取。
- 点击其他工作区的笔记本，会在**该工作区新建一个对话**并跳转过去——学习面板在那里打开的就是那本笔记本，进度、复习队列全部是它自己的。原工作区的当前会话不受影响。
- agent 也可以用 `study_workspace` 的 `notebook.list` / `notebook.publish` / `notebook.unpublish` 查询和登记目录；对其他工作区的笔记本，工具只读，写操作仍在那个工作区自己的会话里进行。

## 题组维护与中断恢复（0.2.0）

- **手工建卡**：添加资料后可直接创建闪卡，无需模型；逐题编辑器支持增删闪卡和修改引用。保存和发布均执行相同质量校验。其他题型和多条引用仍可通过完整 JSON 编辑。
- **已发布题组**：在「管理」中编辑为草稿，再校验发布。未改动题目保留 SM-2 状态；内容有变化的题目重置调度，历史记录保留。应用修改前需完成或结束正在进行的练习。
- **暂停与归档**：管理页可暂停/恢复单题、清除标记；归档会结束题组的活动练习，题组和记录仍保留，可随时恢复。学习库支持标题/主题搜索和归档筛选。
- **错题重练**：按每道题最近一次作答选取低分题，答对后退出错题队列。暂停的题不进入练习。
- **练习与教学恢复**：返回学习库保留当前练习，也可明确结束此轮并保留已答记录。逐步讲解随题恢复进度，不重复生成教学计划。
- **编辑恢复与冲突**：编辑内容暂存在当前浏览器窗口的 sessionStorage 中，刷新后可继续；关闭窗口后不保证保留，请用「保存并校验」持久保存。两个窗口编辑同一草稿时拒绝旧版本覆盖，需重新打开最新草稿。

草稿版本用于内容编辑冲突检测，复习调度更新不会制造无关的编辑冲突。历史练习引用的资料也受到删除保护。

选择题由代码按正确选项集合判分；开放问答与闪卡由学习者对照答案和 rubric 自评。不要把自评分和自动客观判分混为一谈。

## 安装

Node.js >= 22.19。采用 DSH 原生 npm 插件协议，不需要安装 Codex skill。

```powershell
npm install --legacy-peer-deps
npm run build
npm pack
dsh plugin --profile <你的配置名> add <生成的tgz绝对路径>
```

然后重新加载该 DSH 配置。插件调用宿主 `tools`、`llm`、`systemPrompt`、`connection` 与 `sessions` 服务。基于本机 DSH 0.1.5 系列 SDK 和 Pair 插件的会话视图 / 右栏注册方式实现。旧宿主未提供右栏服务时，会话视图仍可用。

生成默认使用会话当前模型（输入框选择 → 上次请求 → DSH 默认模型），也可在设置中从 DSH 模型目录指定一个仅用于出题的模型；复用宿主凭据，不要求再复制 API key。没有可用模型时仍可导入已有学习库、手工编辑题组和复习。查看页面、作答和 SM-2 更新不调用模型。一次生成通常需要 2 次模型调用；发现问题后修复并再审，最多 4 次。审题仍可能出错，发布前可以检查原文。

开发环境需要宿主 SDK 的 `@deepseek-ai/dsh-tools` 和 `@deepseek-ai/dsh-llm` 可被 Node 解析；插件包将其声明为 peer dependencies，避免捆绑第二套宿主运行时。没有 SDK 时核心测试可运行，原生宿主测试会明确跳过。

## 复用现有 study-lib-spar

在设置中选择实际**学习库**目录，例如含有 `study-lib.json`、`nodes/`、`quizzes/` 的目录，再执行导入。`study-lib-spar` 仓库本身是插件源码，通常不是学习库；仓库的 `examples/` 下才是示例库。

导入只读原文件，保留可解析的间隔、熟练系数与到期时间，关联原节点来源。旧版题目是自由文本，导入为自评闪卡，不猜测选择题正确选项。格式不完整的文件逐一报告；重复导入同一路径不重复创建题组，也不覆盖已有进度。生成新题时可以选择导入的节点内容作为来源。

## 数据与质量约束

- 原项目的 `content-quality.md`、`sm2-scheduling.md`、`recruitment-prep.md` 与 `library-schema.md` 原样保留在 `references/`，授权见 LICENSE。
- 题目须有明确答案、提示、解释、误区、独立目标和可核对的原文引用。逐字引用由代码检查；引用能否支持推论由审题模型检查。
- 单选题必须恰好一个正确选项；多选不允许全部正确；每个干扰项必须有解释。显示顺序由运行时洗牌，判断不依赖 A/B/C 字母位置。
- 正式题目与待采纳草稿分开保存；未采纳草稿不进入复习调度。
- `study-workspace.json` 是版本化的唯一事实来源，包含资料、题组、尝试日志、复习会话和教学结论。跨进程文件锁 + 临时文件原子替换保证尝试日志和调度一起提交。不是对旧 Markdown 文件的就地更新。
- 导出提供完整 JSON 备份。资料中的指令只按资料处理；UI 按纯文本显示，不执行 HTML。
- 教学记录保留诊断、已掌握台阶与迁移规则，不保存学习者原始回答或聊天逐字稿。卡片自评草稿仅在页面内存中。

当前不直接解析 PDF、图片或网页；先提供提取后的文字。生成每次 1–30 题；单份资料和一次选中的资料合计最多 600,000 字符，超过 60,000 字符会自动分段出题再合并成一份草稿（某段失败时保留其他段的题并注明）。多个生成请求按顺序排队，agent 用 `job.wait` 等待结果。生成任务在当前宿主进程内运行，重启会中断未完成任务；正式数据和已保存草稿不受影响。数据为单文件设计，适合个人学习库，长期大量使用前应定期导出。
