- **New questions mark code as code.** When the material is about programming, generated questions, options and explanations now put code (`x = 1`, `#`, `.py`, `print()`) in code style and several lines in a code block, so code and words no longer blur together. Cloze blanks still take plain answers, and a code block scrolls sideways instead of widening the card. Questions you already generated stay as they were: regenerate them, or repair them, to get the new style. Not verified: the rule was tested against the program's own prompts and a fake model, not against a real model's output, so how well a real model follows it is still unknown.
