- **New question type: True/False (判断题).** Choose **True/False** wherever you pick question types (Settings, the Create deck page, mixed and coverage runs, JSON import prompts). Each question is one statement; in practice you answer with two large **True** / **False** buttons (keys 1 and 2), it is graded like single choice, counts in exams (on the single-answer side of a balanced paper), the mistakes list and reports, and the explanation of a false statement gives the true statement. The writer and the reviewer follow one set of rules: one idea per statement, false statements are believable misconceptions rather than a sentence with "not" added, no absolute-word giveaways, and roughly as many true as false.
