- **Error messages, empty states and hints now say what happened and give one next step.** The top bar words are short and fit a narrow window: **In background** while a background task runs, **Working…** while an action runs, **Reconnecting…**, **Library error**, **Library offline**, **No model yet**. Hovering or focusing **In background**, **Library error** and **Reconnecting…** shows the full sentence (for a failed read, with DSH's own error after it); **Connected** and **No model yet** have no hover. On a narrow window the folder name beside them folds into its folder icon, and at phone width the icon goes too (the folder is shown in Settings). The model setup gate, the first-run page, **Check again** (it now says so when it cannot read the library, instead of stopping silently), the inbox, board, wrong book, generation failures, notices and receipts swap "please try later" for a reason and a real way out, and the interface sentences that mentioned "the conversation" now say **main chat**. Feature and button names are unchanged. A new handbook, [Voice and tone](docs/voice-and-tone.md), keeps later copy the same. Not verified: the English sentences were written by hand and not read by a native speaker; some background messages from the plugin itself still say "conversation model"; the screens were checked in the browser preview with the fake model, not in a real DSH.
