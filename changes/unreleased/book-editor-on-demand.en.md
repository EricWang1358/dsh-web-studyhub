- **The workspace no longer downloads the review book's text editor when it opens.** The editor and its Markdown, HTML and JavaScript highlighting (about 600 KB) now arrive only when you choose "Edit this point", so the workspace has that much less to fetch and run at start; while the editor arrives the page says "Opening the editor…", and if it cannot be fetched you get a "Reload" button instead of a blank page. Editing, saving and keyboard shortcuts work as before. Not verified: the time saved on a real DSH install over a slow connection was not measured, only the size of what the workspace loads at start.
