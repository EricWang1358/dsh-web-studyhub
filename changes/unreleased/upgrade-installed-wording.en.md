- **After a one-click upgrade the window now says whether you need to restart DSH.** On a DSH that loads the new version at once, the window used to say "StudyHub X is waiting for a restart" and told you to restart DSH, although nothing was waiting. It now says "StudyHub X has been upgraded", that DSH needs no restart, and that opening StudyHub again shows the new version. A DSH that does need a restart still gets the "waiting for a restart" window and the sidebar chip, and the install guide now names those two as the signs of a restart. Not verified: a real DSH 0.2.2 and a DSH that needs a restart, run against a real GitHub release.
