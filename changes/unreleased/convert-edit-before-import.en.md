- **A converted PDF can wait for your edits before it is imported.** Under More settings when you convert a PDF, turn on Let me edit before the import (off by default) and the conversion, with MinerU or Marker, stops once it is done: the task says it is waiting, Edit and import opens the text block by block, you can correct a block or remove it, the editor counts the characters and estimated tokens taken out, and Import saves that text as a document with its page numbers unchanged, so misread text never reaches a model. It survives a restart. Converting the same PDF again while text waits says so and overwrites nothing. A document already imported is never changed: this is not an editor for the library. Not verified: a real MinerU or Marker run (stand-in programs were used); a book of thousands of blocks in the real editor.
