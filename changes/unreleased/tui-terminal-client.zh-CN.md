- **新增 StudyHub 终端客户端（TUI），可在终端里刷题、带学和复习。** 它在仓库的 `packages/studyhub-tui` 下，暂未放进 DSH 插件和桌面版的下载包：需在源码目录里用 `npm run tui:build` 和 `npm run tui` 运行（使用指南：`packages/studyhub-tui/docs/GUIDE.md`，客户端内输入 `/guide` 也能打开）。读取与 StudyHub 相同的资料库，覆盖刷题、学习库、资料、错题本、笔记、待办看板、任务、音频、书、生成、设置、考试与备考教练等视图，支持 Ctrl+K 全文搜索、题组导入/合并/拆分、学习计划、复习与考试模式、阅读与导出工具，以及与 StudyHub 同步的看板。另有 Alt+点击鼠标支持（普通点击仍可选中文字）、暖琥珀深色与低对比柔绿两款主题、96 列居中版面、紧凑/宽松间距、每日学习简报、卡住 20 秒提示、可点击的资料来源链接（OSC 8）、命令面板置顶最近使用的命令。备考页显示后端保存的备考计划，[T] 表格与 Markdown 导出都来自该计划。未验证：除自动化 PTY/E2E 测试环境外，真实终端（包括 Windows 终端）里的表现。
