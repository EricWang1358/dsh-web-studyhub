- **从空学习库到第一组题，只有一条线。** 在你自己发布第一个题组之前，学习库的第一屏就是三步，每步一行：配模型、加资料、做第一组。只有当前这一步展开，只有一个主按钮。没有模型时，第 1 步就地列出和其他地方一样的配置步骤、「去哪拿 Key」那行小字和「重新检查」（只在「选一个模型」那一步里有一个安静的「前往设置」链接）；模型没配好也可以先加资料。第 2 步打开原来的添加资料对话框，加好后打勾、写上资料名，旁边一个安静的「再加一份」。第 3 步出题时，任务卡就在第 3 步里（只画一份，旁边没有「查看进度」）；草稿好了，给「发布并开始练」和一个安静的「先看看草稿」，草稿需要先看时给「检查草稿」。第 3 步从出题到草稿高度不变，任务结束时页面不会跳。发布后照旧直接进第一题，这条线消失，首页回到原样：「课程准备」「今天先做什么」、待发布列表和题组目录都回来。线的底部有两个安静链接：「载入示例并开始导览」和「以后再说」；「以后再说」把这条线收成首页今日位置上的一张卡（同样的三行）。第一次出题如果没做完就结束了（Key 被拒、你按了「停止」、程序中途关掉，或者出完了但不够），第 3 步留着这次任务的卡，写「第一组题没有出完」：卡上那一个按钮就是接下来怎么办（「去配置模型」「接着做」或「为没覆盖的部分补题」），同一屏不会再说草稿已经出好了；收起后的卡也这么说，按钮交给任务卡。还没配模型时，收起后的卡不给别的步骤的按钮（它标出的那一行就是模型）。收起后的卡里，长的模型名、资料名在卡内用省略号截断，每一行都落在卡片的横线上。「载入示例并开始导览」不会先在这条线上方塞进示例横幅再开始导览。欢迎页「示例已载入」那一屏删掉了，示例横幅本来就有「重新开始导览」和「移除示例数据」。QA 旅程（`npm run qa:journey`）和 honest-states 检查也跟上了现在的表单。未验证：没有用真实的 DSH 宿主和真实模型（截图和浏览器测试都用本地预览加假模型，只有中文）；真实模型出第一组题要多久；收起后的那张卡只在单元测试、一个浏览器测试和截图里看过；Key 被拒、出得不够的第一次出题只用 honest-states QA 的假模型在本地预览里看过（refuse、flag），没有用真实的服务商。
