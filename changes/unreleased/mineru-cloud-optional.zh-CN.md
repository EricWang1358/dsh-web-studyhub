- **MinerU 官方接口回来了，作为可选的 PDF 转换方式（#1765）。** 默认仍在本机转换，不上传任何内容。在「设置 › PDF 转换（MinerU）」（或导入窗口的「解析方式」）里可以选「云端（会把文件上传）」，用你自己的 MinerU 令牌（在 mineru.net 的 API 管理页创建，有效期 90 天），也可以填兼容 MinerU 的接口地址。第一次云端解析会写明 PDF 上传到哪个接口，确认之前不上传；这个确认只对该接口有效，随时可以撤回。超过官方单个文件 200 页 / 200 MB 的书会自动分段，再按原书页码合并；每天超过 1000 页后服务会变慢，界面显示为「慢」而不是失败。云端解析失败时可以「接着做」（做完的段会保留）或「改用本机」。令牌不会出现在学习库、导出、备份、日志或消息里；主会话不能打开云端，也不能在解析方式为本机时使用云端。未验证：没有在应用里对真实的 MinerU 接口跑过一次转换（只准备了驱动同一套代码的冒烟脚本）。
