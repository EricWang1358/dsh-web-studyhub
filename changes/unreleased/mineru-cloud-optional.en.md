- **The MinerU official API is back as an optional PDF converter (#1765).** Local conversion stays the default and uploads nothing. In **Settings › PDF conversion (MinerU)** (or the import dialog's **Conversion mode**) you can choose **Cloud (uploads file)** with your own MinerU token (created on the API management page of mineru.net, valid 90 days) and, if you want, a MinerU-compatible endpoint. The first cloud conversion shows which endpoint the PDF goes to and uploads nothing until you confirm; the consent holds for that endpoint only and can be withdrawn. Books over the official 200 pages / 200 MB per file are cut into pieces and merged back with the original page numbers; past 1000 pages a day the service is slower, which is shown as slow, not failed. A failed cloud conversion offers **Continue** (finished pieces are kept) and **Switch to local**. The token never appears in the library, exports, backups, logs or messages, and the main chat cannot turn the cloud on or use it while the mode is local. Not verified: a conversion against the real MinerU API through the app (only a smoke script that drives the same code was prepared).
