- **Live class can transcribe on this computer, without Google and without a key.** A learner with no Gemini key no longer stops at "needs a Gemini key": Live class offers **Local (offline)**, one click installs the SenseVoice engine and its model (about 239 MB the first time, on the non-system drive by default, every file checked against a fixed checksum, pausable and shown in Tasks), and the class then runs with the sound never leaving the computer. Learners with a Gemini key keep Gemini by default; **Settings › Audio transcription** now has **Which engine live classes use** (Automatic, Local, Gemini), and a chosen engine is never swapped for the other. The idea and the port come from the community user BAXUIE's StudyHub for ZCode, thank you! Not verified: macOS and Linux (same prebuilt engine release, untested), a real microphone inside DSH, and accuracy on real lectures; Windows x64 was checked with a real install and synthetic Chinese and English speech.
