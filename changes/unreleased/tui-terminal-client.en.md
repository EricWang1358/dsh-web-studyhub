- **There is now a StudyHub terminal client (TUI) for practising, studying and reviewing in a terminal.** It lives in the repository under `packages/studyhub-tui` and is not yet part of the DSH plugin or desktop downloads: run it from a source checkout with `npm run tui:build` and `npm run tui` (guide: `packages/studyhub-tui/docs/GUIDE.md`, also opened by `/guide` inside the client). It is built on React 19 and Ink 8 and reads the same library as StudyHub. It covers practice, the library, materials, WrongBook, Notes, Board, Tasks, Audio, Book, Generate, Settings, Exam and ExamCoach views, Ctrl+K full-text search, deck import / merge / split, study plans, review and exam modes, reader and export tools, and a board that syncs with StudyHub. It also has Alt+click mouse support (normal clicks still select text), a warm-amber dark theme and a low-contrast soft-sage theme, a 96-column centred layout, compact and relaxed spacing, a daily study brief, a prompt after 20 seconds of being stuck, clickable source links (OSC 8), and recently used commands pinned in the command palette. The exam-prep page shows the saved 备考计划 from the backend; its [T] table and Markdown export come from it. Not verified: any of this in a real terminal other than the automated PTY/E2E harness, and Windows terminals other than the test environment.
