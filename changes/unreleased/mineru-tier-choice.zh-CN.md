- **选了哪个 MinerU 档位就装哪个，没装完的安装也一样。** 以前没装完的安装即使你在「更多」里选了另一档，也还是按旧档位继续。现在那里选的档位优先；没选时，修复沿用没装完那次的档位，再往后是已装好的档位、方案里的档位。给没装完的安装选了另一档时，唯一的按钮变成「改装 basic 档」（或 standard），并用一句话说保留什么：程序和 Python 那几步已经装完的就保留，只换模型。未验证：没有真正安装 MinerU（用假的 MinerU 测过：没装完的 standard 在同一个文件夹里改成 basic 接着装，只下载了 basic 的模型）；旧档位的模型会留在磁盘上，直到卸载。
