- **The draft page now checks the draft by knowledge point: 「这份草稿的资料讲到 70 个知识点，17 个还没有题」 (this draft's materials teach 70 knowledge points; 17 have no question yet), and one action, 「补这些知识点」 (Fill these knowledge points).** The knowledge points are the points of the course outline (总纲) that the draft's materials teach; "has a question" counts the questions in every deck and draft of the course, not only this draft (the help tip beside the line says so). A question counts for a point when its source quote lands on the text the inventory found for that point; a question whose quote lands on no such text counts for the point that owns its page, as before. The draft's own questions count in its own report whatever course the draft is filed under. Under the line, a fold lists the points without a question (at most 30), the ones others build on first and marked 前置 (prerequisite), each with what it rests on, and says which ones cannot be filled because their text was not found in the draft's materials. 「补这些知识点」 shows the estimate of that very round first and runs as a top-up like the page's others: one round of at most the round limit (30 questions), one question per point (two for a point of 20 or more inventory items), each written from that point's own verified passage alone (no text around it, so a question quoting any of it is credited to the point) and titled after it, in the way the draft was written (one pass or staged), through the same checks and review. A point whose question the review drops stays on the list. A request for a point the outline no longer has, one that already has a question, one with no text in the draft's materials, or more questions than one round is refused as a whole, with nothing started. A case paper, or a draft that edits or repairs a published deck, is not offered the action and a request is refused; neither is a draft whose plan still has rounds to run (one line says to continue it first), because a point round would take a planned section's place and the plan would then skip that round. When the host stops in a point round, 接着做 (continue) finishes the points of that round that still have no question instead of skipping them; the 任务 console names such a round by its knowledge points. With an outline that cannot be used (out of date, an old one organised by material names, or a lost inventory), one quiet line says why and where to fix it; a course with no outline shows nothing; the page never starts an outline build by itself.
  - **The 总纲 page and 复习全书 count the same way.** When the outline was built from the inventory and is current, the question counts of its points, its 未出题 (no questions yet) filter and 复习全书's chapter readiness (drafted questions) use the same link, so a point that teaches on a page it does not own (no page-based count could ever give it one) now gets its questions, and the page's owner no longer gets them too. Draft questions are also counted for points anchored to a page range, which they were not before. 复习全书 used to count drafted questions by pages; it now states the same number as the 总纲 page. A question citing another course's or an uncategorised material is counted under 未归位 only, never under a point as well. An outline whose materials changed since it was built is not linked: every page counts by pages, as before; so does an outline without an inventory.
