- **The browser smoke check no longer lets a slow apt mirror eat the whole job.** It runs on a pinned Ubuntu 24.04 image, and installing Chromium's system libraries gets its own 3-minute limit with one retry, and apt is told to drop a silent connection after 20 seconds, so a stalled mirror fails that step instead of waiting for the 10-minute job timeout. When both installs fail the run says so in a warning, so a red test step can be told apart from a regression; the check stays non-blocking.
