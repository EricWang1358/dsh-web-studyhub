- **PaddleOCR 的解析结果可以直接导入，大 PDF 的指引也变短了。** 从 PaddleOCR（PP-StructureV3 或 PaddleOCR-VL，paddleocr.ai 网页或接口）导出的 JSON、JSONL 文件，可以像 MinerU、Docling 的结果一样拖进「添加资料」（最大 40 MB）：页码、标题、表格和公式会保留，页眉、页脚和页码行会去掉。PDF 太大或文字读不出来时，卡片现在并排给两个选择：在本机用 MinerU 解析（不上传），或到 paddleocr.ai 在线解析后把下载的 JSON 拖进来，并写明这条路会上传文件。Marker 收进了折叠项，作为备选引擎，转换卡片和「设置 › PDF 转换」里都是这样。未验证：真实长篇扫描书的 PaddleOCR 导出文件（解析只用测试里的样例输出核对过），以及打包后的桌面窗口里的新卡片。
