- **A book converted from a file on this computer now remembers that file as its original, at any size.** When the assistant converts a PDF it opened by its path (MinerU or Marker), the book is linked to that file when the conversion ends: nothing is copied and there is no size limit, so a 500-page, hundreds-of-MB textbook keeps its original. A page you send to the main chat from the reader now carries the original's path and the page number, with a line to open that PDF page for figures, tables and formulas instead of trusting the converted text. In 补全原文件, a file over 40 MB that is dropped or chosen in the browser is no longer just refused: the dialog says the browser cannot copy it and takes you to the path field; a file that big is not read page by page, and is accepted at once when its name and size match the file that was converted, otherwise after you confirm. A book whose conversion remembers its file is offered "Use the file it was converted from" in one click. Not verified: a real 500-page conversion with MinerU or Marker (only the stand-in programs, and 45 MB sparse files, were run); books converted from a file chosen in the browser, including every book converted before this release, have no path to remember, so for those you enter the path once; the reader cannot open an original over 40 MB yet, so "view original page" is not available for it and the main chat reads it instead.
