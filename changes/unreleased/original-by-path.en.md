- **A book converted from a file on this computer now remembers that file as its original, at any size, and its pages can be viewed.** When you choose the PDF with the native file dialog (or the assistant converts a PDF it opened by its path, with MinerU or Marker), nothing is copied through the browser and the finished book is linked to that file: no size limit, so a 500-page, hundreds-of-MB textbook keeps its original. A page you send to the main chat now carries the original's path and the page number, with a line to open that PDF page for figures, tables and formulas instead of trusting the converted text. A book whose conversion remembers its file is offered "Use the file it was converted from" in one click.
