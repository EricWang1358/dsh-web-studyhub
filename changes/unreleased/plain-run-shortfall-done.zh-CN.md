- **按固定题数出题且题数出满后，不再因为资料还有没覆盖的小节被判成「没出完」。** 在主会话或直接按题数出题（没有设置覆盖强度计划）且出满所要求的题数后，首次引导屏现在会正常显示「第一组题出好了」并提供「发布并开始练」或「检查草稿」，不再误报「第一组题没有出完」；首页任务卡和「待发布」列表也不再标成警告态「待补齐」或把「为没覆盖的部分补题」抢作主按钮。「为没覆盖的部分补题」仍在草稿页和「任务」页保留为可选补充。题数没出满、失败、取消、中断的运行，以及按覆盖强度分轮且停在第 1 轮的运行行为不变。
