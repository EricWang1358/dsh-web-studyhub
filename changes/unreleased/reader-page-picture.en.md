- **Send to the main chat takes the picture of the PDF page with it when the model reads pictures.** In the Original PDF view, when the host says the conversation's current model takes images, the button puts the page's text and a picture of the page into the main chat's input box, so nobody has to take a screenshot, and you still press send. On any other model, which includes models with no declared image input such as DeepSeek or a self-configured SiliconFlow route, only the text goes in, because a picture would block the whole message; the chat's box says why and how to get the picture. The receipt says how many pictures went in and now has a **Go to the main chat** button when the box was filled as well. Pasting a screenshot into the reader's own panel is still not possible: the panel's model reads saved text only. Not verified: DSH 0.2.0-rc.2 (not tested, feature detection only), and that a real vision model reads the picture (checked with a local fake model on DSH 0.2.1-rc.2).
