- **Send to the main chat takes the picture of the PDF page with it.** In the Original PDF view, the button now puts the page's text and a picture of the page into the main chat's input box, so nobody has to take a screenshot, and you still press send; the receipt says whether the picture went in and now has a **Go to the main chat** button when the box was filled as well. On a host without this ability (DSH before 0.2.1) the screenshot way stays. A picture only helps if your main chat's model reads pictures. Direct pasting of a screenshot into the reader's own panel is still not possible: the panel's model reads saved text only. Not verified: DSH 0.2.0-rc.2 (feature detection only, no install to check against), and that a real vision model reads the picture.
