- **Local tool installs no longer blame the network when a Python module is missing or a package name contains "network" or "Connection".** When installing MinerU, Marker, local transcription or the system-audio component fails with `ModuleNotFoundError` (for example `No module named 'torch._C'`) or ordinary log lines containing words like `Connection`, `network` or `timed out`, the failed card now classifies it as a broken install or general failure instead of asking you to retry the network, while real network error codes (`ECONNRESET`, `ETIMEDOUT`, `ReadTimeoutError`, `ConnectionError`, DNS or SSL failures) still offer the network retry. On Windows accounts whose user SID matches one of the built-in system or administrator SIDs, MinerU's settings-folder check also no longer re-writes already valid inherited permissions on every start. Not verified: tested with unit tests and Windows Server ACL fixtures rather than a live MinerU or PyTorch download failure.
