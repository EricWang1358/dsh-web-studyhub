- **同一台电脑同时开两个 StudyHub 窗口或两份资料库时，正在进行的本地安装不再被当成「被中断」，检索提示也不会串到别的资料库。** 一个 StudyHub 窗口正在安装 MinerU、Marker、本地转写或电脑声音组件时，共用同一个 DSH 主目录的另一个窗口现在会同步显示「安装中」，并说明另一个窗口正在安装、要暂停或取消去那个窗口操作，同时拦下往同一位置发起的第二次安装，只有安装进程真的不在了才会标为上次安装被中断。新建的或还没建过索引的资料库，不会再因为别的资料库之前重置过检索索引而误报「索引坏了，已经重置」；在一份 DSH 配置里选过的其他检索工具，也不会再在另一份没有这个工具的资料库里弹出「现在找不到」警告，原来的资料库打开时选择仍然保留。未验证：没有同时开两个真实的 DSH 桌面窗口跑真实的 MinerU 或 Marker 安装；只用多实例单元测试和真实子进程核对过。
