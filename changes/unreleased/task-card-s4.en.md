- **Hands-on task question type (`task`) with main-chat static check.** Added a subject-universal `Hands-on task` (`动手任务`) question type across generation, independent review, draft editing, JSON import, custom course plans and spaced practice, without an in-app code editor or running tests. Each task card pairs a clear task description with structured acceptance criteria and a folded reference solution: learners can hand the task and optional file paths to the main chat via **Check in main chat** (`task.check`) so the assistant reads only user-specified files, statically evaluates each criterion as satisfied, missing or issue (with optional line numbers and at most 3 concrete issues, without rewriting the learner's files), and writes the result back through `card.grade`; opening **View reference solution** before completion records the attempt as having viewed the solution, **Done (self-report)** records it honestly as `Self-reported, unverified`, and due FSRS-6 reviews gently prompt to redo the task from scratch without looking at the solution. Not verified: live end-to-end static grading inside a running DSH desktop session with a connected external model.
