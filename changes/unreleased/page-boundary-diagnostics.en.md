- **A page that fails to draw no longer takes the sidebar with it, and you can copy a diagnostic text for a bug report.** The failed page shows a notice with Retry and Copy diagnostic information, the sidebar and top bar stay, and another page opens normally. The same button is in Settings › About & updates, and "See what will be copied" shows the text before it goes to the clipboard. The text holds only the StudyHub version, interface language, page, the error type, the program's own short error phrase (any other error text is replaced by its length), the names of the functions where it broke, job kinds and statuses, the number of sources, decks and questions, and whether experimental features are on; the DSH version is left for you to fill in. API-style keys are now also removed from the reasons shown for failed conversions.
