- **Resetting a damaged desktop settings file no longer fails when it follows another reset within the same moment.** Two backups of the damaged settings file made in the same millisecond (saving over it, then choosing to back up and reset) used to get the same name, and the second was refused with "backup failed"; each backup now gets its own name and both copies are kept. Not verified: on a real damaged settings file in the desktop app (covered by an automated test with a fixed clock).
