- **新增 StudyHub 桌面版（Windows）：不装 DSH 也能用。** 提供 `.msi` 安装包和免安装的 `.zip`，资料和题库仍存在你电脑上的学习库目录里，可与 DSH 插件版共用同一个目录。未验证：`.msi` 没有实际安装过；资料导入、出题和复习的完整流程没有在桌面版里跑过；Windows 10 上没有试过；系统的选目录弹窗只验证了选完之后的保存。
  - 第一步「配一个 AI 模型」里，检测到本机已登录的 agy 或 codex 时可以一键启用，也可以在设置里填 API Key。
  - 界面大小默认「跟随窗口」：窗口变宽（比如最大化）时自动放大一些，仍可在「设置 › 外观」里改成固定比例。
  - 在「设置 › 学习库与模型」点「在学习库里打开 agy」（或 codex），会另开一个命令行窗口和它对话，可以和 StudyHub 左右并排。它能直接改学习库里的文件，这些改动不经过 StudyHub 的检查。
  - 在「设置 › 学习库与模型」点「更换目录…」可以换学习库；目录由环境变量 `STUDYHUB_LIBRARY` 指定时，按钮不可点并写明原因。
