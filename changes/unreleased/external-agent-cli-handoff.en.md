- **Copy prompt now gives an outside AI a way to work on your library when it has no StudyHub tools (#1714).** On the desktop app, a copied prompt now carries a short note in its StudyHub notes: if the AI cannot call `study_workspace`, it may run StudyHub's own `study-cli.mjs` from a terminal, using the node that ships with the app, so you do not need Node.js installed, and it must stop and tell you rather than hand-edit `.dsh-study/`. The note is added only on the desktop app (never in the web demo or when the prompt goes into the DSH main chat), and a library on a drive root such as `D:\` is written so Windows reads the command correctly. Not verified: no real outside AI (agy, codex) was run on the copied command; the command was checked by parsing it the way Windows does and by running the bundled `study-cli.mjs` with the bundled node.
