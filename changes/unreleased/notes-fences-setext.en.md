- **A question in a note or a book that holds an unfinished `~~~` code block, or a title with a `---` or `===` line under it, no longer turns the text after it into code or into extra headings.** The note written from a question keeps its one title and its four headings, and the book, its reader, contents and export read code blocks and underlined titles the same way; an underlined title in the book is saved as an ordinary `#` heading. One change you may notice: a code block now ends only at a line of the same kind of fence, so a note whose code block was "closed" with a ```js line shows the code running on until a plain ``` line. Not verified: a real learner's book with underlined titles or `$$` formulas, and the book's reading page on a phone width.
