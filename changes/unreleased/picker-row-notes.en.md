A size is never cut ("Markdown · 560 …" no longer happens): the rows of one kind all show it whole or none do, and one kind no longer takes the size from another (one Markdown note left eleven Text notes without their character counts); on narrow windows the counts may read "267 chars". Widening the window never makes a row say less (around 532 px a PDF row lost its character count while "Choose pages" moved up beside the title), and a long course name is never shortened inside a number ("…（202…" no longer happens), its whole name on hover even when only its last pixel is hidden.
