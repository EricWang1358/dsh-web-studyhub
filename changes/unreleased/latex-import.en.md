- **LaTeX lecture notes can be imported directly.** You can drop or select `.tex`, `.ltx` and `.latex` files in Add materials or import them from the main chat (#978). StudyHub keeps the original `.tex` file for download, strips comments and preamble noise, expands custom math macros so formulas display cleanly, and turns sections, Beamer frames, theorems, lists and tables into readable chapters ready for question generation. Not verified: multi-file projects split across `\input` or `\include` still import one file at a time rather than resolving sibling files automatically.
