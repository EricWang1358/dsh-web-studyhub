- **Asking about a page in Original PDF now has four presets and a way to the main chat.** Under the question box, Explain this page, Translate this page, Split this page into points and Formulas and code of this page each ask at once; hovering one shows the exact question it sends. Under the answers, a quiet Send to the main chat puts the material's name, the page number, the page's saved text and your question into the main chat's input box, ending with a line where you paste a screenshot of the page, so a figure can be explained; you press send yourself, and text you already typed there is never written over. On a page without saved text (a scan or a picture), that is now the way forward instead of a dead end. Not verified: with a real model (the four presets were checked with the preview model only), and in the DeepSeek Harness chat itself (the browser preview has no main chat, so there the message was checked on the clipboard; the shared hand-off is tested against DSH's input box elsewhere).
