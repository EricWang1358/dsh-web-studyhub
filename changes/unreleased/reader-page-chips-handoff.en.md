- **Asking about a page in Original PDF now has four presets and a way to the main chat.** Under the question box, Explain this page, Translate this page, Split this page into points and Formulas and code of this page each ask at once; hovering one shows the exact question it sends (Translate this page is a one-off answer about the page's saved text; the kept translation of the whole material stays Translate in the Read toolbar). Under the answers, a quiet Send to the main chat hands over the material's name, the page number, the page's saved text and the question typed on this page, ending with a line for a screenshot of the page; a screenshot only helps if your main chat takes pictures. Press the link first and take the screenshot after, because without a main chat the message goes onto the clipboard. You press send yourself, and text you already typed in the chat box is never written over. A page without saved text (a scan or a picture), which used to be a dead end, now offers Send to the main chat with only the material's name and the page number.
