- **Turning the page in Original PDF no longer reloads the file.** The page is drawn in place with the same PDF engine as **Original page**: the zoom (now beside the page number) and the sideways place stay, a new page starts at its top, and the page shown is always the page the panel asks about. Text can still be selected and copied. This view has no continuous scrolling and no find in the whole file; **Use the browser's viewer** beside the page number offers those, with the old reload on each turn, and a file that cannot be drawn here falls back to it and says so. Not verified: very large scanned books (drawing runs on the page's main thread) and browsers other than Chromium.
