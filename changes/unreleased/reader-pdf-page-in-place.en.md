- **Turning the page in Original PDF no longer reloads the file.** The page is drawn in place with the same PDF engine as **Original page**: the zoom (now beside the page number) and the sideways place stay, a new page starts at its top, rapid page turns jump straight to the final page without drawing every page in between, and the page shown is always the page the panel asks about. Text can still be selected and copied. This view has no continuous scrolling and no find in the whole file; **Use the browser's viewer** beside the page number offers those, with the old reload on each turn. A file that cannot be drawn here, or whose pages draw too slowly on the main thread (such as heavy scanned books), switches to the browser's viewer automatically and says why. Not verified: browsers other than Chromium.
