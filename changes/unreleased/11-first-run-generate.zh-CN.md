- **第一组题就在那条线上出，短导览也按这条线走。** 第一次添加资料（或「再加一份」）后，回到这条线，不再跳到创建题组。第 3 步在花任何用量之前先写明要出什么（和创建题组按钮上方的那句话相同，再加上题型），以及预计用量（就是创建题组的「预计 … tok · … 次模型调用」那一行，估算出来之前先占好位置；估算不出来时这一行不出现，不会一直停在「正在估算…」）。「出第一组题」就在这里开始同一个出题任务，只有你按了才开始。还没配好模型时，打开的是第 1 步，第 3 步只写「配好模型后，用资料出第一组题」，没有按钮。资料超过一次出题的上限，或者在创建题组里选的参考样题和这些资料对不上时，按钮是灰的，旁边写明原因，也不显示要出什么和预计用量（和创建题组一样）。旁边一个安静的「改题型和题数」打开创建题组，资料已经勾好。第 3 步从出题前、出题中到草稿好了高度不变，下面的内容不会跳。点「以后再说」收起后，卡片用两条横线写出这句话和预计 token 数（估算不出来时第二条留空）；资料没法直接出题时，卡上的「出第一组题」也是灰的，原来写这句话的地方换成原因和「改题型和题数」。在本地预览里，从有模型的这条线到第一道题，前后都是按 5 下（添加资料、选文件、出题、发布并开始练、选一个答案），但出题按钮现在就在第一屏（1280 宽时离顶部约 570 像素，390 宽时约 640 像素），以前在创建题组里要往下约 1100 和 1470 像素。短导览从 8 步改成 7 步，顺序和这条线一样：欢迎、模型、资料、出题、草稿、练习、完成；「任务」只在完整导览里。这条线还在时，导览最后一步指向首页这条线的第 2 步（示例资料不会让它打勾），那里的「添加资料」也回到这条线；已经有了自己的题组后，导览里的「添加资料」照旧去创建题组，资料已经勾好。窄的面板上，导览会把高亮的按钮滚到底部那张卡片的上方，不再被它挡住。学习库反应慢的时候，「载入示例并开始导览」不会先画出首页、再被示例横幅整页往下推（以前在 420 宽时往下推 136 像素）：示例真正载入好了导览才开始，载入过程中示例题组也不会被当成你自己的题组。未验证：没有用真实的 DSH 宿主和真实模型（本地预览加假模型，只有中文）；学习库反应慢只在本地预览里模拟过（压住它的回答）和在负载高的机器上跑过；按钮变灰只在本地预览里看过资料太多的情况（和参考样题对不上只在单元测试里看过）；预计用量和真实模型实际用掉的差多少；真实模型出的第一组草稿有多少能直接「发布并开始练」，多少要先检查。
