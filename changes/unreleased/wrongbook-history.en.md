- **The wrong book keeps the mistakes you have already put right.** 「错题与待巩固」 now opens with a **待巩固 / 已订正** switch, both counts on it, once anything has been corrected. 待巩固 is what it always was: the questions whose latest answer is still below 3. 已订正 keeps every question you once missed and have since answered correctly, newest correction first, each row reading 答错 N 次 · 最近答错 <date>; 练 practises it again, and opening a row shows the answer that was wrong instead of the correct one that cleared it. Until now one correct answer removed a mistake from the page for good, and because the daily plan serves weak questions first, a learner could answer them right and read an empty page as "the wrong book only shows today". Nothing is filtered by date: the service reads the answers the library already stores, so an existing library has its history without a migration; the 待巩固 list, its order and its fields are unchanged, and 为你推荐, 重练 and 生成变式 stay there.
