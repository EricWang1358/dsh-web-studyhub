- **When a local tool fails, the main chat can now repair it, and the failed card tells you how to let it.** On the failed card of MinerU, Marker, local transcription, the system-audio component or the search extension, "Send to the main chat" now asks the main chat to find the real cause (the card's sentence is only a guess) and then repair this computer step by step: it says what a step changes before doing it, asks you before ending a process or deleting files, checks the result and stops what it started. What it may do depends on the failure (folder permissions, a busy port, the VC++ runtime, a location that cannot be written, a broken install, the network), and it ends by telling you which button to press back in StudyHub. Installing and uninstalling are still your buttons. Beside the button, one sentence says to choose the full-permission option in the permission menu at the bottom-left of the main chat's input box before sending and to switch back afterwards; a hover explains why, and that full permission lets that chat change any file on this computer. Find it in the finder as "Let the main chat repair a local tool". Not verified: a real repair by a real main chat in DSH; the English name of the permission option in DSH's English interface; what the experimental auto-review option allows outside the workspace; whether a plugin can read the chat's current permission (no supported way was found, so the sentence always shows).
