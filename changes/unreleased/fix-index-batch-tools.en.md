- **Building the search index works again on newer DSH.** Newer DSH builds run a plugin's tool calls as a batch, and StudyHub still sent the old single-call shape, so every page failed and the index stopped after five pages with only "Tool batch execution failed". StudyHub now sends a call both hosts understand, and when the host wraps an error the message says the real reason behind it. Not verified: checked against a stand-in of the new batch executor and the old host's tests, not yet in a running DSH nightly; searching the index uses the same call and should work again too.
