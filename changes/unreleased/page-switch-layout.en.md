- **Switching pages is smoother: the pause on entering Sources and Create deck is about half as long.** With many materials, Sources no longer lays out every row at once; a row far from the window is laid out when it scrolls near. The segmented choices on Create deck, the sidebar highlight and the number beside Sources no longer make the browser lay the page out again while it is still being built. On a test library of 300 materials (headless browser, 1440 px wide) the worst frame on entering Sources went from 208 ms to 125 ms, and on entering Create deck from 325 ms to 167 ms. Not verified: how it feels in a DSH window, a real library, a narrow window; one run before and one after; the scrollbar of a very long Sources list changes length slightly as rows are laid out, which was not looked at on its own.
