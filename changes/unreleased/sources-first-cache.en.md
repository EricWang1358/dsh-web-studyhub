- **Making questions from long material costs less: each step now starts with the material, so the provider's cache can serve it.** Every step of making questions (answers, writing, review) sends the part's material, and a provider such as DeepSeek only discounts the start a request shares with an earlier one. The material used to sit behind each step's own instructions, so it was billed in full every time. It now comes first, and each step's instructions follow it. Measured on DeepSeek V4.1 Flash with an 8-question job on a 24,000-character text: the share of the input read from cache went from about 25% to about 59%, and the input cost to 0.56 of what it was. Material of a page or two is sent as before. Not verified: whether the question quality changes with the new order; the saving on PDFs, whose parts carry different pages, was predicted from the same prompts but measured only for one text.
