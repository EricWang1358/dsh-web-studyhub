- **Three small polish fixes in the live class, the book editor and practice.**
  - **The live-class note about untranscribed audio reads properly in English.** One second now says "was" (not "were"), the note continues after the "; " in lower case, and a message made of three parts, such as a stop reason, the connection-interrupted line and the note, is translated part by part, with no Chinese left in it. Not verified: a real class that lost its connection, in the English interface; checked with the message text and a stand-in connection only.
  - **Pressing 完成 · 回到阅读 (Done) in the book editor while a save is still running is no longer lost.** The click used to raise the "unsaved changes" question, which vanished when the save finished and left the editor open. Now Done waits for the save and leaves the editor; if the save failed, the question is asked because the text is still unsaved. Not verified: a save slow enough to notice on a real disk; checked in a browser with the save held back.
  - **The question card no longer gets a heavy dark outline after keyboard use.** When the program put focus back on the card (Esc out of the source column), the browser drew its own thick near-black ring around the whole card. The card now shows no ring, and the controls inside it keep theirs. Not verified: the Esc-from-source-column route by hand; checked by putting focus on the card in a browser at 1280 and 420 px.
