- **The main chat can now change a question's kind instead of deleting it and writing it again.** When you say "this should be multiple choice", the main chat uses the new `card.convert` to make it multiple choice (or single choice, a flashcard, a cloze or an open question). The same question keeps its answers, prerequisite links and follow-up questions; since what is asked changed, its review schedule starts again. The new kind must be complete: single and multiple choice need 3–6 options and their correct answers, a cloze its blanks and answers, an open question a rubric, and what is missing is named. "Undo the change" turns it back into the kind it was. Before, sending only the kind answered "Nothing to update", and a kind sent with other changes was silently ignored; now you are told to use `card.convert`. A question in an exam that is still open cannot change kind. Not verified: whether a real main chat picks this new action when it should (only the action and the instruction text were tested).
