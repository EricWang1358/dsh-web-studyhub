- **浏览器拒绝共享标签页时，课堂实录会说清你这台电脑上发生了什么，并把下一步做成按钮。** 提示不再让 Windows 用户去找一个并不存在的屏幕录制权限；它会说出真正的原因（单位或学校的管理策略、应用内置的窗口、macOS 的录屏权限），给出「改用麦克风并开始」，以及在重试可能有用时的「再试一次共享」，下面的「排查信息」列出浏览器告诉我们的情况。在 Windows 上还会说明不用共享、也不用外放就能录电脑声音的办法（把「立体声混音」或虚拟声卡设为默认录音设备），应用内置窗口里、戴着耳机时也能用。未验证：在真实的应用内置窗口、受管理的电脑或 macOS 上的表现（这些情况用模拟的拒绝测过）。
