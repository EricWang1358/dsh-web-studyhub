- **In Original PDF, Study tools now asks about the current page instead of an old selection.** Text selected inside the PDF viewer never reached the panel, so it used to keep the passage last selected in Read and answer about that. It now says "Asking about page N", takes a typed or pasted question (text copied from the PDF can be pasted in), and answers from that page's saved text; a very long page is cut, and the panel says so. Pages are turned with the new controls above the PDF or the arrows in the panel, and the PDF follows them. The passage selected in Read and its answers are still there when you come back to Read. A page without saved text says so; for figures it points to Original page in Read. Not verified: with a real model, and in the DeepSeek Harness host's own PDF viewer (checked in the browser preview with Chromium's viewer and the preview model only). Each page turn reloads the PDF, which can be slow for a very large file and does not keep the viewer's own zoom and scroll position. Scrolling inside the PDF is not followed, so the page controls can differ from the page on screen; the panel always names the page it asks about.
