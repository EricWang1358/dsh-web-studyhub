- **PDF 转换好后可以先等你改，再导入。** 转换 PDF 时在「更多设置」里打开「导入前先让我改」（默认关闭），MinerU 或 Marker 转换完就停下：任务上写着在等你，点「修改并导入」按块打开文字，可以改一块或删一块，编辑器会算出去掉了多少字、约多少 tokens，点「导入」后这份文字才存为资料，页码不变，识别错的文字不会再进模型。应用重启后还在。文字还在等你时再转换同一份 PDF，会告诉你，不会覆盖。已经导入的资料不会被改动：这不是资料的编辑器。有文字在等你时退回旧版本并不安全：旧版本会把它当成失败的任务，点「接着做」会直接导入，不带你的修改，修改也会丢掉；退回前请先导入或放弃。未验证：测试副本之外的这种退回；真实的 MinerU 或 Marker 运行（测试用的是替身程序）；几千块的整本书在编辑器里的实际手感。
