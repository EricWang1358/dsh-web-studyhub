- **StudyHub now also runs in ZCode, and every release ships a ZCode package with a one-click installer.** Download `StudyHub-ZCode-<version>.zip` from the release, double-click `install.bat` (it finds ZCode on any drive) and type `/studyhub` in a new chat: the full StudyHub panel opens in ZCode's side pane, and the AI there can use StudyHub's tools. In Settings › Library & model you pick Zhipu GLM, SiliconFlow, DeepSeek or any OpenAI-compatible endpoint, paste a key and select Save and test; no files to edit. The library defaults to `StudyHub` in your Documents folder and can be shared with DSH; a background task belongs to the chat that started it and stops when that chat is closed or ZCode quits, with finished parts kept for Continue. A key is never sent to another provider: changing the address to another one clears it. Thanks to community member BAXUIE for the idea and the first port of StudyHub for ZCode! Not verified: installing into a real ZCode and using the panel there (the package was checked by unpacking it and running its server with Node alone, and the panel in Chromium through that server); ZCode's handling of the ext-apps link and display-mode requests.
