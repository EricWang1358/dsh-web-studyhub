- **The search extension asks for an update only when a release changed it.** Every StudyHub upgrade used to say the search extension needed updating, even when it was exactly the one you had (3.7.1 and 3.7.2 changed nothing in it). Now an upgrade leaves it alone unless that release brings a changed extension; with 3.7.0 or later installed, nothing is asked. When an update is needed, **Settings › About & updates** and **Settings › Search extension** each say so once, with one **Update the search extension** button, and DSH needs a restart afterwards. Not verified: the first release that really changes the extension (none has yet), in a real DSH; the extension still does not update as part of the one-click upgrade, so in that case it takes a second click and a second restart.
