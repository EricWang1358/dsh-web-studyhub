- **A running task no longer makes the panel fetch the whole library again every 2.5 seconds.** While a transcription, a question run or another long task is working, the task cards, the Tasks page and the sidebar count still update every poll, but the panel now fetches only the running tasks' progress; the whole library is fetched again only when something you can see changes (a task starts, pauses, ends or writes a draft). On a test library a ten-minute task went from 241 whole fetches (83.4 MB) to 2 (8.0 MB in all). Not verified: not measured in a real DeepSeek Harness window or with a real long task; only a preview host with simulated tasks was checked.
