- **TUI keys, layout and saving were reworked so shortcuts stop colliding and a failed save no longer loses data.** All global, Ctrl and Alt shortcuts go through one key router used by all 16 primary views; Alt+arrows, Alt+PgUp/PgDn, Alt+Home/End and a quick double Esc are no longer swallowed, and Esc that clears a filter no longer also collapses the assistant panel. `packages/studyhub-tui/docs/KEYBINDINGS.md` and the guide are checked against the code automatically. Below 60×18 an overlay covers the page instead of unmounting it, so unsaved input, cursor and scroll position stay. Ctrl+O opens the latest 50 notifications, where you can copy or clear them. Grade labels now read 0 无答案或完全错误, 1 答对一小部分, 2 接近, 3 答对(通过), 4 良好, 5 完整; the pass line (grade ≥ 3) and stored data are unchanged. Due, weak and mastery numbers on the dashboard, library and board come from single sources and count the same population (learnable cards; suspended cards are shown beside the total). Settings, deck, board, draft, notes and exam-prep writes use one atomic temp-file-and-rename path with rollback; corrupt files are backed up first, a failed backup aborts the write, and a file that cannot be read right now (for example locked on Windows) is not overwritten. `tui.json` gets `version: 1`, and a newer version is left untouched. Free text and question-stem previews are no longer saved to preferences, and recommendation-button usage goes to a separate `tui-usage.json`. Unreadable, corrupt or newer-version retrieval, notebook, coach-daily, estimate-calibration and desktop config files are not overwritten. The large `ReviewView.tsx` (3083 → 696 lines) and `WorkspaceTab.tsx` (2699 → 608 lines) were split, with a 1000-line ratchet on TUI source files; the split also fixes multi-blank cloze drafts (blank 2 and later) being dropped when you leave a card and come back. Not verified: the persistence changes on a real user library (only temporary directories in tests), and the TUI as a whole outside the PTY test harness.
