- **「发给主会话」之后出一张盖章回执，发出去的消息也像你自己写的。** 发完后页面底部升起一张小回执：左边一枚章，右边两行短字，每种结果一套：填「已填进主会话的输入框 · 看一眼，再由你按发送」（没有按钮，5 秒后收起）；留「输入框里你写的字都留着 · 这段已复制，粘贴到合适的位置」，宿主能切到主会话时带「去主会话」（8 秒）；复「已复制到剪贴板 · 没找到主会话，粘贴到任意对话」，带「看看内容」（6 秒）；手「请手动复制」，只在浏览器不让用剪贴板、你又没复制就关掉全文卡片时留下。英文界面的章里是图标，不是字。在手机上每张回执的标题和下面那句都只占一行，四种结果一样高，新的回执不会把它撑高。底边一条细线显示还剩多久，指着、聚焦回执或切到别的标签页时会停，回来后走完剩下的时间才收起；新的回执在原地替换旧的，并重新计时。回执用玉绿、赭和墨，不用其他提示的蓝，也不用页面主按钮的朱红；在做题页的操作区里也是同一个样子。剪贴板被拒时直接打开全文卡片，整条消息只出现一次：先是你自己的那句话，再是引用框里你写的要求，给助手的部分收在「StudyHub 附注（给助手）· N 行」里，和消息里的标题是同一个说法。下面一个「复制全文」，复制后原地变成「已复制」，宽度不变；还有「复制不了？全选后按 Ctrl+C」，选中的底色是赭色荧光笔，手动复制得到的就是原样要发的那条消息。「发给主会话」按钮工作时不再多出转圈，所在那一行不会挪动；「更多 › 整本书 › 发给主会话」点了直接发（没有表单，也没有省略号）。每条消息都先用你的口吻说要什么（不出现工具名和编号），再是「—— StudyHub 附注（给助手）——」下每行一条的说明，学习库里的文字单独隔开（名字放在短代码片段里；选中的话、PDF 的章节标题、骨架的范围放在围栏里），语言句只说一次；录题时贴的题目接在最末尾的「第一批题目：」后面；第一句已经在提要求的消息，末尾不再挂一个空的「我想：」（只有提供「全部重新归并」的主题组消息保留它）；题组菜单里的「在对话中分析」也是这样：直接按发送，主会话照旧做那次分析；想要别的，先在输入框里接着写。主题组消息不再拿某一门软件架构课的主题当例子，英文消息里没有中文标点了，贴进来的题目会保持原文语言。复习全书的消息只写这本书自己语言的「资料以外」标记（不知道书的语言时才两种都写）；英文界面的学习路径消息里，建议跳过的步骤又是小写的说明了。未验证：真实模型怎么回应新消息（只用了假模型和消息测试）；DSH 桌面版和真手机（检查的是 Chromium 的 390 和 1280 像素，以及 npm run qa:dsh 跑的 DSH 网页）；macOS 和手机上的楷体（没有时退回宋体）；真的切换标签页时计时暂停（测试是模拟页面隐藏）；在手机上用长按菜单手动复制（测试是直接触发复制）；比 390 像素更窄的手机；读屏软件怎么读回执。
