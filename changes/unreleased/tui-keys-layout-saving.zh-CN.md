- **重做 TUI 的按键、版面与保存，快捷键不再互相抢键，保存失败也不再丢数据。** 所有全局、Ctrl、Alt 快捷键走同一个按键路由，16 个主要视图全部迁入；Alt+方向键、Alt+PgUp/PgDn、Alt+Home/End 和快速双击 Esc 不再被吞掉；按 Esc 清除筛选时不再同时收起助手面板。快捷键说明和使用指南与代码自动比对。窗口小于 60×18 时以遮罩覆盖页面而不是卸载页面，未保存的输入、光标和滚动位置保留。Ctrl+O 打开最近 50 条通知，可复制或清空。判分档标签改为：0 无答案或完全错误、1 答对一小部分、2 接近、3 答对（通过）、4 良好、5 完整；通过线（分数 ≥ 3）和已存数据不变。仪表盘、学习库与看板的到期、薄弱、掌握度数字改为单一来源，统计同一批卡（可学习的卡；已暂停的卡在总数旁单独显示）。设置、题组、看板、草稿、笔记、备考的写入统一为临时文件加重命名的原子写并可回滚；损坏文件先备份，备份失败则中止写入，暂时读不了的文件（例如在 Windows 上被占用）不会被覆盖。TUI 偏好文件带上版本号，遇到更新版本写的文件保持原样。自由文本和题干预览不再写入偏好文件，推荐按钮的使用记录改存到单独的文件。检索、笔记本、每日教练、估算校准和桌面配置文件若无法读取、已损坏或来自更新版本，则不会被覆盖。TUI 刷题页与工作区设置两个超大源文件已拆小，并限制源文件行数；拆分同时修复了多空填空草稿（第 2 个及以后的空）离开卡片再回来被丢掉的问题。未验证：持久化改动在真实用户资料库上的表现（测试只用临时目录），以及 PTY 测试环境之外的 TUI 整体表现。
