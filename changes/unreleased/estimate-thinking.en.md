A stage this machine has already learned a correction for keeps that correction, which holds the thinking already; a stage it has not takes the measured output per call as its high end, or, with nothing measured yet, what a thinking model wrote on a real 513-page run (the 90th percentile per call), while the low end stays the sample estimate. The headline then says (thinking included), and the generation details show the same per-stage ranges the headline adds up.
