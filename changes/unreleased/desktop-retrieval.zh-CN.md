- **桌面版：原生支持大教材检索扩展（自动复用 DSH 已装扩展 + 一键独立安装）。** 以前在 StudyHub 桌面版打开「设置 › 检索扩展」会提示「当前 DSH 不能在应用内安装插件」，如果这台电脑在 DSH 里用过检索扩展还会误报「之前选择的检索工具现在找不到」。现在桌面版用自带的 Node 22 直接托管本地检索服务：本机 DSH 里已经装过检索扩展时会自动只读复用（不会改动或删除 DSH 目录，并支持随时切换为桌面版独立安装）；没装过时可直接一键下载校验并安装 Windows 预打包版本（无需安装 DSH、Node 或 npm）。索引与模型目录与 DSH 共用，写入时通过跨进程文件锁协调；安装、更新、切换模型下载地址、重试启动或修复索引都会热重启检索子进程，无需重启整个 StudyHub 桌面版。未验证：在真实 GitHub Release 流程中跑完 `pack:retrieval --verify` 完整联网打包，以及真实 Tauri 窗口下的界面目视验收。
