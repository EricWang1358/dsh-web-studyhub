- **Material rows put facts and reminders in their own places; messages stay at the bottom edge of the window and stop repeating the page.** Not verified: checked in a Chromium preview only (1440 and 420 pixels wide, light and dark), not inside DSH itself, and not with a real model.
  - **Materials list.** The line under a title now holds only facts: course, format, pages, characters. A reminder you have to act on (“Too little text, check the text”, “Complex layout”, “Contains old extracted pages”) is a small warning label next to the title, so it is seen at a glance instead of being one more grey phrase. The start of the text is no longer squeezed into that line (open the material to read it).
  - **Messages stay put.** A message used to float right under the last row when a page was short, in the middle of the screen. It now sits at the bottom edge of the window on every page, whatever its height, and still waits while the pointer or the keyboard is on it.
  - **Fewer repeated messages.** Starting a generation no longer says “Started generating …” under the progress card that already says it; it speaks only when a run is split into rounds, to say how the rest goes on. Renaming a material in the list no longer announces the new name that the row already shows.
