- **The whole review book can be saved as one page that opens offline and prints cleanly.** In More › Export… the new "Whole book (.html)" button saves the book (cover, contents, lookup pages, every chapter) as a single file with no Pandoc: footnotes are numbered and stand at the end of their chapter, each chapter starts a new page on paper, formulas are drawn, and the button says about how many A4 pages it is.
