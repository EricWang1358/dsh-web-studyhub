- **Live class: when the model for polish or translation replies with a paragraph instead of the format, another model takes over.** Some chat models answer the format request with prose ("你发来的是一段……"). This used to count as "too long", so batches were halved and sentences skipped, wasting requests. Now the first request goes out as before. If the reply is prose, it is asked once more with the format rule. If that fails too, the other available model takes over: Gemini when the DSH chat model was chosen and Gemini keys are set, the chat model when Gemini was chosen. It stays on for the rest of the class, and the polish panel says so. A network or rate-limit failure also tries the other model for that request. When neither model answers in the format, polish pauses and says why and where to change the model; no sentence is skipped, and the original text is kept. Sentences whose translation failed are tried again on their own about a minute later, up to two rounds, before they wait for you to retry. Not verified: tested with fake models only, not yet with a real switch between the DSH chat model and Gemini in a class.
