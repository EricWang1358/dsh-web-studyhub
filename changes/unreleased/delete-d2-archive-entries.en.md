- **Archiving a deck or several sources now takes one step, and every archive says how to undo it or delete it for good.** A deck's ⋯ menu has **Archive** (after **Manage deck**); if the deck has practice runs open, the menu says before you click how many it ends. On the Sources page, under **Organize courses**, you can tick several sources and press **Archive selected**: one action, one notice. Every archive notice (the deck menu, the Manage page, a source row, the ticked sources) offers **Undo**; for one deck or one source it also offers **Permanently delete…**, which opens the same confirmation as before. Nothing is deleted for good without that confirmation, and permanent delete is still only possible after archiving. The system deck "Personalised" (为你定制) has no Archive entry. Not verified: with a screen reader, and in the DSH desktop app's own browser (tested in Chromium).
