- **界面大小多了 50% 和 70% 两档。** 在「设置 → 界面 → 界面大小」里选，重开后仍然生效；小于 100% 时一屏放得下更多，字也更小：50% 时大部分文字只有 6–7.5 像素、多数按钮小于 24 像素，系统缩放为 100% 的屏幕上会很难看清，70% 时文字约 8.4–12 像素。看不清时在同一处调回去。「跟随窗口」仍然只放大，不会自己缩小。缩到 70% 或 50% 后，420 像素宽的窄面板放得下停靠的侧栏，所以显示侧栏而不是抽屉按钮（侧栏上的收起按钮仍可换成抽屉）。同时修好几处在 100% 以外任何档位都不对的地方：「对照资料」分隔条一拖就乱跳；拖图谱、拖概念画布里的节点、拖侧栏改顺序跟不上指针；原文里「词解」悬停卡不在划线处；选资料列表里每行说哪些名字、「资料」页标题行放不放得下全部按钮，用错了量法，小于 100% 时放得下也会省掉，大于 100% 时放不下也硬塞；统计图只画到半宽或超出框；总纲筛选条停错位置；缩小或放大后一些按窗口高度撑开的区域（如资料里内嵌的网页原件、图谱）只剩一半高或超出窗口；窄面板打开时先闪一下抽屉按钮再变成侧栏。换回旧版本时：旧版本不认识 50% 和 70%，会按默认大小显示（插件版 100%，桌面版跟随窗口）；只要不在旧版本里改外观设置，再升级回来选择还在。未验证：只在本机浏览器预览（Chromium，假模型和示例题库）里看过，没有在 DSH 里、桌面版窗口、Firefox、Safari、触屏或高分屏上试过；浏览器设了「最小字号」时的效果没有试；概念画布拖节点、滚轮缩放的锚点，以及几处让当前条目保持可见的自动滚动只改了算法，没有单独实测；选资料列表的行、「资料」页标题行、改了出题偏好后让输入框露出保存条的滚动，只单独渲染这几个部件量过，没有在这些页面里实测。
