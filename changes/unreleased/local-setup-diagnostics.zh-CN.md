- **本地 PDF 转换、本地转写、电脑声音直采与检索扩展的安装和启动报错，补齐了常见 Windows 原因识别，并统一提供「复制诊断信息」与「发给主会话」。** MinerU 启动失败或超时时保留服务自身的错误日志，只按这一次启动写下的内容判断原因（日志里更早的报错不再左右结果），没能把配置文件夹设为仅自己可用时会在安装日志里写明，识别主目录无写入权限和 Windows 路径过长并提供「换位置」；Marker 在检测到 Python 3.14 及以上时提前提示安装 Python 3.12，能分清依赖包编译失败和网络中断，识别 pip 的 Windows 长路径报错，并在 Python 版本本身没问题时直接说明不是版本问题、建议「发给主会话」；本地转写引擎在检查阶段读取子进程的错误输出，以识别缺失的 VC++ 运行库（英文 Windows 的提示也能识别）；电脑声音直采组件兼容运行库横幅输出并识别编译时的权限与长路径问题。上述卡片与检索扩展出错时，都能在同一行「复制诊断信息」（可先展开看看会复制什么，复制不了时直接选中文字）或「发给主会话」；两者都会去掉密码、令牌和密钥、网址里的账号密码以及用户目录里的用户名，长日志只保留结尾。本地转写的「发给主会话」会先问你是否改用云端转写，再处理录音。未验证：MinerU 配置文件夹的权限设置没有在真实 Windows 电脑上试过；Marker 在 Python 3.13 上可用的现成安装包没有到 PyPI 核对；没有跑过真实安装。
