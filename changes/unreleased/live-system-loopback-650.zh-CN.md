- **在 Windows 桌面客户端（以及无法弹出标签页共享窗口的浏览器环境）里，课堂实录现在可以通过按需热插拔的本机直采组件直接录电脑播放的声音，无需虚拟声卡、平时零后台进程。** 在 Windows 10/11 上选择「电脑系统声音（客户端 / 网课）」，无需弹出共享窗口或改动系统默认录音设备，就能直接采集扬声器、有线耳机或蓝牙耳机正在播放的课程声音：
  - **按需热安装与一键卸载**：安装包平时不预置任何原生程序；只在点击「安装电脑声音组件」时在本地独立目录 1–3 秒内生成约 20 KB 的只读采音程序（无需联网下载或管理员权限），每次启动前自动核对文件大小与 SHA-256 校验值，不用时可在「设置 › 音频转写」里一键卸载。
  - **平时与暂停时零声卡占用**：基于 Windows 原生共享环回接口（WASAPI）只读采集，不安装任何虚拟声卡驱动、不创建空播放流，也不会触发蓝牙耳机通话降质模式；点击「暂停」「结束实录」或关闭窗口都会立即退出采音进程并释放全部声卡句柄，课堂途中插拔耳机或切换播放设备会自动跟随。未验证：在打包后的 DSH 桌面客户端中配合第三方外置 USB 解码器驱动或多声道环绕声游戏耳机时的热切换延迟。
