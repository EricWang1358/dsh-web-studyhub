- **添加资料或后台任务走不通时，那里多了「发给主会话」。** 只在内置做法没走通之后才出现，主路径上不加新按钮；每一处都是同一个安静的链接（规则在悬停提示里，按下后是盖章回执）：
  - 创建题组 › 在主会话里录题：「开始录题并发给主会话」下面有「整本题册或文件里的题：发给主会话」，没配好模型时也有；页签说明改成「题册、刷题软件、错题或截图」。
  - 导入 JSON 题组：各题型提示词下面有「题目在 Word、PDF 或 Excel 里：发给主会话」；粘贴的 JSON 没通过检查时，错误那一行也有，会带上错误原文和这段内容（最多前 2 万字，截断了会写明）。
  - 拖放区不收的文件（添加资料、导入 JSON 题组、音频）：在没添加的文件列表下面。
  - 添加资料：一批文件里有没导入的，汇总那一行给一个，包含所有再试也会失败的文件和各自的原因（JSON 题组还附上开头）；读取中断的文件只保留「重试」。
  - 音频：表单不收的文件（视频、别的格式、太大或太长）那一行，以及预检拦下的文件的「换一个文件」旁边。
  - 太大或扫描版、没法直接导入的 PDF：转换卡片里有「不想装转换工具：发给主会话」（设置页里只是说明，没有）。
  - 失败、中断或已停止的任务：它的卡片（音频转写、首页的出题任务、PDF 转换）在下面那排链接的最后有一个；任务页里这类任务下面有一行「查原因、换条路做完：发给主会话」；PDF 转换失败的诊断里，「复制诊断信息」旁边也有。提示词让主会话先查清原因，接着做之前先问你，不另外再开一个任务。进行中、已完成、已归档或已被接着做的任务没有。
  - 空首页的「在对话中用工作区文件出题」（3.6.0 的已知问题）改成了「用工作区里的文件出题：发给主会话」，走共用部件；有没有主会话都显示（没有就复制）。
  - 已有的题先存成草稿：主会话把题册按章导入时，每章先存成草稿，你在「检查草稿」里看过再发布；只有你说直接导入时才马上发布。提示词里不再提 StudyHub 没有的操作；所有页面都只通过共用部件发给主会话，界面里也不再有「在对话中」「主对话」这类旧说法。
  - 未验证：真实模型怎么回应这些提示词、是否真的会按章拆题册（只跑了提示词测试、导入测试和假模型）；DSH 桌面版和真手机（检查的是 Chromium 的 1280 和 390 像素浅色，以及 npm run qa:dsh 跑的 DSH 网页）；英文和深色截图；真实的 ffmpeg、MinerU 或网络故障（三个卡住的任务是快照里编出来的记录），以及真的超过 8 MB 的教材（用的是一个编出来的 9 MB 文件）。
