- **终端版（TUI）代码块里的填空现在用多行输入框。** 填空位在围栏代码块（题面里的 ``` 或 ~~~）里时，会出现多行输入框：`Enter` 换行，`Ctrl+S` 去下一空、最后一空时提交整张卡（和普通填空里 `Enter` 是同一步），`Tab` 切到下一空，`Esc` 退出输入。普通填空仍是单行。揭示答案和“你的作答 / 参考答案”对照会保持代码缩进，折行后的续行也保持缩进，代码块里不再出现字面的 `**`。只在缩进、行尾空格或换行符上和参考答案不同的作答，不再被显示成不一致。（#1460）
  - 未验证：用内存中的终端测试（中文 100×28 与纯 ASCII 80×24）和真实判分验证过，没有在真实终端窗口里手动敲键试过。支持 `Ctrl+Enter` 的终端里它也能提交，但提示里只写 `Ctrl+S`，因为 Windows 控制台把它当成普通换行。
