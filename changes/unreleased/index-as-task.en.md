- **Building the search index is a task in Tasks.** Starting the index in Settings (or from a large book's card) now adds “Search index · course name” to Tasks, as every other long job is: it shows the pages done out of all of them, that it runs on this computer without AI and costs no tokens, a Stop, the reason when it stops (for example after five pages in a row could not be written, with what the search service said) and, at the end, what it added. Settings keeps its progress bar and Stop, and has “View in Jobs” beside them. A build that was already running when you upgrade is still the one build of the library: starting again shows that build instead of a second one, and the next build writes only the pages not indexed yet. Not verified: not run in a real DSH nightly with a real search extension or a large book (checked with a stand-in extension, in tests and a local preview); a build still running from the version before this one cannot be seen by this version if DSH loads the new version without restarting, and could then run beside a new one; in a preview without a live session the build still runs the old way and does not appear in Tasks.
