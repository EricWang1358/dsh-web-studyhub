- **Desktop: native large-document search extension support (auto-reuses an existing DSH install or installs standalone in one click).** Previously, opening **Settings › Search extension** in StudyHub Desktop reported that DSH could not install plugins in-app and showed a stale "cannot be found" warning when DSH had used the extension on the same computer. StudyHub Desktop now manages the local search MCP server directly with its bundled Node 22 runtime: if the extension is already installed in DSH, Desktop detects and reuses it read-only (never modifying or deleting DSH files, with an option to install a standalone Desktop copy); otherwise you can install the prebuilt Windows package in one click without DSH, Node, or npm. The LanceDB index and embedding model directory remain shared with DSH under a cross-process file lock, and installing, updating, changing the model download address, retrying startup, or repairing the index hot-restarts only the search subprocess with no app restart. Not verified: end-to-end networked `pack:retrieval --verify` build on `windows-latest` CI and visual inspection inside a live Tauri window.
