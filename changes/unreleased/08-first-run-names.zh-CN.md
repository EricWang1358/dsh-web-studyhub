- **第一次用：一个动作一个名字，首页只有一个下一步。** 发布新题组并开始练，现在到处都叫「发布并开始练」（草稿页和出完题的任务卡）；只打开草稿看一看叫「检查草稿」；加资料叫「添加资料」（创建题组页、今天先做什么、备考补习不再叫「导入资料」）。任务台和阅读页也叫「检查草稿」，使用指南和介绍站原来写的「保存并发布」也已改掉。首页那句「发布时还会再检查一遍」改成了实际发生的事：题目在出题时已经审阅过，发布时再检查一遍题目的结构。题组发布以后，它的任务卡会写「已发布」，不再写「草稿已生成」，并入已有题组下一部分的草稿也一样；已不在待发布里、又没有发布的草稿，会如实这样写，不再承诺发布。在你自己发布第一个题组之前，首页不显示「课程准备」和「今天先做什么」；示例课程、它的草稿和资料也不再给首跑步骤打勾。学习库页不再给出一条回到自己的路。没有配置模型时，顶栏写「未配置模型」，不再写「已连接」；窄窗口里页面标题保住位置，这个标签会缩短。未验证：没有用真实的 DSH 宿主和真实模型（截图来自用假模型的本地预览，只有中文）；并入题组后又被丢弃的草稿，和已发布的分不出来，所以任务卡只在它要并入的题组存在时才写「已发布」；窄顶栏只看了截图，没有在真机上看。
