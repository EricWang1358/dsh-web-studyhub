- **「创建题组」改成三种现成的「出题方式」：快问、情境题（默认）、逐题精出。** 主路径上原来选「覆盖强度」的地方，现在只有这一项。「情境题」是标准题量、一次写完、每题一个短情境，和以前的默认完全一样。「快问」是精简题量、一次写完、一个知识点一道短题。「逐题精出」是标准题量、按原来的逐题流程出。每种预设都是两项设置的一个组合，这两项也可以分开选，都在「更多选项 › 出题方式与题量」里：「覆盖强度」（精简 / 标准 / 完整 / 自定义，各档和每万字题数都没变，「自动补到完整」也在这里）和新的「出题深度」（快问 / 情境题 / 逐题精出）。不是预设的组合，主路径上写「自定义」并说出两项各是什么。填了题数，或手动勾选、取消「自动补到完整」时，「更多选项」会自动展开，你设过的东西不会被藏起来。勾选了其他题型时，出题深度不起作用（其他题型总是逐题精出），预设会变灰并写明原因，只有覆盖强度起作用。
  - **每种选择旁写着大致花费。** 选了资料后，主路径上每种预设旁写着相对「情境题」的倍数，如「约 ×0.6」，括号里是它大约出多少题；选中那种的题数写在出题按钮旁。打开「更多选项」后，有一张表列出九种组合的同样信息，当前组合有标记。每个倍数都是按你选的资料，用这个组合 token 预估的上限，除以默认组合的上限得出的，不是固定倍数。悬停说明会讲清：这只是粗略比较，实际花费因模型而异。它还说明两点：逐题精出每万字出的题更少，所以整次可能更省、每道题更贵；快问省下的那部分没有实测。没选资料时不显示倍数。填了题数时，主路径写「自定义：40 题 × 情境题」，也不显示倍数和那张表：每个倍数都是按某一档覆盖强度估的，不是按你填的题数。
  - **写题风格成了真正的设置。** 「设置 › 高级生成控制」里，原来的「出题方式」换成一个「出题深度」，一次保存出题流程和写题风格。保存为逐题精出的学习库，读出来就是「逐题精出」；打开了「采纳审阅建议」又没保存过出题流程的学习库，也是「逐题精出」。原有的保存值都仍然有效。表单上选的只对这一次出题有效。一次写完的草稿会记下写题风格，续出和补题时沿用；更新前的一次写完草稿按「情境题」处理；逐题精出的草稿不记风格。每一次一次写完的写题调用都用这个风格：第一次写题、回复不是 JSON 时的再问、空小节的再问，以及补题轮重写一份资料时。深度定制总是逐题精出。出题失败后点「按原资料重新设置」，会带回那次用的出题深度；更新前的单选题任务没有记录，提示里会说明。
  - 未验证：token 预估把「快问」写题的输出算作「情境题」的 1/1.15。这个系数来自原型对两种提示词的实测，产品里没有实测过。倍数和快问的题数都没有接真实模型验证过。
